# MiSans 字体

- 文件：`MiSans-Normal.woff2`（由 MiSans-Normal.ttf 转 WOFF2，约 3.9 MB）
- 来源：小米 MiSans 官方字体包 <https://hyperos.mi.com/font/download>
- 许可：MiSans 字体知识产权许可协议，官方 FAQ 说明可免费商用、可嵌入软件，但需在软件中注明使用了 MiSans 字体。
- 用途：手机端 UI 正文字体（Android OEM 的 OPPO Sans Regular 字形偏宽、笔画偏厚，16/400 会显笨重）。
- 注意：不要改成系统 `sans-serif` 的唯一来源；保留系统字体作为缺字回退。
