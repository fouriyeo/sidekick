# 用户与场景

> 不写“所有用户”。本期只服务两类具体的人；其他人群明确列为非目标。

## 1. 主要用户

### A. AI 结对开发者 / 小团队工程师

| 项 | 描述 |
| --- | --- |
| 画像 | 25–40 岁，macOS，日常用 Qoder / Claude Code / 终端 / 编辑器；每天有 2 小时以上与 AI 结对 |
| 桌面 | 手机竖着放在支架上，靠近键盘；常充电 |
| 核心诉求 | 不想频繁把手从键盘移到手机；希望一句话就能变成 prompt；桌边有个不打扰的小东西 |
| 痛点 | 打字描述长需求慢；语音备忘录要来回切换；现有桌宠只是动画，不参与工作流 |
| 使用场景 | 写需求、改 bug、让 AI 解释代码时，按住手机说一段，松开后文字出现在光标处 |
| 成功感受 | “顺手，不用想它在哪；它在那儿我就安心。” |

### B. 内容创作者 / 研究者

| 项 | 描述 |
| --- | --- |
| 画像 | 25–45 岁，长期写文档、做研究、和 AI 讨论；桌面时间碎片化 |
| 桌面 | 手机竖放在桌边，偶尔拿起；不喜欢频繁通知 |
| 核心诉求 | 口述长段落比打字快；需要安静的陪伴感，而不是又一个消息中心 |
| 痛点 | 语音输入工具割裂；桌宠太吵、太幼稚或太“游戏化” |
| 使用场景 | 思路来了，按住说 20 秒；工作间隙看一眼宠物，继续 |
| 成功感受 | “它不催我，但我知道它在。” |

## 2. 次要用户

- 桌搭 / 桌面美学爱好者：愿意为“好看、想放在桌上”买单；对视觉和动效敏感，对功能深度要求低。
- 不单独做需求，但作为视觉与情绪价值的验收样本。

## 3. 非目标用户（本期不服务）

- 需要生产力仪表盘、任务管理、团队协作的用户。
- 儿童与未成年人：涉及录音、隐私与合规，本期不设计。
- 公共/共享网络环境用户：本期无鉴权、无加密，只支持可信局域网。
- 期待平板 / 大屏多任务体验的用户：手机只做竖屏单布局（D62），平板按竖屏展示，不做大屏改造。
- 期待桌面端也出现宠物的用户：本期宠物只在手机；桌面端只做麦克风接收与状态浮窗。

## 4. Jobs to be Done

| 场景 | 我想完成的事 | 现在的替代方案 | 我们的做法 |
| --- | --- | --- | --- |
| 双手在键盘上，思路正热 | 快速把一句话变成 prompt | 停下打字 / 切换语音备忘录 | 按住手机说，松开后文字出现在光标处 |
| 一个人工作很久 | 桌边有个会回应的生命 | 真宠物 / 视频 / 社交 | 竖屏桌宠，低打扰、会想你、不要求操作 |
| 离开一会儿回来 | 被轻轻欢迎，而不是被催办 | 通知中心 / 聊天红点 | 宠物抬头、伸懒腰；不弹通知、不报未读 |
| 工作间隙想放松 10 秒 | 看一眼它在做什么 | 刷手机 / 短视频 | 看它呼吸、眨眼、打哈欠 |
| 不想被录音 | 确认麦克风只在按住时工作 | 看不见的后台录音 | 按住才录、可见指示、松手即停、不存音频 |

## 5. 一天的使用旅程

```text
09:00  坐下，手机竖放在支架上；宠物抬头、伸懒腰
09:30  写需求，按住手机说 15 秒；电脑光标处出现文字，宠物安静待在桌边
10:30  卡住了，看一眼宠物；它自己张望，继续工作
12:00  离开吃饭；App 进入后台，宠物停止动画
14:00  回来；宠物轻轻“想你”一下，不弹出任何通知
23:30  还在写；宠物开始打哈欠，慢慢睡着，不催促
```

## 6. 研究计划（不编造数据）

- 5 次自用/朋友试用，每次 30 分钟，记录：
  - 第一次是否知道“不用操作宠物也可以”；
  - 是否愿意把手机竖放在桌上超过 30 分钟；
  - 麦克风一次成功率高不高、最慢的一次多久；
  - 哪句宠物文案让人不舒服或尴尬。
- 访谈只问行为和感受，不问“你喜不喜欢”这种引导性问题。
- 所有指标目标值在 [metrics.md](./metrics.md) 标为 `[假设]`，试用后校准。
