# 本期范围

> 本期两个主功能：**情绪宠物** + **外设麦克风（AI 语音输入）**；另有两个经确认的 P1 能力：**桌面剪贴板历史**、**AI 联动（DSH hook）**。麦克风以百炼云端为唯一识别引擎（P0）。
> 范围之外的想法写到“以后”，不要夹带进 P0。

## 1. 阶段划分

| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| Phase 0 | 局域网 MVP、前端脚手架、产品规范、两份 PRD | ✅ 2026-10-31 |
| Phase 1 P0 | 情绪宠物 + 麦克风 AI 语音输入 + 双姿态 + 本地持久化 + 设置 | 宠物代码完成；麦克风 P0 已实现（真机/自动粘贴待回归） |
| Phase 1.1 P1 | 锁定说话/连续听写、喂零食、配对鉴权、release 打包；剪贴板历史（已实现） | 剪贴板已实现，其余未开始 |
| Phase 1.2 P1 | **AI 联动（DSH hook）**：桌面开关 + 本地脚本注入 + 手机四态/三音效 | 开发中（2026-11-02） |
| Phase 1.3 P0 | **百炼云端流式语音识别**：云端唯一、桌面中转、Keychain、流式回显、模型页/用量统计 | 代码已实现（2026-11-02），真机/账号/金额对账待补 |
| Phase 2 P2 | 系统级虚拟麦克风、BLE、iOS、云同步、多语言 | 未开始 |

## 2. 平台矩阵

| 能力 | 手机（横屏） | 桌面（macOS） |
| --- | --- | --- |
| 情绪宠物 | ✅ 主体，全屏舞台 | ❌ 本期不渲染 |
| 麦克风采集 | ✅ 按住说话、波形、计时 | ❌ |
| 转写 | ❌ | ✅ 百炼云端流式（唯一） |
| 文本输入 | ❌ | ✅ 当前焦点应用 / 剪贴板 |
| 状态反馈 | ✅ 倾听/转写中/完成/失败 | ✅ 应用内浮层（独立小窗 P1） |
| 语音模型 | ❌ 不下载模型 | ✅ 模型页配置百炼/查看用量；不下载模型 |
| 剪贴板历史 | ❌ | ✅ 文本历史（P1 辅助） |
| AI 状态联动 | ✅ 四态动作 + 三音效 | ✅ AI 联动页 + 本地 DSH 脚本注入（P1） |
| 连接角色 | 客户端 | 服务端 + 本地客户端 |

**边界**：桌面和手机是两个独立产物，共享协议与基础组件，不共享页面布局。移动端不强制横竖屏；不做跨端自适应。

## 3. P0 做什么

### 情绪宠物

- 首次见面、命名、默认名。
- 桌面陪伴：呼吸、眨眼、张望、伸懒腰、打哈欠、夜间睡觉。
- 触摸互动：摸摸、戳一戳；不做拖拽、不做复杂手势。
- 情绪与记忆：心情、精力、亲密度（隐藏数值）、离开后回来、跨重启保存。
- 双姿态：支架模式、手持模式；横屏自动支架、竖屏自动手持，设置可手动覆盖（传感器判定 P1）。
- 麦克风联动：契约保留、本轮未实现（P1）。
- 设置：名字、震动、减少动效、姿态（docked/handheld）、屏幕常亮（默认开，最长 2 小时可调）、自动变暗（默认 5 分钟可调）、重置、关于/隐私；声音暂未接入。

### 外设麦克风

- 从宠物界面一键进入；未连接时引导连接。
- 按住说话、上滑取消、最短/最长时长、后台停止。
- 手机录音权限、桌面辅助功能权限的说明与降级。
- 桌面百炼云端流式转写（唯一）；默认自动粘贴，失败/不安全时仅复制。
- 绝不自动按回车、绝不自动发送。
- 手机端状态反馈、波形、结果卡片；桌面应用内状态浮层。
- 桌面「模型」页配置百炼（完整地址、显式同意、Key 存 Keychain；无业务空间 ID 字段）、区间切换查看今天/7/30/365 与按天/按月明细；设置 Sheet 只留自动输入/剪贴板。
- 云端唯一：未配置/未同意/无 Key 时手机明确报错；失败不插入、不回退本机；中间结果实时回显。

### 双姿态

- 支架模式：宠物大、界面元素自动隐藏、底部居中麦克风胶囊。
- 手持模式：宠物在上 2/3；底部居中麦克风按钮 + 上滑取消；界面元素常显。
- 姿态是状态变化，由屏幕方向自动驱动；设置可手动覆盖；切换期间忽略重复切换，录音中冻结布局。

### 桌面剪贴板（P1 辅助，已实现）

- 只记录文本；搜索、复制回填、置顶、删除、清空、暂停。
- 密码管理器标记为隐藏的内容不记录；最多保留最近 100 条（新内容淘汰最旧的未置顶项）。
- 语音转写结果也会记入历史并标为「语音」；手动复制回填只刷新使用时间，不重复入库。
- 本地 `0600` JSON，不联网、不写日志。
- 详情见 [engineering/clipboard-manager.md](../engineering/clipboard-manager.md)。

### AI 联动（P1，开发中）

- 桌面「AI 联动」页：开关、安装/修复/移除、连接状态、当前状态、事件日志、本机模拟。
- 第一期接 DeepSeek Harness：Sidekick 写本地 `.mjs` 插件并插入 profile patch，不装第三方 npm 包；首次需重启 DSH 一次，之后热开关。
- 手机宠物四态：静态、工作中、等你决定、完成（3 秒）；动作夸张、远看可区分。
- 三个音效：开工、提问、完成；默认关，可试听；录音/后台静音。
- 只同步状态/会话数/时间；不读提示词、回复、工具参数、文件路径。
- 产品规则见 [prd/hook](../prd/hook/INDEX.md)，技术方案见 [engineering/dsh-hook.md](../engineering/dsh-hook.md)。

## 4. P1 / P2（先记录，不实现）

| 优先级 | 内容 | 为什么后置 |
| --- | --- | --- |
| P1 | 锁定说话 / 连续听写 | 需要 VAD、流式转写和更复杂的取消逻辑 |
| P1 | 喂零食、收藏、小游戏 | 容易变成任务系统，先验证纯陪伴是否成立 |
| P1 | AI 状态联动（DSH hook） | 先做最小只读状态闭环；手机回答/文本消息后续 |
| P1 | 配对与鉴权 | 当前仅可信局域网；上线前必须补 |
| P1 | release 签名与桌面打包 | 先验证体验，再处理分发 |
| P1 | 剪贴板全局快捷键/菜单栏入口 | 当前先做窗口内切换；快捷键需选型与冲突验证 |
| P1 | 桌面独立 always-on-top 浮窗 | P0 先做应用内浮层，避免窗口焦点问题 |
| P2 | 系统级虚拟麦克风 | 需要 macOS 虚拟声卡驱动，工程量大 |
| P2 | BLE 通道 | Tauri 移动端 BLE 生态弱，需自写插件 |
| P2 | iOS | 后台与音频限制需单独评估 |
| P2 | 云同步 / 多语言 / 多厂商云 ASR | 隐私与成本问题，需单独决策；当前百炼单厂商 |

## 5. 明确不做

- 手机端正式聊天主界面、消息历史、通知中心（现有调试聊天保留，不扩展）。
- 账号、云同步、社交、排行榜、好友。
- 宠物饥饿/死亡/掉级/签到/任务。
- 单独竖屏布局（竖屏沿用同一舞台）。
- 桌面端宠物渲染。
- 跨端响应式断点（`sm/md/lg` 一套通吃）。
- 系统级虚拟麦克风（P2）。
- 公共网络下的可用性承诺。

## 6. 跨功能契约

1. 宠物和麦克风共享手机横屏舞台，但代码分属 `mobile/features/pet` 与 `mobile/features/mic`。
2. 麦克风状态优先于宠物情绪：倾听时暂停随机 idle 行为，结束后恢复之前的心情。
3. 宠物永远不遮挡麦克风按钮、波形、计时和取消区域。
4. 宠物在麦克风失败时表达“关心”，不表达“责怪”；文案不出现“你怎么又没听清”。
5. 麦克风不依赖宠物渲染成功；即使 Rive 加载失败，录音与转写仍可用。
6. AI 联动只影响宠物展示状态，不改变宠物存档/命名/触摸规则；倾听/摸摸优先于 AI 状态，结束后恢复。

## 7. 发布标准（Phase 1）

- [ ] 两份 PRD 评审通过，本期范围内 P0 用例通过（宠物不含麦克风/声音；屏幕常亮已落地，按 P1 回归）。
- [ ] Realme 真机横屏 60fps；麦克风 p95 端到端 ≤ 3s（≤10 秒语音，麦克风阶段）。
- [ ] 录音全程可见；无后台录音；无原始音频落盘。
- [ ] 自动粘贴不按回车；目标窗口变化/密码框时只复制。
- [ ] 宠物跨重启保留名字、基线心情与设置；重置有二次确认。
- [ ] `pnpm typecheck && pnpm lint && pnpm test && pnpm build` 通过。
- [ ] 文档树链接检查通过；`protocol/README.md` 与音频协议同步。
- [ ] 剪贴板历史本地文件权限 `600`，隐藏内容过滤通过。
- [ ] AI 联动：DSH 安装/重启/四态/三音效/隐私用例通过，见 [hook ACCEPTANCE](../prd/hook/ACCEPTANCE.md)。

## 8. 范围变更规则

- 新增 P0 功能：必须说明它替代了哪个 P0，或给出明确排期；P0 模块总数不超过 5 个/功能。
- 任何“顺便做”的想法默认进 P1/P2，不直接进本期。
- 范围变化写入 [decisions.md](../decisions.md)，并同步两份 PRD 的版本号。
- 2026-10-31 经用户确认，将桌面剪贴板作为 P1 辅助能力纳入本轮实现，不替代宠物/麦克风 P0（D44）。
