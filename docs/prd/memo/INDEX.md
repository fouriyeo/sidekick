# 语音备忘录 · 一页摘要

> 实现状态（2026-11-08）：S1 手机独立 + S2 局域网镜像代码完成，待真机联调；Key 暂存 App 私有文件（Keystore 列 P1），手机固定官方端点。技术细节与偏差见 `docs/engineering/memo-pipeline.md`。

> 手机独立完成「录音 → 识别 → 归类 → 存成备忘录」：说完一段话，AI 把它整理成一条可回看的备忘/待办/灵感；电脑是镜像与回看端（同局域网自动同步）。
> 本期定位：**手机主设备 + 桌面只读镜像**。不做完整 AI 聊天、不做公网同步/账号、不做自定义分类体系、不做多设备、iOS 后续。

## 本期做什么

- 手机新增「备忘录」入口（宠物页顶栏图标 → 全屏页）：点按开始录音（**仅前台/亮屏**，锁屏与后台录音 P1 暂缓）；录音默认保留（可在设置关闭）。
- 手机独立跑 AI 管道：分段 ASR（百炼）→ LLM 结构化（标题 / 类型 / 摘要 / 待办项）→ 本地 SQLite；离线时排队、联网自动补处理。
- 手机本地列表与详情：按时间倒序、今天/更早分组；详情含播放器、转写全文、摘要、待办项、类型；可改标题/类型，可删音频或整条。
- 电脑新增独立一级页「备忘录 ⌘3」（D123，只读镜像）：回听、看全文与摘要；剪贴板保持单一职责。
- 同局域网镜像同步：手机为所有者单写，桌面只读；音频分块上传、确认后才删手机本地；不做公网。
- Key：允许电脑一次性下发到手机（电脑生成 6 位码、手机输入），也支持手机手动粘贴兜底；手机存 App 私有文件（0600；Keystore 列 P1）。

## 不做什么

- 完整 AI 会话/多轮聊天（本期是处理管道，单条可「重新归类」）。
- 公网同步、账号体系、多台电脑/多台手机。
- 自定义分类体系、标签管理、批量操作、导出分享。
- 桌面编辑备忘录（只读）。
- iOS、系统级集成（快捷指令/桌面小组件）。

暂缓（不是不做，只是晚做）：锁屏/后台录音（P1）；发热/耗电与用量/成本估算（P2，D118）。
