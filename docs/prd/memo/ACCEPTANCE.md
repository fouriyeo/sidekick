# 语音备忘录 · 验收用例

> 实现状态（2026-11-08）：S1 手机独立 + S2 局域网镜像代码完成，待真机联调；Key 暂存 App 私有文件（Keystore 列 P1），手机固定官方端点。技术细节与偏差见 `docs/engineering/memo-pipeline.md`。

> 覆盖录音（前台）、管道、归类、离线、Key、同步、桌面镜像、隐私与回归。真机基准：Realme RMX3370（Android 13 / WebView 103）与 Honor BKQ-AN10（Android 17 / WebView 156）。
> 测试 Key 用独立测试账号；`SIDEKICK_DATA_DIR` 指向临时目录；不污染真实 `~/.sidekick`。

## M-01 录音基本流程

- **Given** 已授权麦克风、无进行中的录音。
- **When** 进入备忘录页，点一下录音按钮（≤400ms）说 10 秒，再点一下结束。
- **Then** 生成一条状态为「识别中/等待识别」的条目；第一条先出隐私告知；音频文件存在于 App 私有目录；时长误差 ≤1s；页面可离开再回来。

## M-02 前台限制：锁屏/切后台即停止并保存

- **Given** 录音中（App 在前台）。
- **When** 按电源键锁屏 10 秒后解锁；再录一条，按 Home 切到桌面 10 秒后回来。
- **Then** 两次都在切走时**停止并保存**（不继续录）；提示「录音已停止并保存（需要保持 App 在前台）」；回到 App 可见两条条目；不产生后台录音、无未捕获错误。
- **P1 说明**：锁屏/后台录音（原生采集 + 前台服务）暂缓，见 M-02b（本期不验收）。

## M-02b 锁屏/后台录音（P1，暂缓，当前不验收）

- **Given** 录音中。
- **When** 锁屏 30 分钟，再解锁。
- **Then** 录音不中断（通知计时持续）；解锁后计时与实际一致；停止后音频完整可播。标记 `@P1`，本期跳过。

## M-03 切后台/其它 App

- **Given** 录音中。
- **When** 打开相机、或来电抢占麦克风。
- **Then** 录音停止并写盘，提示「录音被系统打断，已保存」；不自动恢复；无未捕获错误。

## M-04 2 小时上限

- **Given** 录音中（可用 mock 时钟加速）。
- **When** 计时到 2:00:00。
- **Then** 自动停止并保存；提示「已到 2 小时上限，录音已保存。」；不生成第二条空录音。

## M-05 崩溃恢复

- **Given** 录音中（已写满 1 个分片）。
- **When** `adb shell am force-stop` 杀进程后重启 App。
- **Then** 提示「上次录音可能中断，已恢复 1 片」；已落盘分片可继续识别或导出；不丢整段。

## M-06 取消录音

- **Given** 录音中。
- **When** 点「取消」→ 2 秒内再点「确认」。
- **Then** 本次音频删除，不产生条目；再点超时则取消取消、录音继续。

## M-07 管道状态

- **Given** 已录 3 段音频、Key 与网络正常。
- **When** 停止录音。
- **Then** 状态依次 `pending → transcribing(第 1/3 段…) → structuring → done`；每段转写落库；完成后出现标题/类型/摘要/待办。

## M-08 离线排队

- **Given** 飞行模式。
- **When** 录一段并停止。
- **Then** 状态「等待网络」；音频与转写草稿保留；恢复网络后自动开始，无需用户操作；中途杀进程重开仍继续。

## M-09 失败重试

- **Given** mock ASR 第 2 段返回错误。
- **When** 停止录音。
- **Then** 条目「识别失败 · 重试」；第 1 段转写仍可看；点重试从第 2 段继续，不重复第 1 段计费/文本。

## M-10 LLM 结构化与兜底

- **Given** mock LLM 返回合法 JSON。
- **Then** `title ≤20 字`、`type ∈ {memo,todo,idea}`、`summary ≤80 字`、`todos ≤5`；非法 JSON/超时时保留转写、类型兜底 `memo`、显示「重新整理」。

## M-11 归类与编辑

- **Given** 三条不同内容。
- **Then** 类型分别落在待办/灵感/备忘录；详情页可改标题与类型，保存后列表立即更新；重启后保留。

## M-12 列表与详情

- **Given** 今天 2 条、昨天 1 条、上月 1 条。
- **Then** 默认选中今天、只显示今天 2 条；点昨天（周或月视角）只显示昨天 1 条；行显示类型、标题、摘要、时间、时长、同步点；详情播放器可播/暂停/拖动；详情可「复制全文」。

## M-13 音频保留

- **Given** 设置「保留录音」开。
- **Then** 处理完成后音频仍在，详情可播。
- **Given** 关闭开关后新录一条。
- **Then** 完成后音频删除、文字保留；已有条目不删。

## M-14 Key 下发

- **Given** 手机已连电脑、电脑已配置 Key。
- **When** 电脑点「发送到手机」生成 6 位码，手机输入。
- **Then** 电脑确认后手机显示「已配置」+ 掩码；Key 不出现在日志/界面明文；错误码 3 次后作废；2 分钟过期。

## M-15 Key 兜底与失效

- **Given** 未配对/电脑不在线。
- **Then** 可手动粘贴 Key 并生效。
- **Given** 错误 Key。
- **Then** 条目「Key 不可用，识别已暂停」，任务保留，改 Key 后可继续。

## M-16 局域网同步

- **Given** 手机有 3 条未同步、电脑在线且已配对。
- **When** 手机连上电脑。
- **Then** 自动推送元数据 + 音频分块；电脑确认后手机标记「已同步」；电脑一级「备忘录」页出现 3 条。

## M-17 断点续传与去重

- **Given** 上传到 60% 时断网。
- **When** 恢复网络。
- **Then** 从字节偏移续传；不产生重复条目；sha256 校验通过；未确认前手机不删。

## M-18 删除同步

- **Given** 一条已同步条目。
- **When** 手机删除并确认。
- **Then** 手机文件/行删除；桌面收到墓碑后移除；桌面不能反向删除手机条目。

## M-19 桌面只读与日历

- **Given** 已同步条目（分布在多天）。
- **When** 打开侧栏「备忘录 ⌘3」，切月/周、翻页、点日期，再点一条。
- **Then** 页头是「备忘录」；左日历 + 右当日列表；默认月视角；点日期只筛当天；详情可播放、看全文/摘要/待办、复制全文；无编辑/删除/重新归类入口；音频缺失时显示「音频不在本机」；1180/960 宽都不横向溢出；剪贴板页不再有备忘录分段。

## M-20 隐私

- **Given** 完成一次录音到同步。
- **Then** `adb logcat` 与桌面日志中不出现转写文本、标题、摘要、音频路径、Key；同步消息只发往已配对连接；未配对客户端收不到 `memo.*`。

## M-21 性能

- **Given** 50 条备忘录、1 小时录音。
- **Then** 备忘录页首屏 p95 ≤300ms；列表滚动 60fps；10 分钟录音处理 p95 ≤90s（测试账号）；内存峰值 ≤200MB。

## M-22 回归

- **Given** 备忘录功能上线。
- **Then** 原语音输入（按住说话→插入光标）行为不变；宠物页布局/会话卡/连接页不受影响；`?role=mobile` dev mock 可用。

## M-23 质量门

- **Then** `pnpm typecheck && pnpm lint && pnpm test && pnpm build`、`cargo test`、`node scripts/check-docs.mjs`、`node scripts/check-boundaries.mjs` 全绿；真机安装走查 390/360/320 × 浅/深无溢出。

## M-24 C 双模手势矩阵

- **Given** 首次告知已同意、页面空闲。
- **When** 轻点 ≤400ms（手机与 TalkBack 双击）→ 持续 60s → 再点结束。
- **Then** 第一次进入锁定态并 toast「已锁定录音，点一下结束」；60s 不中断；第二次点击保存；只产生一条条目。
- **When** 按住 1200ms 后松手。
- **Then** 立即保存，不再继续录。
- **When** 按住上滑超过 80dp 后松手。
- **Then** 取消，不产生条目；提示「已取消录音」。
- **When** 从按钮上开始纵向滚动（20 次）。
- **Then** 0 次产生条目；`pointercancel` 后 <1s 静默丢弃。

## M-25 日历周/月与 320

- **Given** 有跨 3 周的条目。
- **When** 手机在 320×720 下切周/月、翻页、点日期。
- **Then** 月格实测 44×44、7 列、6 行；周视角 6 格可横滑到第 7 天；切视角选中日不变、列表回顶；点灰显跨月日正确翻月并选中；320/390 无横向溢出。

## M-26 录音中 guard

- **Given** 录音中（含锁定态）。
- **When** 按页头返回、系统返回、切日期、切视角、点条目、点 Key 提示、进设置。
- **Then** 全部被拦；返回一次 = 停存 + toast + 留在本页；第二次才离开；不丢录音；`starting` 阶段切后台不会偷偷开录。

## M-27 首录隐私告知

- **Given** 从未录音过（`sidekick:memo:privacy` 为空）。
- **When** 首次按住/点击录音。
- **Then** 先出底部 Sheet，不启动麦克风；取消不启动；「同意并开始」后以锁定态开始且不再弹。

## M-28 复制全文

- **Given** 已完成条目。
- **When** 手机详情点「复制全文」、桌面详情点「复制全文」。
- **Then** 全文进入系统剪贴板，可粘贴到微信/备忘录；成功 toast；无 Clipboard API 时 textarea 回退成功。

## M-29 质量门（v0.3）

- **Then** `pnpm typecheck && pnpm lint && pnpm test && pnpm build`、`cargo test`、`node scripts/check-docs.mjs`、`node scripts/check-boundaries.mjs` 全绿；手机 320/360/390 与桌面 1180/960 × 浅/深无溢出；真机 Realme/Honor 走查通过。
