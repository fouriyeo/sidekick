# 语音备忘录 · SPEC

> 实现状态（2026-11-08）：S1 手机独立 + S2 局域网镜像代码完成；v0.3 交互改版（D124）代码完成，待真机走查。Key 暂存 App 私有文件（Keystore 列 P1），手机固定官方端点。技术细节与偏差见 `docs/engineering/memo-pipeline.md`。

> 只写「长什么样、怎么动、说什么话」。产品规则见 [PRD](./PRD.md)，验收见 [ACCEPTANCE](./ACCEPTANCE.md)。
> 视觉全部落在手机 `.mobile-clean` 与桌面 `.desktop-ios` 作用域内，不新增全局主题。

## 1. 信息架构

```text
宠物页（根）
 ├─ 顶栏：gear / 连接 / 今日用量 / [备忘录] / chat
 ├─ 备忘录页（全屏二级）
 │   ├─ 日历（周 / 月两个视角，D124）
 │   ├─ 当日列表（按选中日筛选）
 │   ├─ 底部录音条（C 双模）
 │   └─ 详情（从列表进入，全屏二级）
 └─ 设置（二级）→ 备忘录分组（保留录音 / 占用空间 / Key / 隐私说明）
```

- 顶栏「备忘录」图标 16px、44×44 命中区；320 宽下优先压缩今日用量与连接文字，不隐藏图标。
- 备忘录页页头 44：左「‹ 返回」、中标题「备忘录」17/400、右「今天」44 文本入口（已选今天时 `aria-disabled`）。
- 返回层级：详情 → 备忘录；月视角 → 周视角；录音中 → 先停存并留在本页；否则回宠物页。
- 不新增底部 tab；备忘录仍是第三个全屏二级页（与连接页、用量页同级）。

## 2. 手机页面结构

```text
┌ PageHeader 44 ────────────────┐  返回 · 备忘录 · 今天
├ 日历 ─────────────────────────┤
│ 工具行 44   ‹ 2026 年 11 月 ›  [周|月] 88×44
│ 周视角 68   周一…周日（7 格 44×52，可横滑）
│ 月视角 296  星期行 24 + 6×44 网格
├ 列表（仅此区域滚动）──────────┤
│ 11 月 8 日 · 周日        2 条 │
│ 白卡 16 圆角 / 行 60          │
├ 录音条 96 + safe-area ────────┤
│ 提示行 + 64 圆钮（录音中 60）  │
└───────────────────────────────┘
```

- 日历固定不滚，只有列表滚动；录音中列表仍可滚，录音条不动。
- 高度预算：320×720 周视角列表 ≈424px（7 行）、月视角 ≈248px（4 行）；390×844 周 10 行、月 6 行。
- **320 宽月格例外**：7×44=308 > 288（页面左右 16），月网格容器允许 `-mx-2.5`（左右各 6）；360 起恢复 16 边距，列宽自然 ≥44。这是 ux.md 全局 16 边距的唯一例外。
- 全部容器处理 `env(safe-area-inset-*)`；录音按钮下沿距屏底 ≥24dp + `env(safe-area-inset-bottom)`（按钮顶部约 88dp），避开 Android 手势条。

## 3. 日历

### 3.1 工具行（44）

| 元素 | 规格 |
| --- | --- |
| 翻页 | `‹` / `›` 44×44；周视角移动选中日 ±7 天（同星期），月视角只翻月、不改选中 |
| 标签 | 13/600 单行省略；周视角「11 月」；月视角当年「11 月」、非当年「2025 年 11 月」 |
| 视角分段 | 88×44 命中区、可视轨道 32 高，滑块用 `transform`；`aria-pressed`，组名「日历视角」 |
| 记忆 | 默认周；`localStorage["sidekick:memo:calendar"]` 记住上次视角 |

- 分段/翻页/日期在录音中全部禁用（`disabled` + `aria-disabled` + 降透明度）。
- 页头「今天」：回到今天并保持当前视角；已选中今天时不可点、不位移。

### 3.2 周视角（68）

- 7 格 **44×52**、gap 2、条内 padding 8；`overflow-x:auto` + `scroll-snap`；320 可见 6 格（6×44+5×2=274），360/390 可见 7 格（7×44+6×2=320）。
- 每格：星期 10.5（今天写「今天」）+ 日期 15 + 记录点 4px（有记录才显示）。
- 今天 1.5px 薄荷描边；选中实底反白；选中日滚到第 2 个可见格（左侧露出一天，暗示可横滑）。
- 空白日可点；未来日期可浏览。

### 3.3 月视角（296）

- 固定 **6 行 × 7 列**（42 格），星期行 24；5 周月份最后一行留空，翻月高度不跳。
- 格 44×44（320 时左右各 6 边距后恰好 44）；日期 13.5；今天描边、选中实底反白；非本月日期 40% 灰显且可点（点了翻到该月并选中）。
- 记录点：1 条 1 点、≥2 条 2 点；`aria-label` 报真实条数与今天/已选状态。
- 翻月只浏览，点日期才改选中；列表随选中日更新，停留在月视角。

## 4. 录音条与 C 双模（P0）

### 4.1 布局

- 白底、上边 0.5px 分隔线；`flex-none`；高 96 + `env(safe-area-inset-bottom)`。
- 提示行：11.5/16，居中；录音中左侧显示 20/24 计时。
- 圆钮 64（录音中 60、石墨 `#2C2C2E`）；白色图标 mic / stop；锁定态加 2px 薄荷外环。
- 锁定态右侧「取消」44 高文本按钮；二次确认 2 秒。

### 4.2 状态机

```text
idle ─pointerdown→ starting（"正在打开麦克风…"）─→ hold
hold（按住）
  ├ up held<400 且位移<10px → locked（轻震 +「已锁定录音，点一下结束」）
  ├ up held≥400 → saving
  ├ 上滑 >80dp → cancelArmed（珊瑚 +「松手取消」）
  │    ├ 回退 <32dp → hold
  │    └ 松手 → cancelled（「已取消录音」）
  └ pointercancel（滚动/来电/手势条）→ <1s 静默丢弃；≥1s 停存
locked ─pointerdown/up 或 TalkBack click→ saving
idle ─click（无 pointer）→ locked（TalkBack 直接开始）
```

- 释放发生在 `starting` 阶段时记录释放时刻，进入 `recording` 后再判 400ms，**启动耗时不计入按住时长**。
- 明确停止时：时长 <600ms 且峰值 <0.03 → 取消并提示「太短了，再说一次」；有声音的 0.5s 短句保留。自动保存（返回/切后台）不走这条。
- 录音中返回：停存 + 提示「录音已停止并保存」+ 留本页；第二次返回才离开。
- 录音中切后台/锁屏：停存；`<1s` 静默丢弃，其余保存并提示「录音已停止并保存（需要保持 App 在前台）」。
- 锁定后切页/进详情：`memoBusyNow()` 拦截；页头返回、系统返回、Key 提示、列表行全部禁用或先停存。
- 计时每 200ms 刷新；`aria-live="polite"` 每 10 秒播报一次（「已录音 20 秒」）。
- 触感：按下 light、进入录音 medium、锁定 light、保存 success、取消 light、失败 error。

### 4.3 文案

| 状态 | 提示行 |
| --- | --- |
| idle | 按住说松手存 · 轻点开始，再点结束 |
| starting | 正在打开麦克风… |
| hold | 正在录音 · 松手保存，上滑取消（左侧计时） |
| locked | 已锁定 · 点一下结束（左侧计时） |
| cancelArmed | 松手取消 |
| saving | 正在保存… |
| 太短 | 太短了，再说一次 |
| 自动保存 | 录音已停止并保存 |

## 5. 首次录音告知

- 未同意时首次按录音先出底部 Sheet，不启动麦克风；同意后写入 `localStorage["sidekick:memo:privacy"]`（`{v:1, at}`）并以锁定态开始。
- 文案三条：① 录音发送到百炼做识别与整理；② 原始录音默认存本机，可在设置关掉；③ 同一 Wi-Fi 且已配对时结果镜像到电脑，电脑只读。
- 用底部 Sheet 而不是居中 Dialog：WebView 103 不支持 CSS `translate` 属性，居中弹层会偏；Sheet 不依赖它。

## 6. 列表与详情

### 6.1 列表

- 只显示选中日：标题「11 月 8 日 · 周日」13/600 +「N 条」11.5 次要色。
- 行 60：类型色块 36×36（圆角 10）、标题 15/21 单行省略、meta 12/17（时间 · 时长 · 状态）、行尾 ›；未同步条目不额外重复。
- 处理中/失败/等待网络沿用状态色：失败珊瑚、等网络琥珀、处理中薄荷。
- 空态：无任何条目「还没有备忘录」+「点下面的麦克风，说一句就存下来。」；当天无条目「这一天还没有记录」+「点下面的麦克风，开始记一条。」
- 列表底部一个 12px「刷新」文本入口（录音中禁用）；页面进入、保存、`memo` 事件都会自动刷新。
- 保存后选中新条目的 `createdAt` 所在日（23:59 开始、00:01 结束算开始日）。

### 6.2 详情

- 顶部：类型胶囊（可点，三类选择）+ 标题（可点编辑）。
- 播放器、摘要、待办、全文；全文块头右侧「复制全文」（Clipboard API + textarea 回退，成功/失败 toast）。
- 底部操作：「删除录音」「删除这条备忘」；删除类二次确认（点一次变「再点一次」，2 秒超时复原）。

## 10. 无障碍与动效

- 录音按钮 `aria-label` 随状态切换：开始录音（按住说话/轻点开始）、松手保存上滑取消、已锁定点一下结束。
- 计时 `aria-live="polite"` 每 10 秒一次；锁定/太短/取消用 toast + 触感双通道。
- 日历每个日期是 `button`，`aria-pressed` + 完整 `aria-label`（含条数、今天/已选）；分段用 `aria-pressed`，组名「日历视角」。
- TalkBack：双击开始（锁定态）→ 双击保存，≤4 步；一次双击只改变一次状态（pointer 后 600ms 内合成 click 去重）。
- 动效：分段滑块 200ms；视图切换不整页跳；全部尊重 `prefers-reduced-motion`。
- 触感：录音 medium / 锁定 light / 保存 success / 失败 error（沿用 `haptic()`，不申请 VIBRATE）。

## 11. 降级与空态

- 数据库不可用：页面显示「本地数据打不开」+「重试」；不自动重建覆盖。
- 存储不足：录音按钮禁用 + 说明；已有条目可读。
- 列表加载中：3 行骨架（不闪白）。
- 同步关闭/未配对：不显示同步点，详情底部提示「配对后可同步到电脑」。
- 日历无记录：仍可切日、仍可录音；不显示插画。
