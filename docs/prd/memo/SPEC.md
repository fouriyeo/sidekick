# 语音备忘录 · SPEC

> 实现状态（2026-11-08）：S1 手机独立 + S2 局域网镜像代码完成，待真机联调；Key 暂存 App 私有文件（Keystore 列 P1），手机固定官方端点。技术细节与偏差见 `docs/engineering/memo-pipeline.md`。

> 只写「长什么样、怎么动、说什么话」。产品规则见 [PRD](./PRD.md)，验收见 [ACCEPTANCE](./ACCEPTANCE.md)。
> 视觉全部落在手机 `.mobile-clean` 与桌面 `.desktop-ios` 作用域内，不新增全局主题。

## 1. 手机信息架构

```text
宠物页（根）
 ├─ 顶栏：gear / 连接 / 今日用量 / [备忘录] / chat
 ├─ 备忘录页（全屏二级，新）
 │   ├─ 列表（今天 / 更早）
 │   ├─ 录音按钮（底部居中，64px）
 │   └─ 详情（从列表进入，全屏二级）
 └─ 设置（二级）→ 备忘录分组（保留录音 / 占用空间 / Key）
```

- 顶栏图标：16px 线性「便签」图形，与 chat 图标同描边粗细；命中区 44×44；`aria-label="备忘录"`。
- 320 宽下优先压缩今日用量数字与连接态文字，不隐藏图标；图标间距 ≥4px（真机 320 需走查）。
- 备忘录页页头：左「‹ 返回」、中标题「备忘录」17/400、右「设置」小字入口（进入设置 › 备忘录）。
- 页面切换用现有 push 动效（fade + 轻微位移），返回键回宠物页；录音中按返回即停止并保存（提示见 §5），不做后台录音。

## 2. 录音页布局

```text
┌──────────────────────────────┐
│ ‹  备忘录              设置   │
│                              │
│  今天                        │
│  ┌────────────────────────┐  │
│  │ 待办  买牛奶…      00:32│  │
│  └────────────────────────┘  │
│  更早                        │
│  …                           │
│                              │
│        00:12 · 2 片           │  ← 录音中才出现
│           ( ● )              │  ← 64px 圆按钮
└──────────────────────────────┘
```

- 列表为空时顶部留白，中间居中空态文案，不显示「今天/更早」分组标题。
- **仅前台录音**：切到其它 App / 锁屏会停止并保存（P1 才做后台服务与常驻通知）；录音期间保持屏幕常亮，停止即释放。
- 录音中：按钮变停止方块（白底深色图形），外圈薄荷呼吸环（1.6s，尊重 `prefers-reduced-motion` 时静止）；计时在按钮上方 12px。
- 处理中：按钮回到初始态；列表顶部插入一条「识别中 · 第 2/5 段」的占位行（不可点）。
- 录音按钮不使用 `left-1/2 -translate-x-1/2`（WebView 103 不支持 translate）。

## 3. 列表行

| 元素 | 规格 |
| --- | --- |
| 容器 | 白卡，圆角 16，左右 16，行高 ≥64，行间 8 |
| 类型标签 | 11px，圆角 4，备忘=薄荷底、待办=琥珀底、灵感=珊瑚底（低饱和） |
| 标题 | 15/21，单行省略 |
| 摘要 | 12/17，单行省略，次要色 |
| 底部 meta | 11/16：时间（今天显示 `HH:mm`，更早显示 `MM-DD`）· 时长 · 同步点 |
| 同步点 | 6px 圆点：已同步=薄荷、待同步=琥珀；不上传时无点 |
| 待办标记 | `todo` 类型在标题右侧显示「2 项」（11px 次要色） |

## 4. 详情页

- 顶部：类型胶囊（可点，弹出三类选择）+ 标题（可点编辑，单行输入）。
- 播放器：44 高胶囊，播放/暂停按钮 + 进度条 + `mm:ss / mm:ss`；进度条可拖动；播放时按钮图标切换。
- 摘要卡：标题「摘要」12/16 次要色，正文 14/21。
- 待办：只读 checklist 图标 + 文本（P0 不可勾选）；空则不显示整个块。
- 转写全文：默认折叠 3 行，点「展开」看全部；长按可选中复制。
- 底部操作：「复制全文」「删除录音」「删除备忘录」；删除类二次确认（点一次变「再点一次」，2 秒超时复原）。
- 处理失败：顶部一条错误条（浅珊瑚底）+「重试」；仍显示已完成部分的转写。

## 5. 状态与文案

| 状态 | 列表表现 | 文案 |
| --- | --- | --- |
| 录音中 | 不计入列表，页内计时 | `00:12 · 2 片` |
| 待识别 | 占位行 + 转圈 | 「等待识别」 |
| 识别中 | 占位行 + 进度 | 「识别中 · 第 2/5 段」 |
| 整理中 | 占位行 + 三点波 | 「正在整理…」 |
| 完成 | 正常行 | — |
| 等待网络 | 正常行 + 琥珀点 | 「等联网后识别」 |
| 失败 | 正常行 + 珊瑚点 | 「识别失败 · 重试」 |
| 同步中 | 行尾转圈 12 | 不显示百分比 |
| 已同步 | 薄荷点 | 长按显示「已在电脑」 |

关键文案（中文，全角标点）：

- 空态：「还没有备忘录。点下面的按钮，说点什么。」
- 首次录音告知：「录音会发送到百炼做识别与整理，只用于生成你的备忘录。」
- 权限拒绝：「需要麦克风权限才能录音。」+「去设置」
- 2 小时上限：「已到 2 小时上限，录音已保存。」
- 切走停止：「录音已停止并保存（需要保持 App 在前台）。」
- 中断恢复：「上次录音可能中断，已恢复 2 片。」
- 来电打断：「录音被系统打断，已保存。」
- 删除确认：「删除后不可恢复。」（第二次点为「确认删除」）
- Key 未配置：「先在电脑上发送 Key，或手动粘贴。」
- Key 失效：「Key 不可用，识别已暂停。」

## 6. 设置 › 备忘录

设置分组重排为 01 连接 / 02 外观 / 03 反馈 / 04 显示 / **05 备忘录** / 06 数据与关于 / 07 消息通道（只插入一组，其余顺延）：

| 行 | 控件 | 默认 |
| --- | --- | --- |
| 保留录音 | 开关 | 开 |
| 录音上限 | 只读说明「2 小时」 | — |
| 后台/锁屏录音 | 只读说明「暂不支持（P1）」 | — |
| 占用空间 | 只读「音频 128MB · 备忘 42 条」 | — |
| 百炼 Key | 状态「已配置 / 未配置」+ 进入 | — |
| 清理音频 | 操作（二次确认） | — |

Key 页：状态、掩码、「从电脑接收」（输入 6 位配对码）、「手动粘贴」、说明「Key 只存在本机；录音会上传百炼做识别」。

## 7. 桌面（一级页「备忘录 ⌘3」）

- 侧栏新增一级入口「备忘录 ⌘3」；页头 34/600「备忘录」，不带动画分段，不改 URL/导航。
- 备忘录列表：与剪贴板同款分组列表（54 行高），左侧类型色块 30×30，标题 15、副行 12、右侧时间与时长。
- 详情：只读 Dialog（560 宽，复用 Dialog 基元），含播放器、摘要、待办、全文与「电脑端只读；修改和删除请到手机上操作」；不提供编辑/删除。
- 空态：「手机还没同步过备忘录。在手机上录一条就会出现在这里。」
- 音频缺失：「音频不在本机（可能已被删除）。」

## 8. 降级与空态

- 数据库不可用：页面显示「本地数据打不开」+「重试」；不自动重建覆盖。
- 存储不足：录音按钮禁用 + 说明；已有条目可读。
- 列表加载中：3 行骨架（不闪白）。
- 同步关闭/未配对：不显示同步点，详情底部提示「配对后可同步到电脑」。

## 9. 无障碍与动效

- 录音按钮 `aria-label` 随状态切换（开始录音/停止录音）；计时用 `aria-live="polite"`，每 10 秒播报一次，避免每秒打扰。
- 播放器按钮可键盘聚焦（桌面）；进度条支持方向键 ±5 秒。
- 动效复用 `shared/ui/motion`：识别中 `LoadingOrbit`、整理中 `LoadingDots`、失败 `HintError`、完成 `HintCheck`；全部尊重 `prefers-reduced-motion`。
- 触感：开始/停止录音 medium；识别完成 success；失败 error（沿用 `haptic()`，不申请 VIBRATE）。
