# 外设麦克风 · 体验规格

> 本文回答“按钮在哪、状态怎么变、失败看到什么”。产品规则见 [PRD.md](./PRD.md)；技术方案见 [engineering/audio-pipeline.md](../../engineering/audio-pipeline.md)。
> 手机只做横屏；桌面只做不抢焦点的小浮窗。

## 1. 手机布局

### 1.1 支架模式

```text
┌────────────────────────────────────────────────────┐
│  [设置]                                  [连接点]   │
│                                                    │
│                  ╭──────────────╮                  │
│                  │   宠物舞台    │                  │
│                  ╰──────────────╯                  │
│                                                    │
│              ┌────────────────────┐                │
│              │  🎤  按住说话       │                │
│              └────────────────────┘                │
│  ─────────────── 安全区 ───────────────             │
└────────────────────────────────────────────────────┘
```

- 胶囊：宽 ≥220dp、高 72dp；底部安全区上方 16dp；水平居中。
- 按住后胶囊扩展为录音条：波形 + 计时 + “上滑取消”。
- 无操作 5 秒，设置/连接点淡出，胶囊保留但降低对比；按下恢复。

### 1.2 手持模式

```text
┌────────────────────────────────────────────────────┐
│  [设置]                                            │
│                  ╭──────────────╮                  │
│                  │   宠物舞台    │                  │
│                  │  （上 2/3）   │                  │
│                  ╰──────────────╯                  │
│  [取消]                                  ( 🎤 )    │
│  ─────────────── 安全区 ───────────────             │
└────────────────────────────────────────────────────┘
```

- 麦克风圆形按钮：直径 96dp，右/底安全区 24dp。
- 取消按钮：左下，≥64dp；仅录音时出现。
- 录音条替代宠物下方空白：波形 + 计时；不遮挡宠物。
- 设置图标常显但低对比。

### 1.3 录音覆盖层

```text
┌──────────────────────────────────────────┐
│  ● 正在听   00:07        ↑ 上滑取消       │
│  ▁▃▅▇▅▃▁▂▄▆▄▂▁  （波形）                 │
└──────────────────────────────────────────┘
```

- 始终可见：录音指示（脉冲点）、计时、取消提示、波形。
- 波形只做视觉反馈，不用于判断音量是否合适；不做“音量太小”的实时指责。
- 取消区高亮：上滑 ≥48dp 后，背景变珊瑚色 + 文案“松手取消”。
- 计时用 tabular numbers；50 秒后变琥珀色并轻震。

## 2. 状态机

### 2.1 状态

| 状态 | 含义 | 允许的下一步 |
| --- | --- | --- |
| `idle` | 可录音 | arming / error |
| `arming` | 按下后等待权限/音频就绪（≤3s） | listening / error |
| `listening` | 正在录音 | processing / cancelled / error |
| `processing` | 松手后等待转写（≤10s） | delivered / error |
| `delivered` | 已输入或已复制 | idle（卡片 10s 后消失） |
| `cancelled` | 用户取消/后台中断 | idle |
| `error` | 失败 | idle / arming（再说一次） |

### 2.2 转移

| 从 | 事件 | 到 | 反馈 |
| --- | --- | --- | --- |
| idle | 按下 | arming | 按钮收缩、轻震 |
| arming | 音频就绪 | listening | 波形 + 计时 + 脉冲点 |
| arming | 权限被拒/采集失败 | error | 错误文案 + 设置引导 |
| listening | 松手（非取消区） | processing | “转写中…” + 禁止再次录音 |
| listening | 上滑到取消区并松手 | cancelled | “已取消” + 轻震 |
| listening | <300ms 误触 | idle | “按住说话” |
| listening | 后台/来电/失焦 | cancelled | 回来提示“已取消” |
| listening | 60 秒上限 | processing | “到 1 分钟了，先转这段” |
| processing | 成功输入 | delivered | 对勾 + “已输入” + 卡片 |
| processing | 仅复制 | delivered | “已复制到电脑” + 卡片 |
| processing | 失败/超时 | error | 人话 + “再说一次” |
| delivered | 10 秒 | idle | 卡片淡出 |
| error | 点“再说一次” | arming | 重新录音，不复用音频 |

### 2.3 状态优先级

1. 权限/连接错误 > 录音状态 > 宠物情绪。
2. 录音中不切姿态、不弹宠物气泡、不显示设置页。
3. 同一时间只允许一个会话；重复按下忽略。

## 3. 手势

| 手势 | 识别 | 结果 |
| --- | --- | --- |
| 按住 | pointerdown，保持 ≥300ms | 开始录音 |
| 松手 | pointerup，非取消区 | 停止并转写 |
| 上滑取消 | 录音中 dy ≤ -48dp | 进入取消区；松手取消 |
| 滑回 | 取消区内 dy 回到 > -24dp | 退出取消区，继续录音 |
| 快速点按 | <300ms | 不录音，提示“按住说话” |
| 双击/长按菜单 | 不识别 | 无 |
| 多指 | 只认第一根 | 第二根忽略 |

- 取消区阈值 48dp；回退阈值 24dp，避免边界抖动。
- 录音中不响应宠物触摸；麦克风按钮优先。
- 所有手势同时支持大按钮点击替代，方便无障碍。

## 4. 视觉反馈

| 状态 | 主视觉 | 辅助 | 禁止 |
| --- | --- | --- | --- |
| idle | 麦克风按钮 + “按住说话” | 连接状态点 | 红色常亮 |
| arming | 按钮收缩 + 轻震 | “准备中…” | 无反馈空白 |
| listening | 波形 + 计时 + 脉冲点 | “上滑取消” | 只变色不显示文字 |
| cancel zone | 珊瑚背景 + “松手取消” | 轻震 | 无提示直接取消 |
| processing | 三点/旋转 + “转写中…” | 禁用按钮 | 允许再次录音 |
| delivered | 对勾 + “已输入/已复制” | 卡片 + 轻震 | 自动消失无确认 |
| error | 图标 + 一句人话 + 按钮 | 重试/设置 | 堆栈/错误码 |

- 录音指示用脉冲点 + 文案，不只靠颜色。
- 波形用 CSS/Canvas 轻量绘制，不做高开销滤镜。
- 成功卡片最多 2 行；展开后显示全文与“复制”。
- 错误不自动消失，直到用户操作或 5 秒后回到 idle（保留可重试入口）。

## 5. 桌面浮窗

```text
┌──────────────────────────────┐
│  ● 正在听  00:07             │
└──────────────────────────────┘
┌──────────────────────────────┐
│  … 转写中                    │
└──────────────────────────────┘
┌──────────────────────────────┐
│  ✓ 已输入 · ⌘Z 撤销          │
└──────────────────────────────┘
```

- 位置：右上角，避开菜单栏/Dock；宽 ≤320dp，高 48–64dp。
- 不抢焦点、不激活、不挡当前输入；用户正在别的应用里时也能看到。
- 状态：倾听中（计时）、转写中、已输入、已复制、失败。
- 完成 2 秒后收起；失败保留 5 秒；可点击查看详情（可选）。
- 不显示完整转写（避免泄露）；只显示状态和字数桶。
- 目标窗口变化/密码框时显示“已复制”，不显示“已输入”。

## 6. 权限流程

### 6.1 手机麦克风

```text
首次按下
  → 说明页：只在按住时录 / 松手即停 / 不保存音频
  → 用户点“继续”
  → 系统权限弹窗
  → 允许：开始录音
  → 拒绝：错误页 + “去系统设置”
```

- 说明页不超过 3 行；不默认勾选任何东西。
- 拒绝后不重复弹系统弹窗；每次按下走引导页。
- 系统设置入口尽量直达应用权限页；做不到就给步骤。

### 6.2 桌面辅助功能

```text
首次“自动粘贴”
  → 说明：需要辅助功能权限，把文字输入到当前应用
  → 打开系统设置
  → 允许：自动粘贴
  → 拒绝/未开：仅复制 + 提示
```

- 权限被拒不影响录音和转写，只影响自动输入。
- 设置页提供“重新授权”和“测试输入”按钮。
- 不诱导用户关闭安全设置；不绕过系统权限。

## 7. 文案

| 场景 | 文案 |
| --- | --- |
| 空闲 | “按住说话” |
| 准备中 | “准备中…” |
| 倾听 | “正在听” |
| 取消区 | “松手取消” |
| 转写中 | “转写中…” |
| 已输入 | “已输入” |
| 已复制 | “已复制到电脑” |
| 误触 | “按住说话。” |
| 未连接 | “先连接电脑，再按住说话。” |
| 麦克风权限拒绝 | “需要麦克风权限才能说话。去系统设置打开。” |
| 辅助功能未开 | “已复制。要自动输入，请允许 Sidekick 的辅助功能。” |
| 目标窗口变化 | “你切到了别的窗口，文字已复制。” |
| 密码框 | “当前是密码框，已复制，未自动输入。” |
| 没听清 | “没听清，靠近一点再说一次。” |
| 网络断开 | “连接断了，这段没有发送。” |
| 电脑端超时 | “电脑端没回应，再说一次？” |
| 版本旧 | “电脑端需要更新才能接收语音。” |

禁止：错误码、堆栈、“操作失败”、“请重试”（无下一步）、责怪用户。

## 8. 宠物联动

| 麦克风状态 | 宠物表现 |
| --- | --- |
| arming | 抬头、看向用户 |
| listening | 竖耳、身体前倾、轻微呼吸；停止随机 idle |
| processing | 安静等待、偶尔眨眼 |
| delivered | 2 秒得意/开心 + 少量闪光；不出转写 |
| cancelled | 眨眼回 idle；不表达失望 |
| error | 歪头/耳朵下垂 1.5 秒；可出“没听清，再来一次？” |

宠物不遮挡录音条、波形、计时、取消按钮；录音中禁用宠物触摸。

## 9. 无障碍

- 麦克风按钮有可读标签：“按住说话，麦克风”。
- 状态变化用 `aria-live="polite"` 播报：“正在听”“转写中”“已输入”“没听清”。
- 录音指示不能只靠颜色/脉冲；必须有文字和计时。
- 支持减少动效：波形降为静态电平条，去掉脉冲动画，保留文字状态。
- 触控目标 ≥64dp；取消按钮与麦克风间距 ≥24dp，避免误触。
- 外部键盘/辅助功能可触发“开始/停止”替代手势。

## 10. 性能与实现约束

- 按下 → 视觉反馈 ≤100ms；状态切换不等待权限弹窗。
- 波形 60fps，但只动 transform/opacity；不做大面积 blur/shadow。
- 音频分片 100ms 级别；不因 UI 动画阻塞发送。
- 转写中超时 10 秒；期间不重复发送、不自动重录。
- App 后台立即停止；无后台任务。
- 桌面浮窗独立于主窗口，不抢焦点。
