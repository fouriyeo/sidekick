# 外设麦克风 · 体验规格

> 本文回答“按钮在哪、状态怎么变、失败看到什么”。产品规则见 [PRD.md](./PRD.md)；技术方案见 [engineering/audio-pipeline.md](../../engineering/audio-pipeline.md)。
> 手机端只支持竖屏；桌面只做不抢焦点的小浮窗。

## 1. 手机布局（竖屏）

### 1.1 麦克风胶囊

```text
┌──────────────────────────────────────────┐
│  [设置]                          [聊天 ●] │
│  ┌ 会话（可选）────────────────────────┐ │
│  │ 收起 1 条 / 展开 5 条                │ │
│  └─────────────────────────────────────┘ │
│              ╭──────────────╮            │
│              │   宠物舞台    │            │
│              ╰──────────────╯            │
│                                          │
│        [  🎙 按住说话  ]  ← 56px 胶囊     │
│  ─────────────── 安全区 ───────────────   │
└──────────────────────────────────────────┘
```

- 胶囊：高 56px、宽 `min(86vw,360px)`；底部安全区上方 16px；水平居中。
- 空闲：麦克风图标 + 「按住说话」/「先连接电脑」。
- 录音：胶囊宽度扩到 `min(90vw,420px)`，内部为脉冲点 + 计时 + 波形 + 「上滑取消 / 松手取消 / 即将超时」。
- 处理中：spinner + 「云端收尾…」+ 「百炼」。
- 覆盖层（实时文本/结果卡片）绝对定位在胶囊上方 12px，独立层，不撑宽容器、不移动按钮。
- 设置图标与聊天入口常显；界面元素常显，由自动变暗防烧屏。
- 手机锁定竖屏；不提供 docked/handheld 两套布局。

### 1.2 录音覆盖层

```text
┌──────────────────────────────────────────┐
│  ● 正在听   00:07  百炼    ↑ 上滑取消     │
│  ▁▃▅▇▅▃▁▂▄▆▄▂▁  （波形）                 │
│  帮我把这段异步的注释改成中文…（实时文本） │
└──────────────────────────────────────────┘
```

- 始终可见：录音指示（脉冲点）、计时、取消提示、波形（波形在胶囊内）。
- 来源徽标：`百炼`（云端唯一，不再区分本机）。
- 实时文本：最多 3 行、灰色；云端 50ms 节流更新，整体替换不追加。
- 云端录音时徽标旁显示“音频上传中”，让用户知道正在上传。
- 波形只做视觉反馈，不用于判断音量是否合适；不做“音量太小”的实时指责。
- 取消区高亮：上滑 ≥48dp 后，背景变珊瑚色 + 文案“松手取消”。
- 计时用 tabular numbers；50 秒后变琥珀色并轻震。

## 2. 状态机

### 2.1 状态

| 状态 | 含义 | 允许的下一步 |
| --- | --- | --- |
| `idle` | 可录音 | arming / error |
| `arming` | 按下后等待权限/音频就绪（≤3s） | listening / error |
| `listening` | 正在录音 | processing / cancelled / error |
| `processing` | 松手后等待转写（≤10s） | delivered / error |
| `delivered` | 已输入或已复制 | idle（卡片 10s 后消失） |
| `cancelled` | 用户取消/后台中断 | idle |
| `error` | 失败 | idle / arming（再说一次） |

### 2.2 转移

| 从 | 事件 | 到 | 反馈 |
| --- | --- | --- | --- |
| idle | 按下 | arming | 按钮收缩、轻震 |
| arming | 音频就绪 | listening | 波形 + 计时 + 脉冲点 |
| arming | 权限被拒/采集失败 | error | 错误文案 + 设置引导 |
| listening | 云端 result-generated | listening | 实时文本更新；不落字 |
| listening | 松手（非取消区） | processing | “转写中…” + 禁止再次录音 |
| listening | 上滑到取消区并松手 | cancelled | “已取消” + 轻震 |
| listening | <300ms 误触 | idle | “按住说话” |
| listening | 后台/来电/失焦 | cancelled | 回来提示“已取消” |
| listening | 60 秒上限 | processing | “到 1 分钟了，先转这段” |
| processing | 成功输入 | delivered | 对勾 + “已输入” + 卡片 |
| processing | 仅复制 | delivered | “已复制到电脑” + 卡片 |
| processing | 失败/超时 | error | 人话 + “再说一次” |
| delivered | 10 秒 | idle | 卡片淡出 |
| error | 点“再说一次” | arming | 重新录音，不复用音频 |

### 2.3 状态优先级

1. 权限/连接错误 > 录音状态 > 宠物情绪。
2. 录音中不切页面、不弹宠物气泡、不显示设置页；录音中按钮位置固定。
3. 同一时间只允许一个会话；重复按下忽略。

## 3. 手势

| 手势 | 识别 | 结果 |
| --- | --- | --- |
| 按住 | pointerdown，保持 ≥300ms | 开始录音 |
| 松手 | pointerup，非取消区 | 停止并转写 |
| 上滑取消 | 录音中 dy ≤ -48dp | 进入取消区；松手取消 |
| 滑回 | 取消区内 dy 回到 > -24dp | 退出取消区，继续录音 |
| 快速点按 | <300ms | 不录音，提示“按住说话” |
| 双击/长按菜单 | 不识别 | 无 |
| 多指 | 只认第一根 | 第二根忽略 |

- 取消区阈值 48dp；回退阈值 24dp，避免边界抖动。
- 录音中不响应宠物触摸；麦克风按钮优先。
- 开始/停止可用大按钮点击替代，方便无障碍；取消只走上滑手势（不设独立取消按钮），TalkBack/VoiceOver 的取消动作放 P1 补。

## 4. 视觉反馈

| 状态 | 主视觉 | 辅助 | 禁止 |
| --- | --- | --- | --- |
| idle | 麦克风按钮 + “按住说话” | 连接状态点 | 红色常亮 |
| arming | 按钮收缩 + 轻震 | “准备中…” | 无反馈空白 |
| listening | 波形 + 计时 + 脉冲点 + 实时文本 | 百炼徽标 + “上滑取消” | 只变色不显示文字 |
| cancel zone | 珊瑚背景 + “松手取消” | 轻震 | 无提示直接取消 |
| processing | 三点/旋转 + “转写中…”/“云端收尾…” | 保留最后实时文本 | 允许再次录音 |
| delivered | 对勾 + “已输入/已复制” | 卡片 + 来源 + 轻震 | 自动消失无确认 |
| error | 图标 + 一句人话 + 按钮 | 重试/设置 | 堆栈/错误码 |

- 录音指示用脉冲点 + 文案，不只靠颜色。
- 波形用 CSS/Canvas 轻量绘制，不做高开销滤镜。
- 成功卡片最多 2 行；展开后显示全文与“复制”。
- 错误不自动消失，直到用户操作或 5 秒后回到 idle（保留可重试入口）。

## 5. 桌面浮窗

```text
┌──────────────────────────────┐
│  ● 正在听  00:07  百炼        │
│  帮我把这段异步的注释…        │
└──────────────────────────────┘
┌──────────────────────────────┐
│  … 转写中                    │
└──────────────────────────────┘
┌──────────────────────────────┐
│  ✓ 已输入 · ⌘Z 撤销          │
└──────────────────────────────┘
```

- 位置：右上角，避开菜单栏/Dock；宽 ≤380dp，高 48–96dp（有实时文本时）。
- P0 为桌面应用内浮层；独立 always-on-top 小窗放 P1。
- 不抢焦点、不激活、不挡当前输入；用户正在别的应用里时也能看到（应用在前台时）。
- 状态：倾听中（计时 + 百炼徽标 + 实时文本）、转写中、已输入、已复制、失败。
- 完成 2 秒后收起；失败保留 5 秒；可点击查看详情（可选）。
- 不显示完整转写（避免泄露）；只显示状态和字数桶。
- 目标窗口变化/密码框时显示“已复制”，不显示“已输入”。
- 桌面「模型」页管理百炼配置与用量；「设置」只保留自动输入权限与剪贴板。见 [asr-model.md](../../engineering/asr-model.md)、[asr-cloud-bailian.md](../../engineering/asr-cloud-bailian.md)。

### 5.1 模型页：百炼配置与用量

- 位置：桌面主导航「聊天 / 剪贴板 / AI 联动 / **模型**」，模型在 AI 联动之后；设置 Sheet 只保留自动输入权限与剪贴板。
- 配置字段：完整服务地址（北京/新加坡快捷按钮；业务空间直接粘贴完整 URL，无独立 ID 字段）、API Key（密码框/掩码/清除）、模型（默认 `qwen-audio-3.1-asr-flash-streaming`）、语言（中文/自动/中英）、场景（近场/远场）、高级（静音断句 800ms、热词每行一个权重 5）。
- 隐私同意：未勾选“录音会发送到阿里云百炼”不能保存；文案说明“电脑直连百炼，不经过 Sidekick 服务器；录音不保存”。
- 操作：`测试连接`（握手 + 320ms 静音，显示延迟/错误）、`保存`、`清除 Key`；保存成功显示“已配置”。
- 状态：未配置 / 已配置（显示模型 + Key 掩码，来自本地 `apiKey` 派生的 `keyPresent`/`keyHint`，不读 Keychain）；测试结果显示延迟/模型/中文错误。
- 用量：segmented control 今天/近 7 天/近 1 个月/近 1 年；只展示当前区间一张汇总卡（金额、总/输入/输出 Token、会话、音频时长）；今天无明细，7/30 按天，1 年按自然月；`priceNote`；`清空统计` 二次确认（只重置本地统计文件，不影响配置/Key）。
- 金额：人民币微元转元显示；0 为 `¥0.00`，不足 1 分 4 位小数，其余 2 位。

## 6. 权限流程

### 6.1 手机麦克风

```text
首次按下
  → 说明页：只在按住时录 / 松手即停 / 不保存音频
  → 用户点“继续”
  → 系统权限弹窗
  → 允许：开始录音
  → 拒绝：错误页 + “去系统设置”
```

- 说明页不超过 3 行；不默认勾选任何东西。
- 拒绝后不重复弹系统弹窗；每次按下走引导页。
- 系统设置入口尽量直达应用权限页；做不到就给步骤。

### 6.2 桌面辅助功能

```text
首次“自动粘贴”
  → 说明：需要辅助功能权限，把文字输入到当前应用
  → 请求权限/打开系统设置
  → 允许：自动粘贴
  → 拒绝/未开：仅复制 + 提示
```

- 权限被拒不影响录音和转写，只影响自动输入。
- 设置页提供“重新授权 / 重新检测 / 在 Finder 中显示当前程序”。
- 不诱导用户关闭安全设置；不绕过系统权限。
- 授权后只合成 `Cmd+V`，不发送回车/提交快捷键。

## 7. 文案

| 场景 | 文案 |
| --- | --- |
| 空闲 | “按住说话” |
| 准备中 | “准备中…” |
| 倾听 | “正在听” |
| 取消区 | “松手取消” |
| 转写中 | “转写中…” |
| 已输入 | “已输入” |
| 已复制 | “已复制到电脑” |
| 误触 | “按住说话。” |
| 未连接 | “先连接电脑，再按住说话。” |
| 麦克风权限拒绝 | “需要麦克风权限才能说话。去系统设置打开。” |
| 辅助功能未开 | “已复制。要自动输入，请允许 Sidekick 的辅助功能。” |
| 目标窗口变化 | “你切到了别的窗口，文字已复制。” |
| 密码框 | “当前是密码框，已复制，未自动输入。” |
| 没听清 | “没听清，靠近一点再说一次。” |
| 网络断开 | “连接断了，这段没有发送。” |
| 电脑端超时 | “电脑端没回应，再说一次？” |
| 云端未配置 | “云端还没配置，去电脑「模型」页填百炼地址和 API Key。” |
| 云端 Key 无效 | “百炼 API Key 无效或已过期，去电脑设置重新保存。” |
| 云端网络失败 | “连不上百炼，检查电脑网络。” |
| 版本旧 | “电脑端需要更新才能接收语音。” |

禁止：错误码、堆栈、“操作失败”、“请重试”（无下一步）、责怪用户。

## 8. 宠物联动

| 麦克风状态 | 宠物表现 |
| --- | --- |
| arming | 抬头、看向用户 |
| listening | 竖耳、身体前倾、轻微呼吸；停止随机 idle |
| processing | 安静等待、偶尔眨眼 |
| delivered | 2 秒得意/开心 + 少量闪光；不出转写 |
| cancelled | 眨眼回 idle；不表达失望 |
| error | 歪头/耳朵下垂 1.5 秒；可出“没听清，再来一次？” |

宠物不遮挡录音条、波形、计时、取消提示；录音中禁用宠物触摸。

## 9. 无障碍

- 麦克风按钮有可读标签：“按住说话，麦克风”。
- 状态变化用 `aria-live="polite"` 播报：“正在听”“转写中”“已输入”“没听清”。
- 录音指示不能只靠颜色/脉冲；必须有文字和计时。
- 支持减少动效：波形降为静态电平条，去掉脉冲动画，保留文字状态。
- 触控目标 ≥64dp；取消只走上滑手势（阈值 48dp），不设置与按住动作冲突的取消按钮；取消区要有文字与颜色双重反馈。
- 外部键盘/辅助功能可触发“开始/停止”替代手势。

## 10. 性能与实现约束

- 按下 → 视觉反馈 ≤100ms；状态切换不等待权限弹窗。
- 波形 60fps，但只动 transform/opacity；不做大面积 blur/shadow。
- 音频分片 100ms 级别；不因 UI 动画阻塞发送。
- 云端首条 partial 目标 ≤1.5s（从开口算）；松手→插入 p95 ≤3s。
- 转写中超时 10 秒；期间不重复发送、不自动重录。
- App 后台立即停止；无后台任务。
- 桌面浮窗独立于主窗口，不抢焦点。
