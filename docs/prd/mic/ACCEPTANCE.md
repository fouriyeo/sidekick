# 外设麦克风 · 验收清单

> 设备基线：Realme RMX3370 / Android 13（横/竖屏）+ macOS 13.3+；可信局域网。

### 2.1 连续操作、松手与电脑端中断

| ID | 优先级 | 类型 | Given | When | Then |
| --- | --- | --- | --- | --- | --- |
| MIC-AC-40 | P0 | 异常 | idle | 快速连续点按/连按「按住说话」，含启动中松手后立刻再按 | 任一时刻最多一个有效会话；电脑端最多一条「正在听」，松手后结束；不出现两端 session 不一致 |
| MIC-AC-41 | P0 | 边界 | `mic.start`/`getUserMedia` 尚未返回 | 松手 | 不进入录音；本地采集取消；电脑端若已收到 start，收到 cancel 后 1.5 秒内收起 |
| MIC-AC-42 | P0 | 功能 | 电脑端浮层显示「正在听」 | 点浮层「取消录音」 | 1 秒内两端回 idle；不转写、不插入、不写剪贴板；手机提示「电脑端已取消录音。」 |
| MIC-AC-43 | P0 | 异常 | 手机停止消息丢失/WebView 卡死 | 等待到 `maxMs + 3s` | 服务端看门狗自动中止会话；浮层提示「录音超时，已自动停止。」；不插入、不记正式结果 |
| MIC-AC-44 | P1 | 兼容 | 同一手机重复 `mic.start` | 观察 | 以最新会话为准，旧会话收到 cancelled；另一客户端连发仍回 `session_busy` |

## 10. 执行说明

- 每条记录：设备、系统、姿态、网络、权限状态、结果、截图/录屏、延迟数值。
- 延迟测量至少 20 次，取 p50/p95；区分 5 秒/10 秒/30 秒语音。
- 隐私检查用文件管理器 + 抓包；不得只看 UI。
- 安全用例必须实际把光标放到密码框、切换窗口、无输入框三种场景。
- P0 全过才可发版；P1 失败记录 issue 和影响范围。
- 云端用例需真实百炼账号 + 本地 Key；未配置时先验 CLOUD-1/MODEL-1 的明确报错路径。
- 发现规则冲突，先改 PRD/SPEC，再改实现；不要只改测试。
