# 外设麦克风 · 一页摘要

> 手机当电脑的无线麦克风：按住说话，松开后文字出现在电脑当前光标处。
> 本期定位：**AI 语音输入**。不做系统级虚拟麦克风（会议/录音软件）。

## 本期做什么

- 从宠物界面一键进入；未连接时引导连接。
- 按住说话、上滑取消、最短/最长时长、后台立即停止。
- 手机麦克风权限、桌面辅助功能权限的说明与降级。
- 桌面百炼云端流式转写（唯一）；显式同意、未配置直接报错、失败不回退；默认自动粘贴，失败/不安全时仅复制。
- 桌面「模型」页配置百炼（无业务空间 ID）并区间切换查看今天/7/30/365 Token/金额。
- **绝不自动按回车、绝不自动发送**。
- 手机端状态反馈 + 最近一次转写卡片。
- 桌面端不抢焦点的小浮窗状态。
- 横屏双姿态：支架模式底部胶囊、手持模式底部居中大按钮（取消只走上滑）。

## 不做什么

- 不做系统级虚拟麦克风/会议麦克风（P2）。
- 不做本机/离线转写、多厂商；百炼是唯一引擎。
- 不做后台录音、不做录音历史、不做音频落盘。
- 不做语音指令/格式化/多语言（P1）。
- 不做手机端聊天主界面。

## 成功标准

- 松手 → 文本出现在目标应用：p50 ≤1.5s，p95 ≤3s（≤10 秒语音）`[假设]`。
- 云端首条 partial ≤1.2s；云端 30 句字符准确率 ≥95% `[假设]`。
- 按下 → 倾听反馈 ≤100ms。
- 一次成功率（无需手动大改）≥80% `[假设]`。
- 周均成功语音输入 ≥10 次/活跃设备 `[假设]`。
- 原始音频落盘 0；自动回车/发送 0；错误目标应用 0。

## 平台

- 手机：采集、按住说话、状态反馈、权限。
- 桌面：接收、百炼转写、文本输入、状态浮窗、模型页/用量、辅助功能权限。
- 共享：协议类型、连接状态；不共享页面布局。

## 已定决策

- 本期只做 AI 语音输入，系统虚拟麦克风后置（D21）。
- 语音识别只走百炼云端（D56）；本机 whisper 已下线。
- 只输入文本，绝不自动回车/发送（D25）。
- 横屏双姿态：支架 + 手持（D22）；方向自动切换（D35）。
- 直接 CGEvent 自动粘贴，未授权只复制（D40）。
- 二进制音频协议 + 单会话；音频不广播（D42）。
- 桌面「模型」页管理百炼配置与用量；设置 Sheet 只留自动输入/剪贴板（D56）。
- 百炼云端流式识别：桌面中转、Keychain、显式同意、失败直接报错、`mic.partial`（D55）；下线本机/新增用量统计（D56）。
