# 应用外壳（指挥舱）· 一页摘要

> 两端应用「怎么装、怎么走、状态怎么说」——桌面 6 视图（含 2026-11-06 新增「用量」）+ 手机两页壳，以及连接 / AI / 麦克风三套状态词。
> 本期定位：**只重排承载与入口，不改功能行为**。宠物、麦克风、AI 联动的规则仍在各自 PRD。
> 决策：D79（2026-11-05，采用方向 A「指挥舱」）。

## 本期做什么

- 桌面：一级 6 视图（总览 / 会话 / 内容 / **用量** / 系统 / 设置，D82）+ 顶部 48 全局状态条 + 72 图标导航（⌘1–⌘6）+ 56 页头；用量规则见 [usage PRD](../usage/PRD.md)；聊天降级为「系统 › 消息」；辅助功能提示条外壳级；麦克风浮层全局；默认首页 = 总览。
- 手机：顶部 44 状态条 + 宠物根页 + 设置二级页 + 二级页 asking / chat / usage / offline / scan + 麦克风胶囊 56；用量从「设置 › 用量」进入（D82）。
- 状态语言：连接 7 态、AI 4 态、麦克风 9 态、会话行工具动作（D78）；琥珀只给「等你决定」；会话对象用「已完成」、AI 聚合用「完成」。
- 首用清单 4 步（连接 / 麦克风 / 百炼 / 辅助功能）；手机本地只验证前两步，后两步写「在电脑上完成」。
- 空态 / 错态统一结构：结论 + 下一步 + 主按钮 + 次按钮；不写「暂无数据」。

## 不做什么

- 不改宠物行为（D69/D77）、麦克风链路、AI 联动协议（D78）；本文件只定义它们的承载位置。
- 不新增协议字段：`asrConfigured`、精确手机台数、活动流持久化、手机批准/拒绝 AI 提问均为范围外（P1，见 [PRD](./PRD.md#8-范围外p1)）。
- 不写视觉令牌与配色：见 [standards/visual.md](../../standards/visual.md)。
- 不写通用触控 / 无障碍 / 返回键细则：见 [standards/ux.md](../../standards/ux.md)。

## 当前结论

- 桌面「状态即入口」：状态条的 3 段都能点（服务 / 手机 → 连接，AI → 会话）；任意页 ⌘1 回总览兜底。
- 手机「宠物是首屏」：宠物页 = 顶部条 + 会话卡（折叠 1 行 / 展开最多 5 行）+ 鲸鱼 + 圆麦克风；会话与 asking 都在宠物页处理，asking 有独立页（D80 删除动态页）。
- 一等入口只有 6 个（桌面）/ 2 页（手机）；配置与排障收进系统 / 更多，不再和主任务平级。
- 数据真实性：只展示协议能给出的字段；手机台数是 `clients - 1` 近似值，不显示设备名 / 延迟 / 心跳等虚构信息。
- 状态词两端同词同落点；颜色只是第二线索，文字与信号格始终在场。

## 维护规则

- 改导航、页面归属、状态词：先改本目录，再同步 [standards/ux.md](../../standards/ux.md) 与 [frontend-architecture.md](../../frontend-architecture.md)。
- 改功能行为：去对应功能 PRD（[pet](../pet/INDEX.md) / [mic](../mic/INDEX.md) / [hook](../hook/INDEX.md)），不要写进本目录。
- 协议字段变化：同步 [../protocol/README.md](../../../protocol/README.md) 与本目录 SPEC 的「数据来源」节。
- 新页面 / 新入口：必须同时补 PRD 页面清单、SPEC 骨架、ACCEPTANCE 用例三处，否则视为未完成。
