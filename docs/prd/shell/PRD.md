# 应用外壳（指挥舱）PRD

> **这篇解决什么**：两端应用「怎么装、怎么走、状态怎么说」——桌面 5 视图与手机两页壳的页面归属、全局状态条、导航、首用清单与状态语言。
> **读者**：产品 / 设计 / 前端 / 测试；实现落点见 [frontend-architecture.md](../../frontend-architecture.md)。
> **不含**：宠物 / 麦克风 / AI 联动的功能规则（各自 PRD 是唯一归属）、视觉令牌（[visual](../../standards/visual.md)）、协议实现（[engineering](../../engineering/INDEX.md)）。
> **状态**：2026-11-05 桌面部分随 D79 完成；手机部分按 D80 / v16 改为两页壳（宠物 + 设置），591 tests / tsc / lint / build 全绿，真机（Realme RMX3370）已验证宠物页 / 设置页 / 返回键；验收用例见 [ACCEPTANCE.md](./ACCEPTANCE.md)。

## 1. 背景与目标

- **背景**：现状桌面四角分散连接 / 手机 / AI / 服务状态，聊天被当成首页、配置藏在设置 Sheet；手机宠物页同时承担气泡 / 会话 / 连接 / 麦克风 / 设置 / 聊天六件事，用户判断是「不成体系」。2026-11-04 完成方向 A「指挥舱」原型与评审，用户选定 A（D79）。
- **目标**：任何页面都能在固定位置回答四个问题——**服务在不在、手机连没连、AI 在干什么、我下一步点哪**；主任务（按住说话 / 处理等你决定）≤1 次操作；配置与排障收进「系统 / 更多」，不再与主任务平级。
- **成功标准（试用判定）**：
  - 桌面首屏 3 秒内能读出四个问题中的至少三个；任一页 ⌘1 能回总览兜底。
  - 手机从宠物页按住说话不需要切页；会话卡直接显示「有没有等我」，不需要再进第二个页面。
  - 同一状态在两端、两页使用同一套词；不出现「已连接 / 连接成功 / 在线」三套说法。
  - 低频入口（消息 / 模拟状态 / 排障）不超过一级导航；没有为止损而新增的隐藏手势。

## 2. 范围与平台

| 项 | 桌面（macOS，1180×760，最小 960×640） | 手机（Android 竖屏，390×844 基准） |
| --- | --- | --- |
| 一级入口 | 5 个视图：总览 / 会话 / 内容 / 系统 / 设置 | 根页「宠物」；设置是二级页（gear 进入），无底部 tab |
| 全局状态 | 顶部 48 状态条三段（服务 / 手机 / AI） | 顶部 44 条（gear / 连接状态 / chat） |
| 全局浮层 | 麦克风浮层（右上、不抢焦点）；辅助功能提示条（外壳级） | 居中 56 圆麦克风 + 结果卡弹窗；首用清单在设置页 banner |
| 二级页 | 无独立路由；「系统」内 4 段 | settings / asking / chat / offline / scan 全屏页 |
| 默认首屏 | 总览 | 宠物 |
| 不做 | 跨端自适应、桌面渲染宠物、手机剪贴板历史 | 手机批准/拒绝 AI 提问；手机端任务看板 |

- 两端是独立固定布局，不写响应式断点；共享组件只共享无平台语义的部分。
- 功能行为不变：宠物仍按 D69/D77（无触摸互动、无舞台声呐环、不响应麦克风）；麦克风仍走百炼云端；AI 联动仍按 D78 只同步状态与工具类别。

## 3. 桌面壳规则

| 区域 | 规则 |
| --- | --- |
| 全局状态条 | 高 48，横跨导航右侧，跨页一致；三段 = 服务（`服务正常` + 端口副文；异常 `服务没起来`）/ 手机（`已连接 · N 台设备`，未连接为 `未连接`）/ AI（`空闲 / 工作中 / 等你决定 / 完成` + 当前会话标题）。三段都可点：服务、手机 → 系统 › 连接；AI → 会话。状态条是**状态即入口**，不是只读装饰。 |
| 图标导航 | 宽 72；图标 20 + 文字 9.5；项高 44；顺序固定：总览 / 会话 / 内容 / 系统 / 设置；「设置」与上面 4 项用分隔线隔开。 |
| 页头 | 高 56；标题 17/600 + 一句 12 状态副题；右侧**最多一个**主按钮（h 36 / px 14 / 13px）；其余动作为次级 / 幽灵按钮。 |
| 内容区 | 左右 padding 24；内容最大宽 880 居中；卡片间距 12 / 跨组 16；页内滚动，不做外框滚动。 |
| 系统页 | 页头下方固定 4 段（连接 → 语音 → 联动 → 消息）；每段是独立页面内容，共用系统外壳。 |
| 辅助功能提示条 | **外壳级**：macOS 未授权时所有桌面页都在状态条下方显示一条 40px 提示，带「去开启 / 知道了」；「知道了」只关本次，设置页仍可查。 |
| 麦克风浮层 | **全局**：任意页面右上角出现，宽 ≤320，不抢焦点、不挡输入；规则沿用 [ux.md](../../standards/ux.md) §11。 |
| 页脚 | 只放本页低频操作与版本号（如总览页脚 `小跟班 Sidekick · v0.1`）。 |
| 快捷键 | ⌘1–⌘5 切一级视图；焦点在输入框时不拦截。 |

- 一级导航只有 5 项；聊天（消息）不在导航一级，只能从「系统 › 消息」进。
- 所有路径的兜底是总览：任何页都能通过导航 / ⌘1 回到总览。
- 桌面设置是整页，不再用设置 Sheet；剪贴板的唯一归属是「内容」页，设置只留开关与「去内容页」链接。

## 4. 桌面页面清单

| 页面 | 目标 | 主行动 | 空态 | 错态 |
| --- | --- | --- | --- | --- |
| 总览 | 3 秒回答四问 | 按优先级只出现一个：连接手机 → 去看是谁在等 → 配置百炼 → 重试服务；都没有则不造按钮，写「现在没有要处理的事」 | 从未连接：手机段「还没连上手机」，「现在」卡说明开启联动后的效果，主按钮「连接手机」 | `server_info` 失败：服务段红 + 「服务没起来，重启 Sidekick 再试」+ 重试 |
| 会话 | 知道 AI 在做什么、谁在等 | 有 asking 时「处理第一个」；否则不出现 | 未开联动 → 「AI 联动还没开启」+「去开启」；已开未连 → 「等 DeepSeek Harness 启动」+「查看联动状态」 | 状态超过 15 秒没更新 → 顶部「AI 状态可能过期」+「刷新」 |
| 内容 | 找回最近复制的内容 | 无主按钮；主行动位放「暂停记录 / 继续记录」 | 「复制一段文字就会出现在这里」+ 隐私说明 | 搜索无结果 → 「没有匹配的记录，换个关键词」 |
| 系统 › 连接 | 让手机在 30 秒内连上 | 未连接时「展开二维码」；已连接后「继续添加设备」 | — | 获取连接信息失败 → 原因 + 重试；0 台时给三条真原因 |
| 系统 › 语音 | 配好百炼并知道花费 | 未配置时「保存配置」；已配置不造主按钮 | 未配置 = 阻塞态，顶部一行「语音输入还差这一步」 | 测试失败 → 原因 + 下一步；保存失败回滚 Key |
| 系统 › 联动 | 知道联动开没开、连没连上 | 按状态：未安装「开启联动」/ 已安装待重启无主按钮 / 出错「修复」 | — | 未安装、已断开、错误各有说明与修复入口 |
| 系统 › 消息 | 通道调试与双向消息 | 有草稿时「发送」 | 「还没有消息。这个页面用于排查通道」+ 去连接 / 去手机 | 未连接 → 输入禁用 + 「手机还没连上，先连接」 |
| 设置 | 外观 / 自动输入权限 / 剪贴板 / 关于与隐私 / 快捷键 | 无主按钮 | — | 权限未授权 → 说明 + 「去开启」；重新打包后授权失效的提示 |
| 麦克风浮层 | 知道手机在录音、结果去哪、能中断 | 浮层内的「取消录音」（仅倾听中） | — | 失败 / 已复制 / 超时都有原因行与下一步 |

- 每页固定四段（顺序不可变）：页头 → 状态区（仅总览 / 会话）→ 内容区 → 页脚工具（可选）。
- 总览「最近事件」最多 5 条，不把总览做成日志页；会话页才承载完整列表。
- 会话页行尾「在 DSH 打开」= 桌面本地 WS 发 `focus.request`（复用已有能力，无协议改动）；只对 asking 行出现。

## 5. 手机壳规则

| 区域 | 规则 |
| --- | --- |
| 顶部条 | 高 44；左 gear（44 热区 → 设置）；中间连接状态整块可点（5px 点 + 文字 → 连接页）；右 chat（44 热区 → 消息页）。 |

| 鲸鱼 | 无底色、无品牌小字；230（展开 220）居中偏下；不重绘、不染色、不加 filter。 |

| 屏幕常亮 | 只在宠物页前台生效（设置页打开时释放），由 [ux.md](../../standards/ux.md) §7 约束。 |

## 6. 手机页面清单

| 页面 | 目标 | 主行动 | 空态 | 错态 |
| --- | --- | --- | --- | --- |
| 宠物（首屏） | 一屏看到宠物 + 连接 + AI + 麦克风 | 按住说话 | 没有会话时整张会话卡不出现，不留空洞 | 存档失败 → 底部一行「这次记不住，下次再试。」；断连 → 麦克风「先连接电脑」 |
| 设置（更多） | 设置集中管理 | 无主按钮 | — | 保存失败行内红字 + 原因 |
| 等你决定 | 知道 AI 在等，并一键到电脑处理 | 「在电脑上继续」 | 无 asking → 自动回宠物页 | 唤起失败 → 「没打开，电脑上 DSH 在运行吗？」+ 重试；断连 → 禁用 +「先连接电脑」 |
| 消息 | 调试通道 | 「发送」 | 「还没有消息。这个页面是和电脑互发的调试通道」 | 断连 → 折叠块（倒计时 + 立即重连 + 重新搜索 + 手动地址 / 扫码文字入口）+ 输入禁用 |
| 连接 | 连上电脑；连不上时知道为什么 | 「扫码连接」 | 0 台 → 三条真原因（同一 Wi-Fi / 电脑端开着 / 防火墙允许）+ 扫码 / 手输 | 连接失败 → 原因 +「重新搜索」；Android 16+ 未授权 → 局域网权限说明 +「去设置」 |
| 扫码 | 扫电脑二维码完成连接 | 自动识别，无主按钮 | — | 没识别到 → 「对准电脑上的二维码再试」+ 手输；相机权限被拒 → 说明 + 手输 |

- 宠物页的会话卡折叠 1 行、展开最多 5 行；不跳第二个页面看完整列表。
- 宠物页不再有 AI 气泡/「现在」行/品牌小字；AI 状态由鲸鱼姿态 + 会话卡承担（录音不改变宠物）。
- 手机不显示剪贴板内容、不显示 AI 提问正文、不提供批准 / 拒绝。

## 7. 状态语言规则

逐字文案以 [SPEC.md](./SPEC.md#7-状态语言逐字表) 为准，本节只定规则：

1. **三线索**：每个状态 = 文字 + 3 格信号（3/2/1）+ 颜色；颜色只是第二线索，色弱也必须能读。禁止只有圆点 / 只有颜色。
2. **琥珀红线**：`--decide` 只给 AI「等你决定」；连接中 / 重连中 / 未连接 / 会话完成一律不用琥珀。
3. **对象 vs 聚合**：会话对象自己的状态用「已完成」（如会话卡行）；AI 聚合态（状态条、现在卡）用「完成」。
4. **两端同词**：连接、AI、麦克风三套词在桌面与手机完全一致；文案改动必须两端同时改（见 SPEC 表）。
5. **会话工作行（D78）**：工作中行 = spinner + 「正在<动作>」（8 类白名单：运行命令 / 阅读文件 / 修改文件 / 搜索代码 / 查资料 / 处理子任务 / 整理计划 / 使用工具）；无 `tool` 或未知值显示「正在思考」；行尾保留相对时间。不再出现笼统的「工作中」作为行内唯一信息。
6. **完成时长**：手机「完成」3 秒后回稳定态；桌面保留到下次状态变化；不跨后台 / 重连补播。
7. **连接 7 态**（服务在跑 / 服务异常 / 已连接 / 正在连接 / 正在重连 / 还没连上电脑 / 连接失败）各有固定文案，不得改写或缩写。

## 8. 范围外（P1）

| 项 | 为什么不做 | 需要什么 |
| --- | --- | --- |
| 手机显示「语音还没配置」（`asrConfigured`） | 现有 `status` 不携带桌面配置状态；手机只能等 `mic.error` | 协议新增可选字段 + 旧客户端忽略验证，单独排期 |
| 精确手机台数 / 设备名 | 服务端只知道连接总数，且含桌面本机窗口与网页预览 | 本轮用 `system.clients - 1` 近似，文案写「N 台设备」，不写设备名 |
| 活动流展示 | 「最近发生」在 D80 后不再有 UI（activity-store 保留） | 先只保留数据，是否恢复另评 |
| 手机批准 / 拒绝 AI 提问 | 协议不支持，且与隐私红线冲突（不外发提问正文） | 需要 hook 结果回传 + 新的安全设计，P1 另立 PRD |
| 桌面音效试听 | AI 音效开关与试听在手机「更多 → 反馈」；桌面不做（D79） | 如需要另评 |
| 深链 / 路由库 | 两端固定壳，视图切换用状态即可 | 有深链需求再单独决策（不引路由库） |

## 9. 与现有功能的契约

1. 外壳只决定「在哪里显示」，不改变宠物 / 麦克风 / AI 联动的内部状态机与隐私口径。
2. 宠物：仍按 D69 / D77——触摸无反应、舞台无声呐环、录音不改变宠物、done 循环；AI 四态展示不变。
3. 麦克风：按住说话、上滑取消、结果卡片、手动回车 / 清空仍按 [mic PRD](../mic/PRD.md)；桌面浮层不因换成新壳改变收起时长与安全规则。
4. AI 联动：仍按 [hook PRD](../hook/PRD.md) 与 D78——只同步状态、会话标题、工具类别、数量、时间；宠物页会话卡复用 `sessionList`，不新增外发字段。
5. 连接：连接状态仍是唯一事实源（[frontend-architecture.md](../../frontend-architecture.md) §5），所有页面读同一 store。
6. 首用清单的后两步只在电脑完成；手机不显示「已完成」，避免伪造状态。

- 1180×760 与 960×640 不溢出；390×844 / 360×800 / 300×800 不横向滚动。
- 不新增协议字段；如后续变化，先走 [decisions.md](../../decisions.md) 与协议文档。
