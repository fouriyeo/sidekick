# 应用外壳（桌面 Liquid Glass · iOS 26 + 手机两页壳）PRD

> **这篇解决什么**：两端应用「怎么装、怎么走、状态怎么说」——桌面 6 个一级入口 + 224 玻璃侧栏 + Liquid Glass 分组列表，与手机两页壳的页面归属、状态摘要、导航、首用清单与状态语言。
> **读者**：产品 / 设计 / 前端 / 测试；桌面实现契约见 [engineering/desktop-ios-ui.md](../../engineering/desktop-ios-ui.md)，前端落点见 [frontend-architecture.md](../../frontend-architecture.md)。
> **不含**：宠物 / 麦克风 / AI 联动 / 用量的功能规则（各自 PRD 是唯一归属）、视觉令牌细节（[visual](../../standards/visual.md)）、协议实现（[engineering](../../engineering/INDEX.md)）。
> **状态**：2026-11-06 桌面部分按 D85 结构重做、同日按 D86 升级为 Liquid Glass · iOS 26 质感层，并按 D104 把语音升为侧栏第 4 项「语音 ⌘5」、D123 把备忘录拆为独立一级页「备忘录 ⌘3」（语音单页三段、内部不 push；代码完成，待交互回归）；手机部分按 D80 / D81 两页壳（宠物 + 设置），591 tests / tsc / lint / build 全绿，真机（Realme RMX3370）已验证宠物页 / 设置页 / 返回键；验收用例见 [ACCEPTANCE.md](./ACCEPTANCE.md)。

## 1. 背景与目标

- **背景**：D79「指挥舱 A」在桌面留下 48 全局状态条 + 72 图标导航 + 6 个一级视图 + 系统页 4 段 + 56 页头，壳本身的框比内容还多；状态分散在状态条、会话页、系统段三处，会话列表页与概览重复。2026-11-06 用户要求按 iOS 的「干净、一眼」重做电脑端（与 D80 手机端同一方向），只重排承载与入口，不改功能行为。
- **目标**：任何页面都能在固定位置回答三个问题——**服务在不在、手机连没连、AI 在干什么**；主任务（看状态 / 取剪贴板 / 看用量 / 语音配置）≤1 次操作；低频配置与排障收进「设置」二级页，不再与主任务平级；**页面自己的功能配置留在该页**（语音、剪贴板，D104 / D119）。
- **成功标准（试用判定）**：
  - 桌面首屏 3 秒内能读出侧栏三行状态摘要与概览「当前会话」；任一页 ⌘1 能回概览兜底。
  - 手机从宠物页按住说话不需要切页；会话卡直接显示「有没有等我」，不需要再进第二个页面。
  - 同一状态在两端使用同一套词；不出现「已连接 / 连接成功 / 在线」三套说法。
  - 桌面上不出现说明句、mono 大写装饰与「暂无数据」；每条低频配置从设置首页 ≤2 次点击可达。

## 2. 范围与平台

| 二级页 | 设置内 push：手机连接 / AI 联动 / 自动输入 / 关于本机 / 消息通道（语音、剪贴板与备忘录都是一级页，不设二级页） | settings / memo / asking / chat / usage / offline / scan 全屏页 |

| 窗口 / 标题栏 | macOS 原生标题栏 Overlay + 隐藏标题；交通灯浮在侧栏顶部 38；sticky 玻璃工具栏是拖动区 | — |

- 两端是独立固定布局，不写响应式断点；共享组件只共享无平台语义的部分。
- 功能行为不变：宠物仍按 D69/D77（无触摸互动、无舞台声呐环、不响应麦克风）；麦克风仍走百炼云端；AI 联动仍按 D78 只同步状态与工具类别。

## 3. 桌面壳规则

| 区域 | 规则 |
| --- | --- |
| 窗口 / 拖动 | macOS `titleBarStyle: Overlay` + `hiddenTitle`；交通灯浮在侧栏顶部 38 区域内。**拖动区 = 侧栏顶部 38 + sticky 工具栏（含二级页返回行）**；交互元素不要放进拖动区作为唯一目标。 |
| 侧栏 224 | Liquid Glass 导航层（blur 30 / saturate 180 + 顶部受光）：38 交通灯区 → logo 22 + 「小跟班」15/600 → 概览 / 剪贴板 / 备忘录 / 用量 / 语音（项高 34、14/500、圆角 9、选中白色滑块 spring morph；语音未配置时右侧 6px 琥珀点）→ 弹性留白 → 设置 → 分隔线 + 三行状态摘要。 |
| 状态摘要 | 三行短值，每行 26 高、12 号：服务（真实端口 / 未启动）、手机（N 台 / 未连接）、AI（空闲 / 工作中 / 等你决定 / 完成 / 未联动）；色点 7px + 文字。服务与手机点按进「设置 › 手机连接」，AI 点按进「设置 › AI 联动」。 |
| 页头 / 滚动 | **sticky 玻璃工具栏**：未滚动时透明、只显示右侧动作组（二级页另有左侧「‹ 设置」返回）；滚动 > 6px 变玻璃胶囊（高 48 / 圆角 18）并淡入 17/600 紧凑标题；下方大标题 34/600、字距 -0.022em，随后滚走；不写说明句。二级页从右侧 push 进入。 |
| 内容区 | 分组灰底（画布带极淡薄荷 / 鲸蓝环境光）；左右 28 边距；内容最大宽 **730** 居中；页内滚动、单列；组与组间距 24。唯一例外：备忘录用 `PageShell size="wide"`（max-w 956）做宽幅两栏（D124）。 |
| 分组列表 | 组标题 13/400 次级灰、在卡外；**不透明白卡 16 圆角** + 双层阴影 + 顶部高光；行最小 54、左右 16、行标题 15/400、说明 13/400、hairline 0.5px 内缩 16（带图标块 60）；整行可点，右侧只有一个值或一个控件；卡尾动作行只用文字（如「在 DSH 打开」「清空历史」），不做实心按钮。 |
| 图标块 | 30×30 / 圆角 10 / 白字，7 个 iOS system color 按语义分配；不给 tone 时用 22 盒薄荷线性图标。 |
| 按钮 / 开关 / 输入 | 按钮是**胶囊**：36 / sm 30 / xs 26、13–14/500，一页最多一个实心薄荷；次级用玻璃填充，文字动作用薄荷或红色；工具栏相邻动作并进一个玻璃动作组。开关 40×24；输入 38 高 / 11 圆角 / 浅灰无边框；搜索是胶囊；确认操作用 dialog。 |
| 玻璃 / 材质 | **玻璃只做控件层**（侧栏 / 工具栏 / 动作组 / 分段轨道 / 辅助功能提示 / 弹层遮罩），内容卡、列表行、图表永远不透明；同心圆角、specular 高光、2.6% grain 与极淡环境光只做整体质感，不铺到内容层。 |
| 辅助功能提示 | 未授权时**只在概览页内容顶部**出现一行玻璃提示（`role="status"`，可关闭，带「去开启」）；「去开启」进「设置 › 自动输入」；授权后回到窗口自动收起，不占其它页布局。 |
| 麦克风浮层 | **全局**：任意页面右上角出现，宽 ≤320，不抢焦点、不挡输入；规则沿用 [ux.md](../../standards/ux.md) §11。 |
| 快捷键 | ⌘1–⌘7 切一级视图（概览 / 剪贴板 / 备忘录 / 用量 / 语音 / 设置 / 英语角）；焦点在输入框 / 下拉 / contentEditable 时不拦截。 |
| 动效 | 一级页 fade 320ms、二级页 push 340ms（不加过冲）；侧栏 / 分段滑块 spring（ζ 0.59、过冲 10%）；行 0.985 / 按钮 0.94 / checkbox 0.9 按压（按下 90ms、松手回弹）；弹层 320ms；手机结果卡 pop-in / 会话行错峰 / 麦克风钮与开关回弹。`prefers-reduced-motion` 关入场与缩放，`prefers-reduced-transparency` 玻璃退为实底卡。 |
| 文案 | 不写页面说明句、不复述标题含义、不放 mono 大写装饰、不写「暂无数据」；只有不可逆操作、隐私承诺、必须的输入提示可留一句。版本行写「0.1.0 · 简约 iOS」。 |

- 一级导航 6 项（语音、备忘录是独立一级页，不在设置里）；聊天（消息）不在导航一级，只能从「设置 › 消息通道」进。
- 所有路径的兜底是概览：任何页都能通过侧栏 / ⌘1 回到概览。
- 设置是「列表 → 二级页」的 iOS 结构：首页不承载配置表单，只有入口与一行短值（功能组：手机连接 / AI 联动）；**剪贴板是 ⌘2 一级页**（D119），**备忘录是 ⌘3 一级页**（D123，只读镜像），历史与设置（记录开关 / 密码框不记录 / `N / 100 条` / 清空）都在那一页，设置里没有剪贴板行与二级页。

## 4. 桌面页面清单

| 页面 | 目标 | 主行动 | 空态 | 错态 |
| --- | --- | --- | --- | --- |
| 概览 | 3 秒回答服务 / 手机 / AI | 页头玻璃动作组里只放「二维码」次级按钮，不造主按钮 | 服务未启动 = 「未启动」；AI 未联动 = 「没有开启联动」；无会话 = 「没有进行中的会话」；无语音 = 一行「还没有语音记录」 | `server_info` 失败：服务行「未启动」，去「设置 › 手机连接」重试 |
| 概览 › 当前会话 | 知道 AI 在做什么，并一键到电脑 | 卡尾「在 DSH 打开」 | 没有当前会话时整组不出现 | 唤起失败只提示错误，不重试循环 |
| 剪贴板 | 找回最近复制的内容、开关记录、调整保留条数、清空 | 无主按钮；页头玻璃动作组放 `N / M 条` 计数与「清空」；组标题「设置」下是记录开关、最多保留（20 / 50 / 100 / 200）与密码框不记录 | 一行「还没有记录」；搜索无结果一行「没有匹配的内容」 | 读取失败 → 一行错误原因 |
| 备忘录 | 在电脑上回听、看全文与摘要；只读镜像 | 无主按钮；页头 34/600「备忘录」；**宽幅两栏**（日历 300 + 当日列表，D124）；列表显示类型/标题/摘要/时间/时长，点开只读详情（摘要 / 待办 / 全文 / 播放 / 复制全文） | 一行「手机还没同步过备忘录。在手机上录一条就会出现在这里。」 | 读取失败 → 一行错误原因；手机未配对时列表为空 |
| 用量 | 看 Token / 花费 / 分组与价格 | 无主按钮；页头区间切换 + 刷新 | 账本缺失 → 一行结论 + 重试 | 读取失败 → 一行原因 + 重试；价格过期 → 卡尾「价格表 · 待更新」 |
| 设置 | 进入各配置入口 | 无主按钮 | — | — |
| 设置 › 手机连接 | 让手机在 30 秒内连上 | 二维码默认展开（白块 196 + 0.5px 细描边环 + 轻浮影），按钮在「二维码 / 收起二维码」间切换；另有「重新搜索」 | — | 获取连接信息失败 → 原因 + 重试；0 台时给三条真原因 |
| 语音（一级） | 配好百炼、管理关键词、知道花费 | 单页纵向三段（百炼配置 / 关键词列表 / 语音用量），内部不再 push；配置段未配置时「保存配置」 | 未配置 = 侧栏「语音」项 6px 琥珀点 + 配置段状态行「未配置」，表单直接可填，勾选同意后保存 | 测试失败 → 原因 + 下一步；保存失败回滚 Key；关键词保存失败给行号 |
| 设置 › AI 联动 | 知道联动开没开、连没连上 | 按状态：未安装「开启联动」/ 已安装待重启无主按钮 / 出错「修复」 | — | 未安装、已断开、错误各有说明与修复入口 |
| 设置 › 自动输入 | 让 macOS 辅助功能授权 | 「去开启」 | 未授权 = 说明 + 去开启（TCC 不能编程授权） | 重新打包后授权失效的提示 |
| 设置 › 关于本机 | 版本 / 平台 / 数据目录 / 隐私 / 快捷键 | 无主按钮；「隐私说明」开弹窗 | — | — |
| 设置 › 消息通道 | 通道调试与双向消息 | 有草稿时「发送」 | **全宽聊天区（无卡片）**：我方薄荷实心气泡（`bg-primary`）+ 对方白卡气泡（`--card-shadow`），系统事件居中小字；底部浮一条玻璃胶囊输入栏；空态一行「还没有消息」+「打开连接设置」 | 未连接 → 输入禁用、占位「服务未连接」 |
| 麦克风浮层 | 知道手机在录音、结果去哪、能中断 | 浮层内的「取消录音」（仅倾听中） | — | 失败 / 已复制 / 超时都有原因行与下一步 |

- 每页固定结构：sticky 页头 → 分组列表（概览多「当前会话」「语音输入」两组）；**没有页脚**；白卡不透明，玻璃只在工具栏 / 侧栏 / 动作组 / 弹层。
- 概览「当前会话」按 等你决定 → 工作中 → 已完成 取最高优先级一条；桌面不再有完整会话列表，完整信息在 DSH 里看。
- 「在 DSH 打开」= 桌面本地 WS 发 `focus.request`（复用已有能力，无协议改动），只在有当前会话时出现。

## 6. 手机页面清单

| 页面 | 目标 | 主行动 | 空态 | 错态 |
| --- | --- | --- | --- | --- |
| 宠物（首屏） | 一屏看到宠物 + 连接 + AI + 麦克风 | 按住说话 | 没有会话时整张会话卡不出现，不留空洞 | 存档失败 → 底部一行「这次记不住，下次再试。」；断连 → 麦克风「先连接电脑」 |
| 设置（更多） | 设置集中管理 | 无主按钮 | — | 保存失败行内红字 + 原因 |
| 等你决定 | 知道 AI 在等，并一键到电脑处理 | 「在电脑上继续」 | 无 asking → 自动回宠物页 | 唤起失败 → 「没打开，电脑上 DSH 在运行吗？」+ 重试；断连 → 禁用 +「先连接电脑」 |
| 消息 | 调试通道 | 「发送」 | 「还没有消息。这个页面是和电脑互发的调试通道」 | 断连 → 折叠块（倒计时 + 立即重连 + 重新搜索 + 手动地址 / 扫码文字入口）+ 输入禁用 |
| 连接 | 连上电脑；连不上时知道为什么 | 「扫码连接」 | 0 台 → 三条真原因（同一 Wi-Fi / 电脑端开着 / 防火墙允许）+ 扫码 / 手输 | 连接失败 → 原因 +「重新搜索」；Android 16+ 未授权 → 局域网权限说明 +「去设置」 |
| 扫码 | 扫电脑二维码完成连接 | 自动识别，无主按钮 | — | 没识别到 → 「对准电脑上的二维码再试」+ 手输；相机权限被拒 → 说明 + 手输 |

- 宠物页的会话卡折叠 1 行、展开最多 5 行；不跳第二个页面看完整列表。会话卡是浮层：展开只加高卡片、宠物不动；新完成自动展开并用薄荷色标出那一条，点它能切回电脑。
- 宠物页不再有 AI 气泡/「现在」行/品牌小字；AI 状态由宠物姿态 + 会话卡承担（录音不改变宠物）。
- 手机不显示剪贴板内容、不显示 AI 提问正文、不提供批准 / 拒绝。

## 7. 状态语言规则

逐字文案以 [SPEC.md](./SPEC.md#7-状态语言逐字表) 为准，本节只定规则：

1. **文字 + 颜色点**：每个状态 = 文字 + 颜色点；颜色只是第二线索，色弱也必须能读。禁止只有圆点 / 只有颜色。3 格信号只在手机消息页的连接强度处保留，桌面侧栏用色点。
2. **琥珀红线**：`--decide` 只给 AI「等你决定」；连接中 / 重连中 / 未连接 / 会话完成一律不用琥珀。
3. **对象 vs 聚合**：会话对象自己的状态用「已完成」（如概览当前会话行、手机会话卡行）；AI 聚合态（侧栏 AI 行、概览 AI 行）用「完成」。
4. **两端同词**：连接、AI、麦克风三套词在桌面与手机完全一致；文案改动必须两端同时改（见 SPEC 表）。
5. **会话工作行（D78）**：概览「当前会话」与手机会话卡的工作中行 = spinner + 「正在<动作>」（8 类白名单：运行命令 / 阅读文件 / 修改文件 / 搜索代码 / 查资料 / 处理子任务 / 整理计划 / 使用工具）；无 `tool` 或未知值显示「正在思考」；行尾保留相对时间。不再出现笼统的「工作中」作为行内唯一信息。
6. **完成时长**：手机「完成」3 秒后回稳定态；桌面保留到下次状态变化；不跨后台 / 重连补播。
7. **连接 7 态**：服务在跑 / 服务异常只出现在桌面（侧栏「服务」行与概览服务行，短值 = 真实端口 / 未启动）；已连接 / 正在连接 / 正在重连 / 还没连上电脑 / 连接失败是手机连接页的固定文案，不得改写或缩写。手机顶部条**连上时只显示信号塔图标**（状态不是主要信息，v17 / D93），没连上时用最短状态词（连接中 / 重连中 / 重连 Ns / 未连接），完整固定文案保留在 `aria-label`（读屏可达）与连接页。桌面手机行只用「N 台 / 未连接」，不另造「服务正常 / 服务没起来 / 正在重连」这类句子（连接中途状态属于手机）。
8. **状态过期**：手机超过 15 秒没有状态更新时提示「AI 状态可能过期 / 已断连，AI 状态可能过期」；桌面侧栏与概览只显示最后收到的真实值，不制造心跳读数。

## 8. 范围外（P1）

| 项 | 为什么不做 | 需要什么 |
| --- | --- | --- |
| 手机显示「语音还没配置」（`asrConfigured`） | 现有 `status` 不携带桌面配置状态；手机只能等 `mic.error` | 协议新增可选字段 + 旧客户端忽略验证，单独排期 |

| 桌面完整会话列表 | D85 删除会话列表页后，桌面只显示概览里最高优先级的一条；完整列表在 DSH | 重新评估会话列表的信息价值与位置，另立 PRD |
| 活动流展示 | 「最近发生」在 D80 后不再有 UI（activity-store 保留） | 先只保留数据，是否恢复另评 |
| 手机批准 / 拒绝 AI 提问 | 协议不支持，且与隐私红线冲突（不外发提问正文） | 需要 hook 结果回传 + 新的安全设计，P1 另立 PRD |
| 桌面音效试听 | AI 音效开关与试听在手机「更多 → 反馈」；桌面不做（D79） | 如需要另评 |
| 深链 / 路由库 | 两端固定壳，视图切换用状态即可 | 有深链需求再单独决策（不引路由库） |

## 9. 与现有功能的契约

1. 外壳只决定「在哪里显示」，不改变宠物 / 麦克风 / AI 联动 / 用量的内部状态机与隐私口径。
2. 宠物：仍按 D69 / D77——触摸无反应、舞台无声呐环、录音不改变宠物、done 循环；AI 四态展示不变。
3. 麦克风：按住说话、上滑取消、结果卡片、手动回车 / 清空仍按 [mic PRD](../mic/PRD.md)；桌面浮层不因换成新壳改变收起时长与安全规则。
4. AI 联动：仍按 [hook PRD](../hook/PRD.md) 与 D78——只同步状态、会话标题、工具类别、数量、时间；概览「当前会话」与手机会话卡复用 `sessionList`，不新增外发字段。
5. 用量：仍按 [usage PRD](../usage/PRD.md) 与 D82–D84、D93——桌面「用量」一级页 + 手机宠物页顶栏今日数字 → 用量页；不改账本 / 价格规则。
6. 连接：连接状态仍是唯一事实源（[frontend-architecture.md](../../frontend-architecture.md) §5），所有页面读同一 store。
7. 首用清单的 ③④ 由桌面通过 `desktop.status` 上报真实状态（百炼已配置 / 辅助功能已授权），手机据此显示「已完成」；旧桌面或未收到上报时显示「在电脑上完成」，不伪造状态（2026-11-06 起，取代「本轮不做跨端同步」）。
