# 应用外壳（指挥舱）SPEC

> 布局骨架、导航、状态词与首用清单的可执行规格；产品规则见 [PRD.md](./PRD.md)，验收见 [ACCEPTANCE.md](./ACCEPTANCE.md)。
> 视觉令牌只用 `app/src/shared/styles/tokens.css` 语义令牌；触控 / 无障碍通用规则见 [standards/ux.md](../../standards/ux.md)。
> 兼容底线：Android WebView 103——不用 `oklch` / `color-mix` / CSS `translate` 属性 / `dvh`；居中用 `inset-x-0` + flex 或 `left-0 right-0 mx-auto`。

## 2. 桌面壳骨架

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ [品牌] │ ● 服务在跑 · 47810 │ ● 已连接 · 1 台设备 │ ● 工作中 · 重构登录模块 │ [设置] │ ← 48
├────┬─────────────────────────────────────────────────────────────────────┤
│总览│ 页头 56：标题 + 一句状态 +（右侧最多一个主按钮）                      │
│会话│ ─────────────────────────────────────────────────────────────────── │
│内容│ 内容区：max-width 880 居中，页内滚动                                 │
│系统│  （系统页：页头下固定 4 段 segmented：连接 / 语音 / 联动 / 消息）     │
│    │                                                                     │
│ ── │                                                                     │
│设置│ 页脚：低频操作 + 版本（可选）                                         │
└────┴─────────────────────────────────────────────────────────────────────┘
  导航 72：图标 20 + 文字 9.5；顺序 总览 / 会话 / 内容 / 用量 / 系统 / 设置（⌘1–⌘6）
```

- **外壳级元素**：辅助功能提示条（状态条下方 40，未授权时常驻所有页）与麦克风浮层（右上，宽 ≤320，`.deep-sea-scope` 恒定深海）不属于任何单页，由壳统一渲染。
- 总览默认首页；聊天（消息）只在系统第 4 段；设置是整页，不再是 Sheet。
- 960 宽：内容区单列，间距降为 12；导航保持 72，不折叠成抽屉。

## 3. 桌面视图规格

| 视图 | 必须内容（自上而下） | 主行动 |
| --- | --- | --- |
| 总览 | ① 「现在」卡（AI 状态大字 + 当前会话标题 + 时间；asking 时琥珀左描边） ② 最近一次语音输入卡 ③ 最近事件 ≤5 条 ④ 这台电脑（`IP:端口` + 复制 + UDP 发现 + 连接手机） ⑤ AI 联动摘要（状态 + 最近心跳 + 打开联动设置） ⑥ 页脚版本 | 按 PRD §4 优先级只出现一个；没有则不造按钮 |
| 会话 | ① 筛选条（全部 / 等你决定 / 工作中 / 已完成，可点过滤） ② 会话列表（asking 置顶 + 琥珀左条；行 = 状态 + 标题 + 相对时间 + 行尾动作） ③ 页脚联动状态 | asking > 0 →「处理第一个」 |
| 内容 | ① 工具带（`N / 100 条` + 暂停记录 + 清空） ② 搜索框 ③ 列表（类型标签 + 摘要 + 时间 + 置顶 + hover 动作） ④ 页脚隐私说明 | 无；主行动位放暂停 / 继续记录 |
| 用量 | ① 4 个 KPI（总 Token / DSH 花费 / 缓存命中 / 调用·会话） ② 30 天花费柱阵 ③ 缓存环 + 构成 ④ Token 构成 ⑤ 分组卡（客户端 / 会话 / 模型） ⑥ 价格表入口与 Sheet | 无；页头区间切换 + 刷新 |
| 系统 › 连接 | ① 状态行（等待手机连接 / 已连接 N 台） ② 方式 01 自动发现（UDP 47820 监听状态） ③ 方式 02 扫码（默认折叠，展开 160×160 二维码） ④ 方式 03 手动地址 + 复制 ⑤ 排障折叠（三条真原因） ⑥ 页脚 `WS <端口> · UDP 47820` + 重新搜索 | 未连接「展开二维码」；已连接「继续添加设备」 |
| 系统 › 语音 | ① 页头状态 chip（已配置 / 还没配置） ② 未配置时阻塞提示 ③ 配置区（服务地址 / Key 掩码 + 替换 + 清除 / 模型 / 语言 / 场景 / 同意开关） ④ 测试连接 + 结果行 ⑤ 用量区（区间 + 4 指标 + 明细） ⑥ 隐私说明 | 未配置「保存配置」 |
| 系统 › 联动 | ① 页头主按钮（按状态） ② 状态卡（状态词 + 当前状态 / 会话数 / 最近心跳） ③ 启用开关 ④ profile 选择 ⑤ 当前会话预览 ≤5 行（点行 → 会话页） ⑥ 诊断折叠（模拟状态仅 DEV 可见、映射表、最近事件、写入位置、隐私说明） ⑦ 移除联动（destructive + 二次确认） | 按状态；其余不造主按钮 |
| 系统 › 消息 | ① 页头（消息 + 通道调试副题 + 清空） ② 消息列表（我方 / 对方 / 系统） ③ 输入框 + 发送 ④ 未连接时输入禁用 + 去连接 | 有草稿「发送」 |
| 设置 | ① 外观（跟随系统 / 浅色 / 深色，即时生效） ② 自动输入权限（状态 + 去开启） ③ 剪贴板（开关 + `N/100` + 去内容页 + 清空） ④ 关于与隐私（版本、数据目录、隐私弹窗） ⑤ 快捷键（⌘1–⌘6） | 无 |

- 空态统一结构：一句结论（14）+ 一句下一步（12 muted）+ 1 主按钮 + 1 次按钮；占满内容区，不弹 modal。
- 错态统一结构：发生了什么 + 下一步 + 主按钮（重试 / 去开启 / 去配置）+ 次按钮（查看详情）；位置替换内容区，不弹 modal。
- 页内不重复其他地方已承担的信息：用量不在总览、剪贴板列表不在设置、完整会话不在总览。

## 4. 手机壳骨架

```text
┌──────────────────────────────────────────────┐
│ [gear]      ● 已连接 · 局域网        [chat]   │ ← 顶部条 44
├──────────────────────────────────────────────┤
│  会话 4                                  ⌄   │ ← 白卡 16 圆角
│  ◌ QQ · 我觉得现在的 UI 还是…            ×   │
│    正在运行命令 · 1 小时前                    │
│  还有 3 条                              ···   │
│                                              │
│                  鲸鱼（230）                  │
│                                              │
│                  [ 56 圆麦克风 ]              │
└──────────────────────────────────────────────┘
```

- 没有底部 tab；设置从 gear 进、消息从 chat 进。录音中所有换页入口由 `ui-store.setView` 拦截，不切页。
- 会话卡折叠 1 行、展开最多 5 行；展开时鲸鱼从 230 收到 220，卡片不推动麦克风。
- 变暗遮罩、再按一次退出提示在麦克风上方独立层，不遮挡麦克风。
- 设置页是二级整页（非 sheet）；6 组顺序固定：连接 / 外观 / 反馈 / 显示 / 数据与关于（含重置宠物）/ 消息通道；首用清单 banner 在顶部。

## 5. 手机页面规格

| 页面 | 结构 | 主行动 | 关键状态 |
| --- | --- | --- | --- |
| 宠物 | 顶部条 → 会话卡（折叠/展开）→ 鲸鱼（无底色）→ 56 圆麦克风 | 按住说话 | 空闲 / 工作中 / 等你决定 / 断连 / 录音中 / 变暗 |
| 设置（更多） | 页头（返回 + 更多 17/400）→ 首用清单 banner → 6 组白卡 | 无 | 保存失败行内红字 |
| 等你决定 | 页头（等你决定 + DSH 已暂停）→ 会话标题 21 → 状态 + 提出时间 → 主按钮「在电脑上继续」→ 其他 asking 列表 ≤5 | 「在电脑上继续」 | 单条 / 多条 / pending / 成功 / 失败 / 断连 |
| 消息 | 页头（返回 + 消息 + 局域网直连 + 连接信号格）→ 消息列表 → 输入框 | 发送 | 已连接 / 空态 / 断连折叠块 / 发送中 |
| 连接 | 页头（连接 + 信号格）→ 状态卡 → 扫码主按钮 → 手动地址可展开 → 自动发现列表 → 重连行 → 上次地址 → 局域网权限提示 | 「扫码连接」 | 正在找 / 0 台 / N 台 / 连接失败 / 重连中 / 权限未授权 |
| 扫码 | 全屏取景 + 取景框 + 说明 + 关闭 | 自动识别 | 扫描中 / 连接中 / 没识别到 / 相机权限被拒 |

- 宠物页没有 AI 气泡 /「现在」行 / 品牌小字；AI 状态由鲸鱼姿态 + 会话卡承担。
- 手机不显示剪贴板内容与 AI 提问正文；点 asking 只发 `focus.request`，不提供批准 / 拒绝。

## 7. 状态语言逐字表

### 7.1 连接（7 态）

| 状态 | 固定文案 | 信号格 | 颜色 | 落点 |
| --- | --- | --- | --- | --- |
| 服务在跑 | 桌面状态条 `服务正常`（mono 副文 `· <端口>`；端口 / UDP / WS 细节只在连接页展开） | 3 | `--signal` | 桌面状态条第 1 段、连接页 |
| 服务异常 | `服务没起来` | 1 | `--destructive` | 桌面状态条第 1 段 |
| 已连接 | `已连接 · N 台设备` | 3 | `--signal` / `--pet-signal` | 桌面状态条第 2 段、手机顶部条 |
| 正在连接 | `正在连接…` | 2 | `--muted-foreground` + 脉冲 | 手机顶部条、连接页 |
| 正在重连 | `连接断了，正在重连（8 秒后 · 第 2 次）` | 2 | `--muted-foreground` + 脉冲 | 手机顶部条、消息页断连块 |
| 未连接 | `还没连上电脑` | 1 | `--muted-foreground` | 手机顶部条、连接页、胶囊禁用态 |
| 连接失败 | `连不上电脑：<原因>` | 1 | `--destructive` | 手机连接页 |

- 连接状态一律不用琥珀；`<端口>` / `<原因>` 用真实值，不写死 47810（端口可能回退）。
- 桌面状态条的服务段用短词：`服务正常` / `服务连接中…` / `服务重连中` / `服务没起来`；手机连接态用上表 7 态文案。服务正常时端口作为 mono 副文，连接页才展开完整地址与 UDP 细节。

### 7.2 AI 四态

| 状态 | 固定文案 | 信号格 | 颜色 | 备注 |
| --- | --- | --- | --- | --- |
| 空闲 | `空闲` | 1 | `--muted-foreground` | 宠物 idle |
| 工作中 | `工作中` | 2 | `--signal` | 工作行再加「正在<动作>」 |
| 等你决定 | `等你决定` | 1 | `--decide`（唯一琥珀） | `askKind=approval` 副行「等你审批」 |
| 完成 | `完成` | 3 | `--success` | 手机 3 秒后回稳定态 |

- 多会话聚合优先级：等你决定 > 工作中 > 完成 > 空闲；聚合后缀统一「· N 个会话」。
- 会话对象自己的状态用「已完成」（会话卡行），不用「完成」。

### 7.3 会话工作行（D78）

| `tool` | 行内文案 |
| --- | --- |
| `bash` | 正在运行命令 |
| `read` | 正在阅读文件 |
| `edit` | 正在修改文件 |
| `search` | 正在搜索代码 |
| `web` | 正在查资料 |
| `agent` | 正在处理子任务 |
| `plan` | 正在整理计划 |
| `tool` | 正在使用工具 |
| 无 / 未知 | 正在思考 |

- 工作行 = 小圆环 spinner + 文案 + 「 · 相对时间」；仅 `state=working` 有 `tool`。
- 白名单在协议解析与 Rust 桥两层校验，未知值折叠为通用「正在使用工具 / 正在思考」，不透传原文。

### 7.4 麦克风（9 态）

| 状态 | 固定文案 | 落点 |
| --- | --- | --- |
| 空闲 | `按住说话` | 胶囊 / 浮层 |
| 未连接 | `先连接电脑` | 胶囊禁用（点按 → 连接页） |
| 未配置（P1 提案） | `语音还没配置 · 去电脑配置` | 本轮无 `asrConfigured`，用「先连接电脑」兜底 |
| 倾听中 | `正在听 · 0:07` | 胶囊内 + 浮层 + 计时 |
| 转写中 | `转写中…` | 胶囊 / 浮层（禁止「云端收尾」「准备中」） |
| 已输入 | `已输入` | 结果卡 / 浮层 |
| 已复制 | `已复制到电脑` | 附原因一行（[ux.md](../../standards/ux.md) §8） |
| 失败 | `没听清，靠近一点再说一次` | 必须给「再说一次」 |
| 已取消 | `已取消，没有发送` | 浮层 1.8 秒 |

- 手机胶囊与桌面浮层共用这组词；同一状态两端不得改写。

## 8. 首用清单（4 步）

| 步 | 在哪端 | 完成条件 | 手机如何显示 | 跳过会怎样（必须写出） |
| --- | --- | --- | --- | --- |
| ① 连接 | 手机 | `conn.online = true` | 实时判定：已连接 / 去连接 | 麦克风禁用、看不到 AI 状态 |
| ② 麦克风权限 | 手机 | 系统权限允许 + 首次 `micReady` | 本地判定（`micReady` 存 localStorage） | 按住说话直接失败 |
| ③ 百炼 Key | 桌面 | 已保存 Key 且测试通过 | 固定显示「在电脑上完成」（不显示完成态） | 录音能开始，但一定转写失败 |
| ④ 桌面辅助功能 | 桌面 | macOS 已授权 | 固定显示「在电脑上完成」 | 只复制到剪贴板，不自动输入、结果卡没有「回车 / 清空」 |

- 设置页顶部只在有未完成步骤时显示清单 banner：`首用清单 · 还差 N 步` + 展开箭头；展开后 4 步逐行：步骤名 + 状态标签（已完成 / 当前步骤 / 在电脑上完成）+ 一句「为什么需要 / 跳过会怎样」；done 只累计手机可验证的 ① ②，可收起并本机记住。
- 宠物页不再放首用清单卡；首用清单内容只在设置页。
- 手机不伪造 ③ ④ 的完成态；全部 4 步只由用户自行核对，本轮不做跨端同步。

## 9. 空态与错态

| 场景 | 结构 | 文案要点 |
| --- | --- | --- |
| 空态（通用） | 结论一句 + 下一步一句 + 主按钮 + 次按钮 | 不写「暂无数据 / 无内容」；必须有下一步 |
| 错态（通用） | 发生了什么 + 下一步 + 主按钮（重试 / 去开启 / 去配置）+ 次按钮（查看详情） | 不弹 modal；位置替换内容区；不显示堆栈 / 错误码 |
| 断连态 | 顶部一行 / 折叠块说明 + 去连接 | 不用琥珀；不阻断已缓存的只读内容（会话卡保留最后快照，可继续查看标题与时间） |
| 录音中 | 麦克风内状态 + 换页拦截 | 不弹气泡、不切页、不出现第二个取消按钮 |

## 10. 数据来源与隐私边界

| 展示 | 来源 | 边界 |
| --- | --- | --- |
| 桌面手机数 | `system` 消息可选 `clients`（服务端广播，含桌面本机与网页预览） | 显示 `max(0, clients - 1)` 台设备；旧服务端不发送时显示「未知」；不显示设备名 |
| 会话卡 / 状态 | `status`（`state/sessions/ts/resume/sessionList`，D78 含 `tool`） | 不显示提示词、回复、工具参数、路径、模型名；标题 ≤80 字符 |
| 总览「最近一次语音输入」 | `mic.result`（手机 / 浮层同源） | 只显示结果摘要与去处，不显示完整转写 |
| 连接 / 重连 | `conn` 事件 + 手机重连 store | 倒计时与第 N 次是真实值；桌面不展示虚构延迟 / 心跳 |
| 语音配置状态 | 桌面 `asr_cloud_status` | 手机侧本轮不显示（`asrConfigured` P1）；手机只按 `mic.error` 提示 |
| DSH 唤起 | `focus.request` / `focus.result` | 只回成功 / 错误码，不传应用路径 |

- 隐私口径沿用 [hook PRD](../hook/PRD.md) 与 [engineering/dsh-hook.md](../../engineering/dsh-hook.md)：只同步状态、标题、粗粒度工具类别、数量、事件时间。
- 手机是外设：不渲染剪贴板历史、不展示 AI 提问正文、不提供批准 / 拒绝。

## 11. 兼容、主题与无障碍

- **WebView 103**：颜色用 hex；高度用 `100vh` / `100%`；不用 CSS `translate` 属性做居中；dialog / sheet / tooltip 中的 `translate` 类是已知待修项，新壳不再新增。
- **双主题**：深色 / 浅色都要成立；宠物舞台随主题（D76）；桌面麦克风浮层用 `.deep-sea-scope` 恒定深海；手机扫码取景同样恒深海。
- **动效**：只动 `transform` / `opacity`；尊重 `prefers-reduced-motion`；录音中不弹气泡；后台 / 窗口失焦暂停循环动画。
- **无障碍**：状态条三段是按钮并带 `aria-label`（如「连接状态，点按查看」）；信号格 `aria-hidden`、文字始终在场；页头标题是页面 h1；键盘焦点顺序按视觉顺序。
