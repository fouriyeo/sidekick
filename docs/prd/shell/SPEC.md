# 应用外壳（桌面 Liquid Glass + 手机两页壳）SPEC

> 布局骨架、导航、状态词与首用清单的可执行规格；产品规则见 [PRD.md](./PRD.md)，验收见 [ACCEPTANCE.md](./ACCEPTANCE.md)。
> 桌面视觉令牌在 `app/src/desktop/styles/ios.css`（`.desktop-ios` 作用域）：D85 定结构，**D86 升级为 Liquid Glass · iOS 26 质感层**（玻璃只给控件层、内容卡不透明）；手机在 `app/src/mobile/styles/clean.css`（`.mobile-clean`）；通用视觉见 [standards/visual.md](../../standards/visual.md)，触控 / 无障碍通用规则见 [standards/ux.md](../../standards/ux.md)。
> 兼容底线：Android WebView 103——不用 `oklch` / `color-mix` / CSS `translate` 属性 / `dvh`；居中用 `inset-x-0` + flex 或 `left-0 right-0 mx-auto`。

## 1. 布局常量

### 1.1 桌面

| 项 | 值 |
| --- | --- |
| 画布 | 设计基准 1180×760；最小 960×640；单列固定布局，不写响应式断栏；窗口缩放不折叠侧栏 |

## 2. 桌面壳骨架

```text
┌──────────────┬──────────────────────────────────────────────┐
│ 38 交通灯区   │  ░ sticky 玻璃工具栏（滚动后 17/600 紧凑标题） │
│ logo 小跟班   │  概览（34/600）                      [动作组]  │
│ ▸ 概览        │  组标题 13/400                               │
│   内容        │  ┌ 白卡 16 圆角（不透明） ──────────────────┐  │
│   用量        │  │ 服务 47810 · 运行中                    › │  │
│ ──────────    │  │ 手机 1 台                              › │  │
│ ▸ 设置        │  │ AI 空闲                                › │  │
│ ● 服务 47810  │  └─────────────────────────────────────────┘  │
│ ● 手机 1 台   │  当前会话：重构登录模块 · 正在运行命令         │
│ ● AI 空闲     │  在 DSH 打开                                  │
└──────────────┴──────────────────────────────────────────────┘
```

- 侧栏 224（玻璃）：38 交通灯 + logo + 3 个一级入口 + 底部设置 + 3 行状态摘要；内容列 730 单列、页内滚动。
- **外壳级元素**：麦克风浮层仍是全局右上（宽 ≤320，`.deep-sea-scope` 恒定深海）；辅助功能未授权提示不再浮在左下角，而是概览页内容顶部一行（玻璃、`role="status"`，授权后消失）。
- 概览是默认首页；聊天（消息）只在「设置 › 消息通道」；设置是「列表 → 二级页」，不是整页表单也不是 Sheet。
- 960 宽：侧栏保持 224，内容区仍按最大 730 居中；不折叠导航、不出现横向滚动。

## 3. 桌面视图规格

| 视图 | 必须内容（自上而下） | 主行动 |
| --- | --- | --- |
| 概览 | ① 三行状态列表（服务 / 手机 / AI，彩色图标块 + 整行可点 + chevron；AI 行说明 = 状态 / 动作 + 相对时间） ②「当前会话」组（有则出现）：标题 + 说明 + 行尾相对时间 + 卡尾「在 DSH 打开」 ③「语音输入」组：最近一次结果 + 去处 / 时间；无记录一行「还没有语音记录」 | 页头玻璃动作组里的「二维码」；不造主按钮 |
| 内容 | 页头玻璃动作组：`N / 100 条` + 红色「清空」；正文：胶囊搜索、记录开关 + `密码框与隐藏内容 不记录`、记录列表（行 52–54，整行点按复制并 toast「已复制到剪贴板」，hover / 聚焦出现置顶 / 删除）；空态一行「还没有记录」，搜索无结果「没有匹配的内容」 | 无主按钮；清空二次确认 |
| 用量 | ① 2×2 汇总（花费 / Token / 会话 / 缓存命中；数字换区间 400ms 补间） ② 分段胶囊（客户端 / 会话 / 模型）+ 分组行，卡尾「价格表」/「价格表 · 待更新」 ③「花费趋势」（近 30 天柱阵，今日 `--ios-blue`，420ms / 20ms 错峰，组标题右侧合计） ④「Token 构成」（五桶行）；细节以 [usage SPEC](../usage/SPEC.md) 为准 | 页头区间分段 + 刷新；无主按钮 |
| 设置 | 首页：外观 + 自动输入 / 功能（手机连接、语音输入、AI 联动、剪贴板）/ 关于（关于本机、消息通道），行带彩色图标块；二级页从右侧 push 进入，内容沿用对应 feature Section（`ConnectionSection` / `ModelsSection` / `HookSection` / `AccessibilityCard` / 剪贴板设置 / 关于本机 / `ChatSection`），主行动按 [PRD](./PRD.md#4-桌面页面清单) | 无（二级页按各自 PRD） |

- 空态统一为「一行结论或一个动作」，不画空态插画、不写「暂无数据」；危险操作、隐私承诺、必须的输入提示可保留一句解释。
- **动效与材质**：滚动 > 6px 工具栏才变玻璃；页面 fade / 二级页 push；侧栏与分段滑块 spring；按压缩放；`prefers-reduced-motion` 关入场与缩放，`prefers-reduced-transparency` 玻璃退为实底卡；内容层（白卡 / 行 / 图表）始终不透明。
- 页内不重复其他地方已承担的信息：完整会话在 DSH、剪贴板列表在「内容」、用量分组在「用量」；旧 `Card` / `PageChip` / `PageFooter` 已无页面使用（仅保留导出、待删）；页面一律用 List 系列与桌面令牌。

## 4. 手机壳骨架

```text
┌──────────────────────────────────────────────┐
│ [gear]      ● 已连接 · 局域网        [chat]   │ ← 顶部条 44
├──────────────────────────────────────────────┤
│  会话 4                                  ⌄   │ ← 白卡 16 圆角
│  ◌ QQ · 我觉得现在的 UI 还是…            ×   │
│    正在运行命令 · 1 小时前                    │
│  还有 3 条                              ···   │
│                                              │
│                  鲸鱼（230）                  │
│                                              │
│                  [ 56 圆麦克风 ]              │
└──────────────────────────────────────────────┘
```

- 没有底部 tab；设置从 gear 进、消息从 chat 进。录音中所有换页入口由 `ui-store.setView` 拦截，不切页。
- 会话卡折叠 1 行、展开最多 5 行；展开时鲸鱼从 230 收到 220，卡片不推动麦克风。
- 变暗遮罩、再按一次退出提示在麦克风上方独立层，不遮挡麦克风。
- 设置页是二级整页（非 sheet）；6 组顺序固定：连接 / 外观 / 反馈 / 显示 / 数据与关于（含重置宠物）/ 消息通道；首用清单 banner 在顶部。

## 5. 手机页面规格

| 页面 | 结构 | 主行动 | 关键状态 |
| --- | --- | --- | --- |
| 宠物 | 顶部条 → 会话卡（折叠/展开）→ 鲸鱼（无底色）→ 56 圆麦克风 | 按住说话 | 空闲 / 工作中 / 等你决定 / 断连 / 录音中 / 变暗 |
| 设置（更多） | 页头（返回 + 更多 17/400）→ 首用清单 banner → 6 组白卡 | 无 | 保存失败行内红字 |
| 用量 | 页头（返回 + 用量 17/400）→ 区间切换 → 分组卡 | 无 | 账本缺失 / 价格过期 |
| 等你决定 | 页头（等你决定 + DSH 已暂停）→ 会话标题 21 → 状态 + 提出时间 → 主按钮「在电脑上继续」→ 其他 asking 列表 ≤5 | 「在电脑上继续」 | 单条 / 多条 / pending / 成功 / 失败 / 断连 |
| 消息 | 页头（返回 + 消息 + 局域网直连 + 连接信号格）→ 消息列表 → 输入框 | 发送 | 已连接 / 空态 / 断连折叠块 / 发送中 |
| 连接 | 页头（连接 + 信号格）→ 状态卡 → 扫码主按钮 → 手动地址可展开 → 自动发现列表 → 重连行 → 上次地址 → 局域网权限提示 | 「扫码连接」 | 正在找 / 0 台 / N 台 / 连接失败 / 重连中 / 权限未授权 |
| 扫码 | 全屏取景 + 取景框 + 说明 + 关闭 | 自动识别 | 扫描中 / 连接中 / 没识别到 / 相机权限被拒 |

- 宠物页没有 AI 气泡 /「现在」行 / 品牌小字；AI 状态由鲸鱼姿态 + 会话卡承担。
- 手机不显示剪贴板内容与 AI 提问正文；点 asking 只发 `focus.request`，不提供批准 / 拒绝。

## 7. 状态语言逐字表

### 7.1 连接（7 态）

| 状态 | 固定文案 | 信号格 | 颜色 | 落点 |
| --- | --- | --- | --- | --- |
| 服务在跑 | 桌面侧栏「服务」行：真实端口；概览服务行：`<端口> · 运行中` | — | `--signal` | 侧栏 / 概览 / 设置 › 手机连接 |
| 服务异常 | `未启动` | — | `--destructive` | 侧栏 / 概览 |
| 已连接 | 桌面手机行：`N 台`；手机顶部条：`已连接 · 局域网`；手机连接页：`已连接 · 电脑` | 3 | `--signal` | 侧栏 / 概览 / 手机顶部条 / 连接页 |
| 正在连接 | 手机顶部条：`连接中…`；手机连接页：`正在连接…` | 2 | `--muted-foreground` + 脉冲 | 手机顶部条、连接页 |
| 正在重连 | 手机顶部条：`正在重连 · 第 N 次` / `还没连上电脑 · N 秒后重连`；消息页断连块：倒计时 + 第 N 次 + 操作按钮 | 2 | `--muted-foreground` + 脉冲 | 手机顶部条、消息页断连块 |
| 未连接 | 桌面：`未连接`（手机行）；手机：`还没连上电脑` | 1 | `--muted-foreground` | 侧栏 / 概览 / 手机顶部条、连接页、胶囊禁用态 |
| 连接失败 | `连不上电脑` + 一行真实原因 | 1 | `--destructive` | 手机连接页 |

- 连接状态一律不用琥珀；`<端口>` / `<原因>` 用真实值，不写死 47810（端口可能回退）。
- 桌面只用「真实端口 / 未启动」「N 台 / 未连接」两组短值，不写「服务正常 / 服务没起来」这类句子；连接中途状态与失败原因在手机侧呈现，桌面不虚构进度。

### 7.2 AI 四态

| 状态 | 固定文案 | 信号格 | 颜色 | 备注 |
| --- | --- | --- | --- | --- |
| 空闲 | `空闲` | 1 | `--muted-foreground` | 宠物 idle |
| 工作中 | `工作中` | 2 | `--signal` | 侧栏 AI 行 + 概览当前会话「正在<动作>」 |
| 等你决定 | `等你决定` | 1 | `--decide`（唯一琥珀） | `askKind=approval` 副行「等你审批」 |
| 完成 | `完成` | 3 | `--success` | 手机 3 秒后回稳定态 |

- 多会话聚合优先级：等你决定 > 工作中 > 完成 > 空闲；聚合后缀统一「· N 个会话」。
- 会话对象自己的状态用「已完成」（概览当前会话行、会话卡行），不用「完成」。
- 桌面 AI 行的说明 = 当前会话的状态 / 动作 + 相对时间；没有状态时显示「没有开启联动」。

### 7.4 麦克风（9 态）

| 状态 | 固定文案 | 落点 |
| --- | --- | --- |
| 空闲 | `按住说话` | 胶囊 / 浮层 |
| 未连接 | `先连接电脑` | 胶囊禁用（点按 → 连接页） |

## 8. 首用清单（4 步）

| 步 | 在哪端 | 完成条件 | 手机如何显示 | 跳过会怎样（必须写出） |
| --- | --- | --- | --- | --- |
| ① 连接 | 手机 | `conn.online = true` | 实时判定：已连接 / 去连接 | 麦克风禁用、看不到 AI 状态 |
| ② 麦克风权限 | 手机 | 系统权限允许 + 首次 `micReady` | 本地判定（`micReady` 存 localStorage） | 按住说话直接失败 |
| ③ 百炼 Key | 桌面 | `desktop.status.asrConfigured = true`（已同意上传 + 已保存 Key + 地址/模型校验通过） | 桌面上报 true 时显示「已完成」；false / 未知时显示「在电脑上完成」 | 录音能开始，但一定转写失败 |
| ④ 桌面辅助功能 | 桌面 | `desktop.status.accessibilityTrusted = true`（macOS 已授权） | 桌面上报 true 时显示「已完成」；false / 未知时显示「在电脑上完成」 | 只复制到剪贴板，不自动输入、结果卡没有「回车 / 清空」 |

- 清单只出现在手机设置页顶部 banner：有未完成步骤时显示 `首用清单 · 还差 N 步` + 展开箭头，全部完成时显示 `首用清单 · 已完成`；展开后 4 步逐行：步骤名 + 状态标签（已完成 / 当前步骤 / 在电脑上完成）+ 一句「为什么需要 / 跳过会怎样」。
- done 累计 ① ②（手机本地可验证）+ ③ ④（桌面通过 `desktop.status` 上报的真实状态）；③④ 只在桌面明确上报 `true` 时显示「已完成」，旧桌面不发送或手机未收到时保持「在电脑上完成」，**不伪造完成态**。
- 刷新时机：手机连上电脑、App 回前台、打开设置页时各发一次 `status.request`，桌面回 `status` + `desktop.status`；电脑上改 Key / 辅助功能后无需重装 App，重新拉取即可更新。

## 9. 空态与错态

| 场景 | 结构 | 文案要点 |
| --- | --- | --- |
| 空态（桌面） | 一行结论或一个动作（列表卡内一行，不画插画） | 不写「暂无数据 / 无内容」；有下一步就给动作 |
| 空态（手机） | 结论一句 + 下一步一句 + 主按钮 + 次按钮 | 不写「暂无数据 / 无内容」；必须有下一步 |
| 错态（通用） | 发生了什么 + 下一步 + 主按钮（重试 / 去开启 / 去配置）+ 次按钮（查看详情） | 不弹 modal；位置替换内容区；不显示堆栈 / 错误码 |
| 断连态 | 顶部一行 / 折叠块说明 + 去连接 | 不用琥珀；不阻断已缓存的只读内容 |
| 录音中 | 麦克风内状态 + 换页拦截 | 不弹气泡、不切页、不出现第二个取消按钮 |

## 10. 数据来源与隐私边界

| 展示 | 来源 | 边界 |
| --- | --- | --- |
| 桌面手机数 | `system` 消息可选 `clients`（服务端广播，含桌面本机与网页预览） | 显示 `max(0, clients - 1)` 台设备；旧服务端不发送时显示「未知」；不显示设备名 |
| 桌面服务端口 | `server_info` | 显示真实端口（可能回退到 47811–47814 / 8848）；取不到时「未启动」 |
| 概览当前会话 / 会话卡 | `status`（`state/sessions/ts/resume/sessionList`，D78 含 `tool`） | 不显示提示词、回复、工具参数、路径、模型名；标题 ≤80 字符 |
| 概览「语音输入」 | `mic.result`（手机 / 浮层同源） | 只显示结果摘要与去处，不显示完整转写 |
| 连接 / 重连 | `conn` 事件 + 手机重连 store | 倒计时与第 N 次是真实值；桌面不展示虚构延迟 / 心跳 |
| 语音配置状态 | 桌面 `asr_cloud_status` | 手机侧本轮不显示（`asrConfigured` P1）；手机只按 `mic.error` 提示 |
| 用量分组 | `token_usage_stats`（只读 DSH ledger） | 不含提示词 / 路径 / cwd；模型 ID 按 D83 开关决定是否上手机 |
| DSH 唤起 | `focus.request` / `focus.result` | 只回成功 / 错误码，不传应用路径 |

- 隐私口径沿用 [hook PRD](../hook/PRD.md) 与 [engineering/dsh-hook.md](../../engineering/dsh-hook.md)：只同步状态、标题、粗粒度工具类别、数量、事件时间。
- 手机是外设：不渲染剪贴板历史、不展示 AI 提问正文、不提供批准 / 拒绝。

## 11. 兼容、主题与无障碍

- **WebView 103**：颜色用 hex；高度用 `100vh` / `100%`；不用 CSS `translate` 属性做居中；dialog / sheet / tooltip 中的 `translate` 类是已知待修项，新壳不再新增。
- **双主题**：深色 / 浅色都要成立；桌面令牌与玻璃材质在 `.desktop-ios`（`ios.css`），手机在 `.mobile-clean`（`clean.css`），互不影响；宠物舞台随主题（D76）；桌面麦克风浮层用 `.deep-sea-scope` 恒定深海；手机扫码取景同样恒深海。
- **玻璃层级**：玻璃只给控件层（侧栏 / 工具栏 / 动作组 / 分段轨道 / 辅助功能提示 / 弹层遮罩），内容白卡与行保持不透明；玻璃层数要克制，不在滚动内容里叠 `backdrop-filter`；弹层走 portal，需 `.desktop-ios` 同时挂在 `<html>` 上才吃得到桌面令牌。
- **动效**：只动 `transform` / `opacity` / 颜色；页面 fade 320ms / 二级页 push 340ms（**不加过冲**）、滑块 `SPRING_SLIDE` spring（ζ≈0.59、过冲 10%）、按压缩放（按下 90ms、松手 320ms 回弹）、弹层 320ms、用量数字 400ms、柱阵 420ms/20ms 错峰；手机端 `clean.css` 用同一根 `--spring-back` 曲线做结果卡 / 会话行 / 麦克风钮 / 开关（WebView 103 只认 `transform`）；`prefers-reduced-motion` 关页面与弹层入场、按压与滑块动效，`prefers-reduced-transparency` 玻璃退为 `--card` 实底；不做循环装饰；后台 / 失焦暂停。
- **无障碍**：侧栏状态摘要行是按钮并带 `aria-label`（如「连接状态，点按查看」）；色点 `aria-hidden`、文字始终在场；页头标题是页面 h1；当前导航项 `aria-current="page"`；辅助功能提示是 `role="status"`、不抢焦点；键盘焦点顺序按视觉顺序。
- **拖动区**：侧栏顶部 38 与 sticky 工具栏（含二级页返回行）是拖动区；拖动区内若放按钮，必须另有可用入口，不能把拖动区当唯一可点目标。
