# 应用外壳（桌面 Liquid Glass · iOS 26 + 手机两页壳）验收

> 范围：桌面 6 个一级入口 + 224 玻璃侧栏 + Liquid Glass 分组列表（D85 结构 + D86 质感 + D104 语音一级页）、手机两页壳（D80/D81）、状态语言、首用清单、返回层级、数据真实性。功能行为不在本文件（宠物 / 麦克风 / AI 联动 / 用量各自验收）。
> 判定：P0 全部通过才算壳完成；P1 可随下一轮补。桌面用例在 1180×760 / 960×640 上手点验证，手机用例在 390×844 真机验证，不依赖读代码。

## A. 桌面壳（P0）

| 编号 | Given | When | Then |
| --- | --- | --- | --- |

| SHL-AC-05 | 手机已连接 / 未连接 | 看侧栏「手机」行 | 显示「N 台」/「未连接」；点整行进「设置 › 手机连接」 |
| SHL-AC-06 | AI 处于 空闲 / 工作中 / 等你决定 / 完成 | 看侧栏「AI」行 | 显示四态固定词；点整行进「设置 › AI 联动」；概览 AI 行落点相同 |
| SHL-AC-07 | 打开设置 | 浏览首页 | 一张分组列表：外观 + 自动输入；「功能」= 手机连接 / AI 联动（剪贴板是一级页，设置里没有它）；「关于」= 关于本机 / 消息通道；每行左侧 30×30 彩色图标块、右侧只有一个短值或控件 |

| SHL-AC-09 | 有 / 没有当前会话 | 打开概览 | 有：三行状态 + 「当前会话」组（标题 + 状态说明 + 相对时间 + 卡尾「在 DSH 打开」）+ 「语音输入」组；没有：不出现「当前会话」组，不留空洞 |
| SHL-AC-10 | 剪贴板有内容 | 打开 ⌘2「剪贴板」页 | 页头大标题「剪贴板」+ 右侧 `N / M 条`（M 默认 100）+ 红色「清空」；搜索、组标题「设置」下的记录开关、最多保留（20 / 50 / 100 / 200，改小立即裁剪且置顶优先）、`密码框与隐藏内容 不记录`、整行点按复制、置顶 / 删除都在；空态一行「还没有记录」；清空二次确认 |
| SHL-AC-10M | 手机已同步备忘录 | 打开 ⌘3「备忘录」页，再点第一条 | 页头 34/600「备忘录」；列表显示类型/标题/摘要/时间/时长；点开只读详情（摘要 / 待办 / 全文 / 播放）；页面没有「剪贴板」分段、没有编辑/删除/重新整理 |
| SHL-AC-11 | 用量账本可读 | 打开用量页 | 页头大标题 + 区间分段 + 刷新；内容为 2×2 汇总（花费 / Token / 会话 / 缓存命中）、分组列表（客户端 / 会话 / 模型 + 卡尾价格表）、花费趋势、Token 构成；无说明句、无页脚、无状态的 mono 大写装饰 |
| SHL-AC-12 | 窗口 1180×760 与最小 960×640 | 逐页浏览 | 单列、内容最大宽 730 居中、不横向溢出；侧栏固定 224 不折叠；交通灯不压 logo 与导航；滚动内容从玻璃工具栏下滚过 |

| SHL-AC-69 | 语音一级页 | 点侧栏「语音 ⌘4」 | 单个一级页（不是二级页、不再 push 子页）：页头 34/600「语音」；页内纵向三段 = 百炼配置 / 关键词列表（`N / 2000` + 保存）/ 语音用量；页内滚动、无页面说明句 |
| SHL-AC-70 | 关键词 | 点「加一行」输入关键词并保存 | 一行一个词、行尾可删除；保存后重启仍在；空行/重复词自动去掉；旧热词平铺进同一列表 |
| SHL-AC-71 | 关键词超限 | 2000+ 词或 16 字中文 / 8 段英文 | 前端阻止保存并给行号/数量提示；后端二次校验失败不写盘 |
| SHL-AC-72 | 关键词生效 | 关键词含重复/空行后录音 | `run-task` 的 `vocabulary` 为去重后的词表（每词权重 4）；空列表不带该键 |

## 手工回归建议

- 先走桌面主线：启动 → 概览三行状态 → 设置首页 → 手机连接二级页往返（看 push + 二维码白块描边）→ 剪贴板 → 备忘录 → 用量 → 消息通道（全宽聊天 + 玻璃输入栏）→ 切外观；滚动验证玻璃工具栏，再走 asking 链路与断连链路。
- 再走手机主线：宠物页按住说话 → 结果卡 → 会话卡展开 → 等你决定。
- 每次改壳都回归：⌘1–⌘6、备忘录一级页、语音一级页单页（三段、内部不 push）、设置二级页 push/返回、侧栏状态摘要落点、滚动后玻璃工具栏、reduce-motion / reduced-transparency、录音中禁切页、首用清单、状态词两端对照。
