# 应用外壳（指挥舱）验收

> 范围：桌面 6 视图壳（含 D82 用量）、手机两页壳（宠物 + 设置）、状态语言、首用清单、返回层级、数据真实性。功能行为不在本文件（宠物 / 麦克风 / AI 联动各自验收）。
> 判定：P0 全部通过才算壳完成；P1 可随下一轮补。每条都能在 1180×760 / 390×844 上手点验证，不依赖读代码。

## A. 桌面壳（P0）

| 编号 | Given | When | Then |
| --- | --- | --- | --- |
| SHL-AC-01 | 桌面启动、服务已就绪 | 打开窗口 | 默认落在「总览」；顶部 48 状态条三段齐全（服务 / 手机 / AI），72 导航 6 项，页头 56 |
| SHL-AC-02 | 任意一级页 | 按 ⌘1–⌘6 | 依次切到 总览 / 会话 / 内容 / 用量 / 系统 / 设置；焦点在输入框时不误触 |
| SHL-AC-03 | 任意页 | 点状态条第 1 段（服务） | 跳到 系统 › 连接，且分段选中「连接」 |
| SHL-AC-04 | 手机已连接 | 点状态条第 2 段 | 跳到 系统 › 连接；手机段显示「已连接 · N 台设备」 |
| SHL-AC-05 | AI 处于工作 / 等你决定 | 点状态条第 3 段 | 跳到「会话」；AI 段文案与信号格与状态一致 |
| SHL-AC-06 | 系统页 | 切换 4 段 | 连接 / 语音 / 联动 / 消息切换正确，页头与内容同步；不出现第 5 段 |
| SHL-AC-07 | 导航 | 点「设置」 | 进入设置整页；不再出现设置 Sheet |
| SHL-AC-08 | macOS 辅助功能未授权 | 打开任意桌面页 | 状态条下方出现 40px 提示条，所有页一致；点「知道了」本次隐藏；设置页仍可查状态 |
| SHL-AC-09 | 辅助功能已授权 | 打开任意桌面页 | 无提示条；`window.focus` 回来自动收起 |
| SHL-AC-10 | 手机正在录音 | 切到任意桌面页 | 右上麦克风浮层出现；不抢焦点、不挡输入；宽 ≤320 |
| SHL-AC-11 | 窗口缩到 960×640 | 逐页浏览 | 不横向溢出；内容单列、卡片不被裁切 |
| SHL-AC-12 | 布局基准 1180×760 | 逐页浏览 | 内容区 max-width 880 居中；不出现两个同权重主按钮 |

| SHL-AC-23 | 系统 › 联动未安装 / 已连接 / 断开 | 打开该段 | 三种状态各有状态词与主行动（开启 / 无主按钮 / 修复） |
| SHL-AC-24 | 系统 › 消息未连接 | 打开该段 | 输入禁用 +「手机还没连上，先连接」+ 去连接；已连接可双向收发 |
| SHL-AC-25 | 设置页 | 切换外观三选一 | 即时生效、不重启；深浅两套都成立；自动输入权限、剪贴板开关、关于与隐私、快捷键齐全（桌面不做音效试听） |

## 手工回归建议

- 先走主线：启动 → 总览 → 手机连接 → 宠物页按住说话 → 结果卡 → 总览最近事件；再走 asking 链路与断连链路。
- 每次改壳都回归：⌘1–⌘6、返回层级（含 usage→settings）、录音中禁切页、首用清单、状态词两端对照。
- 失败先判断是文档过期还是实现偏离：以本文件与 [SPEC.md](./SPEC.md) 为准，修一处并同步 [docs/status.md](../../status.md)。
