# 情绪宠物 · 体验规格

> 本文回答“长什么样、怎么动、怎么响应”。产品规则见 [PRD.md](./PRD.md)；视觉令牌见 [standards/visual.md](../../standards/visual.md)；技术实现见 [engineering/pet-runtime.md](../../engineering/pet-runtime.md)。
> 手机端；只支持竖屏；桌面不渲染宠物。

## 1. 画布与安全区

- 设计基准：20:9 竖屏（约 1080×2400）；兼容 16:9 竖屏（约 1080×1920）。
- 使用 `100dvh`；左右安全区 24dp，底部手势条额外 16dp。
- 不出现横向滚动；刘海/挖孔侧内容内缩。
- 所有尺寸用 dp/相对比例，不写死像素宽度。
- Android Activity 锁定竖屏；浏览器 dev 也不做横屏布局。

## 2. 布局（单竖屏）

```text
┌ 安全区 ──────────────────────────────────┐
│ [设置]                        [聊天] [●] │
│ ┌ 会话（AI 联动） ─────────────────────┐ │
│ │ ● 修复登录 bug   工作中 · 2 分钟前  ✕ │ │  ← 有会话时显示，默认收起 1 条
│ └──────────────────────────────────────┘ │
│                  ╭──────────────╮        │
│     气泡          │   宠物舞台    │        │
│                  │  （居中略偏上）│        │
│                  ╰──────────────╯        │
│                                          │
│        [  🎙 按住说话  ]  ← 56px 胶囊     │
└──────────────────────────────────────────┘
```

- 宠物舞台水平居中、略偏上；有 AI 会话列表时整体下移（收起 32px、展开 56px）。
- 设置图标左上角 44dp；聊天入口右上带连接状态点；界面元素常显，由自动变暗防烧屏。
- 气泡最多 2 行，位于宠物左上方；会话列表展开时隐藏气泡。
- 麦克风：56px 高、`min(86vw,360px)` 宽的胶囊；录音/处理状态在同一胶囊内，实时文本/结果卡片在胶囊上方独立定位，不推动按钮。
- 取消只保留上滑手势（≥48dp 进入、<24dp 退出），不新增取消按钮。
- 屏幕常亮默认开、默认最长 2 小时（可调，0 = 不限）：宠物页前台可见（含设置弹层）时不自动熄屏，到点释放；聊天页与后台按系统默认熄屏。
- 宠物页无操作默认 5 分钟自动暗到 70%（设置可调 1/2/5/10/15/30 分钟），触摸恢复；宠物页不响应长按选中/复制。
- AI 会话列表布局/交互见 [hook/SPEC.md](../hook/SPEC.md)；宠物只负责下移与让出气泡。

## 3. 状态机

### 3.1 状态

| 状态 | 含义 | 允许的下一步 |
| --- | --- | --- |
| `idle` | 安静陪伴，随机 idle 动作 | 互动 / 倾听 / 睡觉 / 后台 |
| `interacting` | 摸摸/戳一戳反馈 | idle（指针抬起 2 秒后） |
| `listening`（P1 契约，本期不可达） | 麦克风录音中 | celebrating / concerned / idle |
| `celebrating`（P1 契约，本期不可达） | 转写成功后的短暂开心 | idle |
| `concerned`（P1 契约，本期不可达） | 转写失败的短暂关心 | idle |
| `sleeping` | 夜间睡眠 | idle（触摸唤醒） |
| `away` | App 后台/不可见 | idle（回前台） |

### 3.2 转移

| 从 | 事件 | 到 | 动作 |
| --- | --- | --- | --- |
| away | 回前台 | idle | 先眨眼一次；>6h 播问候；睡眠优先，离开 ≥5 分钟跨夜直接 sleeping |
| idle | 触摸（摸摸/戳） | interacting | 对应动作 + 轻震 |
| interacting | 指针抬起后 2 秒无新触摸 | idle | 回到呼吸 |
| idle | 麦克风开始（P1，仅单测注入） | listening | 竖耳、停止随机 idle |
| listening | 转写成功（P1，仅单测注入） | celebrating | 2 秒开心 + 闪光 |
| listening | 转写失败（P1，仅单测注入） | concerned | 1.5 秒歪头/耳朵下垂 |
| listening | 取消/后台（P1） | idle | 眨眼，不表达失望 |
| idle | 23:00–06:00 且前台 5 分钟无互动 | sleeping | 慢慢趴下、闭眼 |
| sleeping | 触摸（麦克风为 P1） | idle | 轻轻醒来 |
| 任意 | App 后台 | away | 暂停动画与计时 |

- 设置/聊天覆盖层不进入 `away`，不卸载宠物；暂停 idle/睡眠计时，心情保留（AC-18）。
- 睡醒后不补发离开问候；后台跨夜离开 ≥5 分钟回前台直接 `sleeping`。
- **AI 联动四态是叠加展示状态，不新增 `PetPhase`**：静态=idle，工作中/等你决定/完成由 AI store 驱动；完成 3 秒；不落盘。优先级与动作见 [hook SPEC](../hook/SPEC.md) §2；倾听/摸摸优先，结束后恢复 AI 状态。

### 3.3 心情与表现

| 心情 | 触发 | 表现 |
| --- | --- | --- |
| content | 默认 | 呼吸、眨眼、偶尔张望 |
| happy | 摸摸持续 3 秒 | 眼睛弯、尾巴快摆、爱心 ≤6，2 秒 |
| curious | 戳一戳 | 歪头、盯手指 |
| sleepy | 夜间 / energy<15 | 打哈欠、眼皮下沉 |
| listening（P1） | 麦克风录音 | 竖耳、身体前倾、轻微摆动 |
| proud（P1） | 转写成功 | 挺胸、闪光、短跳 |
| concerned（P1） | 转写失败 | 耳朵下垂、歪头 1.5 秒 |

- 存档只存基线心情（content/sleepy）；happy/curious/listening/proud/concerned 等瞬态不落盘。
- 低精力 `[假设]`：energy<30 哈欠增加、<15 sleepy；启动按当前时段/精力重算基线。

## 4. 触摸与手势

| 手势 | 识别 | 反馈 | 冷却 |
| --- | --- | --- | --- |
| 摸摸 | 热区内滑动，1.5 秒内 ≥2 次方向变化，持续 3 秒 | 靠近、闭眼、轻震；happy + 爱心 ≤6 | 2 秒（手势结束起算） |
| 戳一戳 | 点按 <250ms | 看向手指、好奇 | 2 秒 |
| 快速连戳（P1） | 2 秒内 3 次点按 | 扭头 3 秒后恢复 | 5 秒（仅 P1，本轮不实现） |
| 拖拽/捏合 | 不识别 | 无 | — |

- 热区 = 宠物舞台 + 24dp；不要求点中身体；slop 8px 起步，真机校准。
- 多指只认第一根；冷却期点击丢弃、不计数、不排队，仅保留按下态视觉。
- 指针抬起后 2 秒无新触摸回 idle；录音中禁用互动为 P1 契约。
- 触摸反馈 ≤100ms；大动画不阻塞输入。

## 5. 气泡与文案

### 5.1 规则

- 最多 1 条/30 秒；统一 4 秒自动消失；2 行以内。
- 录音/转写中不出气泡（P1）；错误由麦克风模块提示。
- 不用感叹号堆叠；不撒娇过度；不制造愧疚。
- 文案可带名字，但名字不写日志。

### 5.2 文案库（P0 示例）

| 场景 | 文案 |
| --- | --- |
| 初次见面 | “你来了。叫我什么？” |
| 默认名 | “那我就叫小跟班。” |
| 长时间未操作 | “你忙你的，我在这儿。” |
| 被摸 | “嗯，这里。” |
| 连续摸 | “再摸一下也可以。” |
| 被戳 | “嗯？” |
| 快速连戳 | “好啦好啦，我转过去。” |
| 回来（6h+） | “回来啦。” |
| 回来（3d+） | “我刚刚在打盹，没听见你。” |
| 夜间 | “夜深了，我陪你一会儿。” |
| 麦克风开始 | （不出气泡，竖耳） |
| 转写成功 | “收到。” |
| 转写失败 | “没听清，再来一次？” |
| 重置确认 | “要让我重新认识你吗？” |

禁止文案：

- “你怎么才回来。”
- “你不理我。”
- “我饿了，快喂我。”
- “今天还没签到。”
- “你落后了。”

## 6. 首次见面流程

```text
进入宠物页
  → 宠物从睡梦中醒来（1.5s）
  → 伸懒腰 + 眨眼
  → 气泡：“你来了。叫我什么？”
  → 输入框 + 默认名“小跟班” + “先这样叫我”
  → 确认/跳过
  → 宠物点头/轻叫
  → 进入 idle
```

- 不请求任何权限。
- 输入框自动聚焦但不强制键盘；可直接跳过。
- 名字 1–8 字符；实时显示剩余字数。
- 保存失败不阻塞，使用默认名。

## 7. 设置页

| 分组 | 项 | 默认 | 说明 |
| --- | --- | --- | --- |
| 宠物 | 名字 | 小跟班 | 1–8 字符 |
| 宠物 | 重置宠物 | — | 二次确认，不可撤销 |
| 反馈 | 震动 | 开 | App 原生触感：开始录音中震、取消轻震、成功/失败；不申请 VIBRATE 权限，跟随系统触感开关 |
| 反馈 | 声音 | 关 | AI 联动三音效（开工/提问/完成）；默认关闭，可开关 + 三个试听；只在宠物页前台播放，录音/后台静音 |
| 显示 | 减少动效 | 跟随系统 | 可手动强制 |
| 显示 | 屏幕常亮 | 开 | 宠物舞台前台时阻止系统熄屏；可关闭，关闭后按系统策略；聊天/后台不常亮 |
| 显示 | 最长常亮 | 2 小时 | 常亮最长时长，到点释放交给系统；0 = 不限；点亮屏幕回前台后重新计时 |
| 显示 | 自动变暗 | 5 分钟 | 宠物页无操作后暗到 70%，触摸恢复；可调 1/2/5/10/15/30 分钟 |
| 关于 | 隐私说明 | — | 本机存储、卸载丢失 |
| 关于 | 版本/许可证 | — | 只读 |

- 入口：舞台左上角设置图标；一次点击。右上聊天入口带连接状态点，聊天页可返回宠物；宠物页不自动连接、不发起网络请求。
- 设置页为全屏/整页，单列滚动；返回不丢状态。
- 不做账号、云同步、通知设置（本期无通知）。

## 8. 降级与减少动效

### 8.1 动态形象加载失败

- 显示 `poster.webp`（图集首帧）；摸摸/戳仍有轻震和气泡。
- manifest 非法、图集解码失败、尺寸与 `cols/cell` 不匹配，都走同一条降级路径，不阻塞录音。
- 静默降级，不向用户报错；本地记录一次 `pet_error`。

### 8.2 减少动效

- 系统 `prefers-reduced-motion: reduce` 或设置开启：
  - 去掉随机 idle、弹跳、爱心粒子、闪光；
  - 保留状态切换的即时表情（交叉淡入 120ms）；
  - 保留触摸/录音的按钮反馈；
  - 睡觉/醒来用静态姿势切换。

### 8.3 低电量/低内存

- 低电量：idle 间隔加倍，粒子关闭，保留触摸反馈。
- 低内存/后台被杀：恢复上次保存状态；不重复问候。
- 存储失败：本次会话继续，设置页提示“这次记不住”。

## 9. 无障碍

- 宠物舞台提供可读标签：“小跟班，正在陪伴”；状态变化用 `aria-live="polite"` 简短播报，最多 1 条/30 秒。
- 摸摸/戳一戳的替代按钮放在设置页，不强制手势。
- 气泡文字对比 ≥4.5:1；不只用颜色表达心情。
- 计时/录音状态有文字，不只波形。
- 减少动效遵循系统设置；应用内可覆盖。
