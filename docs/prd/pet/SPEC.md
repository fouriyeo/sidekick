# 情绪宠物 · 体验规格

> 本文回答“长什么样、怎么动、怎么响应”。产品规则见 [PRD.md](./PRD.md)；视觉令牌见 [standards/visual.md](../../standards/visual.md)；技术实现见 [engineering/pet-runtime.md](../../engineering/pet-runtime.md)。
> 手机端；只支持竖屏；桌面不渲染宠物。

## 1. 画布与安全区

- 设计基准：20:9 竖屏（约 1080×2400）；兼容 16:9 竖屏（约 1080×1920）。
- 使用 `100dvh`；左右安全区 24dp，底部手势条额外 16dp。
- 不出现横向滚动；刘海/挖孔侧内容内缩。
- 所有尺寸用 dp/相对比例，不写死像素宽度。
- Android Activity 锁定竖屏；浏览器 dev 也不做横屏布局。

## 2. 布局（单竖屏）

```text
┌───────────────────────────────────────────────────────────┐
│ [gear] [📡]           ¥0.42 [备忘录] [chat]   ← 顶部条 44 │
│ ┏ 会话卡（浮层：折叠 1 行 / 展开最多 5 行）┓              │
│ ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛                    │
│                                                           │
│             鲸鱼（无底色，固定 230，展开不位移）          │
│                                                           │
│             [ 56 薄荷圆麦克风，居中、距底 56 ]            │
└───────────────────────────────────────────────────────────┘
```

- 顶部条 44：左 gear → 设置页；连接状态图标 → 连接页；右侧今日用量数字 → 用量页、备忘录 → 备忘录全屏页、chat → 消息页（D80 / D93 / D124）。
- 宠物舞台水平居中、略偏上；会话卡不推动宠物与麦克风。
- 气泡最多 2 行，绝对定位层，位于宠物上方；不推动舞台与胶囊。
- 麦克风：空闲是 56 薄荷圆钮、居中、距底 56（原 24 贴屏幕下沿，按住不方便）；录音时展开为 `min(90vw,420px)` 胶囊，收尾时收回圆钮、只转 spinner 不写字；实时文本/结果卡片在按钮上方独立定位，不推动按钮。
- 取消只保留上滑手势（≥80dp 进入、<32dp 退出），不新增取消按钮。
- 屏幕常亮默认开、默认最长 2 小时（可调，0 = 不限）：宠物页前台可见时不自动熄屏，到点释放；非宠物页与后台按系统默认熄屏（D80：设置从 gear 进）。
- 宠物页无操作默认 5 分钟自动暗到 70%（设置可调 1/2/5/10/15/30 分钟），触摸恢复；宠物页不响应长按选中/复制。
- AI 会话卡规则见 [hook/SPEC.md](../hook/SPEC.md) §2；宠物页只负责置顶展示与会话卡交互，不改变四态动作。
- 宠物舞台不绘制背景声呐环（手机舞台环已删除，D77）；只有桌面状态点的 `.sonar-dot-ring` 保留。

## 3. 状态机

### 3.1 状态

| 状态 | 含义 | 允许的下一步 |
| --- | --- | --- |
| `idle` | 安静陪伴，随机 idle 动作 | 睡觉 / 后台 |
| `sleeping` | 夜间睡眠 | idle（06:00 后自动醒 / 回前台重算） |
| `away` | App 后台/不可见 | idle（回前台） |

> 首次命名/庆祝已下线（2026-11-05）：不再有 `celebrating` 状态、`NAME_SET` 事件与爱心粒子；宠物固定显示「小跟班」。

> 麦克风联动已下线（D77）：不再有 `listening` / `concerned` 姿态与 `MIC_*` 事件；录音时宠物保持不变。

### 3.2 转移

| 从 | 事件 | 到 | 动作 |
| --- | --- | --- | --- |
| 无存档 / 未见过面 | BOOT | idle | 气泡「你来了。我是小跟班。」；`onboarded=true` |
| away | 回前台 | idle | 先眨眼一次；>6h 播问候；睡眠优先，离开 ≥5 分钟跨夜直接 sleeping |
| idle | 23:00–06:00 且前台 5 分钟无互动 | sleeping | 慢慢趴下、闭眼 |
| sleeping | 06:00 后 TICK / 回前台重算 | idle | 轻轻醒来 |
| 任意 | App 后台 | away | 暂停动画与计时 |

- 设置/聊天覆盖层不进入 `away`，不卸载宠物；暂停 idle/睡眠计时，心情保留（AC-18）。
- 睡醒后不补发离开问候；后台跨夜离开 ≥5 分钟回前台直接 `sleeping`。
- 点击、长按、来回抚摸宠物不产生任何状态变化（D69）；06:00 后自动醒，回前台按跨夜规则重算。
- 录音开始/成功/取消/失败不产生任何宠物事件（D77）。
- **AI 联动四态是叠加展示状态，不新增 `PetPhase`**：静态=idle，工作中/等你决定/完成由 AI store 驱动；完成 3 秒；不落盘。优先级与动作见 [hook SPEC](../hook/SPEC.md) §2；休息优先，结束后恢复 AI 状态。

### 3.3 心情与表现

| 心情 | 触发 | 表现 |
| --- | --- | --- |
| content | 默认 | 呼吸、眨眼、偶尔张望 |
| curious | 首次见面（尚未见过面） | 歪头、张望 |
| sleepy | 夜间 / energy<15 | 打哈欠、眼皮下沉 |

- 存档只存基线心情（content/sleepy）；curious 等瞬态不落盘。`happy` 随命名流程下线删除（2026-11-05）；麦克风联动已下线（D77），不再有 listening/proud/concerned 心情。
- 低精力 `[假设]`：energy<30 哈欠增加、<15 sleepy；启动按当前时段/精力重算基线。

## 4. 触摸与手势（非目标，D69）

当前阶段不实现宠物触摸互动：点击、长按、来回抚摸宠物都没有任何反应，不出现气泡、震动、爱心或姿态切换，也不写存档。热区、slop、冷却、多指与录音中禁用等规则不再适用；设置页不提供「摸摸它/戳一下」替代按钮。后续恢复需作为独立功能重新评审。

## 5. 气泡与文案

### 5.1 规则

- 最多 1 条/30 秒；统一 4 秒自动消失；2 行以内。
- 录音不再屏蔽气泡（宠物不感知麦克风，D77）；错误仍由麦克风模块提示。
- 不用感叹号堆叠；不撒娇过度；不制造愧疚。
- 文案不含用户自定义内容；宠物固定显示「小跟班」。

### 5.2 文案库（P0 示例）

| 场景 | 文案 |
| --- | --- |
| 初次见面 | “你来了。我是小跟班。” |
| 长时间未操作 | “你忙你的，我在这儿。” |
| 回来（6h+） | “回来啦。” |
| 回来（3d+） | “我刚刚在打盹，没听见你。” |
| 夜间 | “夜深了，我陪你一会儿。” |
| 重置确认 | “要重置宠物吗？” |

禁止文案：

- “你怎么才回来。”
- “你不理我。”
- “我饿了，快喂我。”
- “今天还没签到。”
- “你落后了。”

## 6. 首次见面流程

```text
进入宠物页
  → 宠物从睡梦中醒来（1.5s）
  → 伸懒腰 + 眨眼
  → 气泡：“你来了。我是小跟班。”
  → 直接进入 idle（无输入框、无确认/跳过按钮）
```

- 不请求任何权限。
- 宠物固定叫「小跟班」；不弹命名框、不收集文字、不提供改名。
- 首次 BOOT 置 `onboarded=true` 并落盘；之后启动不再重复首次问候。
- 旧存档里的 `name` 字段忽略、不迁移，其他字段照常恢复。
- 重置宠物后下次启动重新走一次首次见面。

## 7. 设置页

| 分组 | 项 | 默认 | 说明 |
| --- | --- | --- | --- |
| 宠物 | 重置宠物 | — | 二次确认，不可撤销；下次启动重新首次见面 |
| 反馈 | 震动 | 开 | App 原生触感：开始录音中震、取消轻震、AI 提问/完成提醒；转写成功/失败不再触发宠物触感（D77）；不申请 VIBRATE 权限，跟随系统触感开关 |
| 反馈 | 声音 | 关 | AI 联动三音效（开工/提问/完成）；默认关闭，可开关 + 三个试听；只在宠物页前台播放，录音/后台静音 |
| 显示 | 减少动效 | 跟随系统 | 可手动强制 |
| 显示 | 屏幕常亮 | 开 | 宠物舞台前台时阻止系统熄屏；可关闭，关闭后按系统策略；聊天/后台不常亮 |
| 显示 | 最长常亮 | 2 小时 | 常亮最长时长，到点释放交给系统；0 = 不限；点亮屏幕回前台后重新计时 |
| 显示 | 自动变暗 | 5 分钟 | 宠物页无操作后暗到 70%，触摸恢复；可调 1/2/5/10/15/30 分钟 |
| 关于 | 隐私说明 | — | 本机存储、卸载丢失 |
| 关于 | 版本/许可证 | — | 只读 |

- 入口：顶部 44 条（D80 / D93 / D124）——左 gear → 设置页，连接状态图标 → 连接页，右侧今日用量数字 → 用量页、备忘录 → 备忘录全屏页、chat → 消息页；宠物页不自动连接、不发起网络请求。
- 设置页为全屏/整页（D80），单列滚动、返回不丢状态、不提供名字/改名入口；完整分组（含连接 / 外观 / 备忘录 / 消息通道）以 [shell SPEC](../shell/SPEC.md) 为准。
- 不做账号、云同步、通知设置（本期无通知）。

## 8. 降级与减少动效

### 8.1 动态形象加载失败

- 显示 `poster.webp`（图集首帧）；气泡/录音不受影响。
- manifest 非法、图集解码失败、尺寸与 `cols/cell` 不匹配，都走同一条降级路径，不阻塞录音。
- 静默降级，不向用户报错；本地记录一次 `pet_error`。

### 8.2 减少动效

- 系统 `prefers-reduced-motion: reduce` 或设置开启：
  - 去掉随机 idle、弹跳、闪光；
  - 保留状态切换的即时表情（交叉淡入 120ms）；
  - 保留麦克风/AI 的按钮反馈；
  - 睡觉/醒来用静态姿势切换。

### 8.3 低电量/低内存

- 低电量：idle 间隔加倍，粒子关闭，保留 AI/麦克风反馈。
- 低内存/后台被杀：恢复上次保存状态；不重复问候。
- 存储失败：本次会话继续，设置页提示“这次记不住”。

## 9. 无障碍

- 宠物舞台提供可读标签：“小跟班，正在陪伴”；状态变化用 `aria-live="polite"` 简短播报，最多 1 条/30 秒。
- 宠物不提供触摸互动，因此设置页也不提供摸摸/戳替代按钮。
- 气泡文字对比 ≥4.5:1；不只用颜色表达心情。
- 计时/录音状态有文字，不只波形。
- 减少动效遵循系统设置；应用内可覆盖。
