# 情绪宠物 · 体验规格

> 本文回答“长什么样、怎么动、怎么响应”。产品规则见 [PRD.md](./PRD.md)；视觉令牌见 [standards/visual.md](../../standards/visual.md)；技术实现见 [engineering/pet-runtime.md](../../engineering/pet-runtime.md)。
> 只做手机横屏；桌面不渲染宠物。

## 1. 画布与安全区

- 设计基准：20:9 横屏（约 2400×1080）；兼容 16:9（约 1920×1080）。
- 使用 `100dvh`；左右安全区 24dp，底部手势条额外 16dp。
- 不出现横向滚动；刘海/挖孔侧内容内缩。
- 所有尺寸用 dp/相对比例，不写死像素宽度。

## 2. 布局

### 2.1 支架模式（docked）

```text
┌────────────────────────────────────────────────────┐
│  [设置]                                  [状态点]   │
│                                                    │
│   “你忙你的，我在这儿。”        ╭──────────────╮    │
│                                  │              │    │
│                                  │   宠物舞台    │    │
│                                  │  （居中偏右） │    │
│                                  │              │    │
│                                  ╰──────────────╯    │
│                   [ 按住说话 ]                       │
│  ─────────────── 安全区 ───────────────             │
└────────────────────────────────────────────────────┘
```

- 宠物舞台占宽 55–65%，垂直居中偏右；左侧留给气泡。
- 设置图标左上角 44dp；无操作 5 秒后与状态点一起淡出。
- 麦克风胶囊底部居中，宽 ≥220dp、高 72dp；距底部安全区 16dp。
- 气泡最多 2 行，位于宠物左上方；不与宠物重叠。
- 屏幕常亮时每 2 分钟无操作暗到 70%，触摸恢复。

### 2.2 手持模式（handheld）

```text
┌────────────────────────────────────────────────────┐
│  [设置]                                            │
│                  ╭──────────────╮                  │
│     气泡          │   宠物舞台    │                  │
│                  │  （上 2/3）   │                  │
│                  ╰──────────────╯                  │
│  [取消]                                  ( 🎤 )    │
│  ─────────────── 安全区 ───────────────             │
└────────────────────────────────────────────────────┘
```

- 宠物舞台占上 2/3；底部 1/3 为控制区。
- 麦克风圆形按钮右下，直径 96dp；距右/底安全区 24dp。
- 取消按钮左下，≥64dp；仅录音时出现。
- 设置图标左上，常显但低对比。
- 气泡位于宠物左上，最多 2 行；录音时隐藏。

### 2.3 姿态切换

- 触发：充电 + 静止 10 秒 → 支架；拿起/移动 → 手持；手动选择优先。
- 动画：320ms spring；宠物位置、缩放、按钮形态同步过渡；不跳位。
- 录音中不切换；等录音结束 300ms 后再切。
- 不确定时保持上次模式，30 秒内不反复。

## 3. 状态机

### 3.1 状态

| 状态 | 含义 | 允许的下一步 |
| --- | --- | --- |
| `idle` | 安静陪伴，随机 idle 动作 | 互动 / 倾听 / 睡觉 / 后台 |
| `interacting` | 摸摸/戳一戳反馈 | idle（冷却后） |
| `listening` | 麦克风录音中 | celebrating / concerned / idle |
| `celebrating` | 转写成功后的短暂开心 | idle |
| `concerned` | 转写失败的短暂关心 | idle |
| `sleeping` | 夜间睡眠 | idle（触摸唤醒） |
| `away` | App 后台/不可见 | idle（回前台） |

### 3.2 转移

| 从 | 事件 | 到 | 动作 |
| --- | --- | --- | --- |
| away | 回前台 | idle | 先眨眼一次；>6h 先播问候 |
| idle | 触摸（摸摸/戳） | interacting | 对应动作 + 轻震 |
| interacting | 2 秒无互动 | idle | 回到呼吸 |
| idle | 麦克风开始 | listening | 竖耳、停止随机 idle |
| listening | 转写成功 | celebrating | 2 秒开心 + 闪光 |
| listening | 转写失败 | concerned | 1.5 秒歪头/耳朵下垂 |
| listening | 取消/后台 | idle | 眨眼，不表达失望 |
| idle | 23:00–06:00 且 5 分钟无互动 | sleeping | 慢慢趴下、闭眼 |
| sleeping | 触摸/麦克风开始 | idle / listening | 轻轻醒来 |
| 任意 | App 后台 | away | 暂停动画与计时 |

### 3.3 心情与表现

| 心情 | 触发 | 表现 |
| --- | --- | --- |
| content | 默认 | 呼吸、眨眼、偶尔张望 |
| happy | 摸摸 3 秒 / 成功 | 眼睛弯、尾巴快摆、爱心 |
| curious | 戳一戳 / 新声音 | 歪头、盯手指 |
| sleepy | 夜间/低精力 | 打哈欠、眼皮下沉 |
| listening | 麦克风录音 | 竖耳、身体前倾、轻微摆动 |
| proud | 转写成功 | 挺胸、闪光、短跳 |
| concerned | 转写失败 | 耳朵下垂、歪头 1.5 秒 |

## 4. 触摸与手势

| 手势 | 识别 | 反馈 | 冷却 |
| --- | --- | --- | --- |
| 摸摸 | 热区内滑动，1.5 秒内 ≥2 次方向变化 | 靠近、闭眼、轻震；3 秒开心 | 2 秒 |
| 戳一戳 | 点按 <250ms | 看向手指、好奇 | 2 秒 |
| 快速连戳 | 2 秒内 3 次点按 | 扭头 3 秒，之后恢复 | 5 秒 |
| 拖拽/捏合 | 不识别 | 无 | — |

- 热区 = 宠物舞台 + 24dp；不要求点中身体。
- 多指只认第一根；录音中禁用互动。
- 触摸反馈 ≤100ms；大动画不阻塞输入。

## 5. 气泡与文案

### 5.1 规则

- 最多 1 条/30 秒；自动消失 4 秒；2 行以内。
- 录音/转写中不出气泡；错误由麦克风模块提示。
- 不用感叹号堆叠；不撒娇过度；不制造愧疚。
- 文案可带名字，但名字不写日志。

### 5.2 文案库（P0 示例）

| 场景 | 文案 |
| --- | --- |
| 初次见面 | “你来了。叫我什么？” |
| 默认名 | “那我就叫小跟班。” |
| 长时间未操作 | “你忙你的，我在这儿。” |
| 被摸 | “嗯，这里。” |
| 连续摸 | “再摸一下也可以。” |
| 被戳 | “嗯？” |
| 快速连戳 | “好啦好啦，我转过去。” |
| 回来（6h+） | “回来啦。” |
| 回来（3d+） | “我刚刚在打盹，没听见你。” |
| 夜间 | “夜深了，我陪你一会儿。” |
| 麦克风开始 | （不出气泡，竖耳） |
| 转写成功 | “收到。” |
| 转写失败 | “没听清，再来一次？” |
| 重置确认 | “要让我重新认识你吗？” |

禁止文案：

- “你怎么才回来。”
- “你不理我。”
- “我饿了，快喂我。”
- “今天还没签到。”
- “你落后了。”

## 6. 首次见面流程

```text
进入宠物页
  → 宠物从睡梦中醒来（1.5s）
  → 伸懒腰 + 眨眼
  → 气泡：“你来了。叫我什么？”
  → 输入框 + 默认名“小跟班” + “先这样叫我”
  → 确认/跳过
  → 宠物点头/轻叫
  → 进入 idle
```

- 不请求任何权限。
- 输入框自动聚焦但不强制键盘；可直接跳过。
- 名字 1–8 字符；实时显示剩余字数。
- 保存失败不阻塞，使用默认名。

## 7. 设置页

| 分组 | 项 | 默认 | 说明 |
| --- | --- | --- | --- |
| 宠物 | 名字 | 小跟班 | 1–8 字符 |
| 宠物 | 重置宠物 | — | 二次确认，不可撤销 |
| 反馈 | 震动 | 开 | 触摸/录音/成功/失败 |
| 反馈 | 声音 | 关 | 不绕过系统静音 |
| 显示 | 减少动效 | 跟随系统 | 可手动强制 |
| 姿态 | 自动/支架/手持 | 自动 | 手动优先 |
| 显示 | 屏幕常亮 | 仅充电时 | 支架模式生效 |
| 关于 | 隐私说明 | — | 本机存储、卸载丢失 |
| 关于 | 版本/许可证 | — | 只读 |

- 入口：舞台左上角设置图标；一次点击。
- 设置页为底部抽屉/整页，横屏左右分栏；返回不丢状态。
- 不做账号、云同步、通知设置（本期无通知）。

## 8. 降级与减少动效

### 8.1 动态形象加载失败

- 显示静态宠物图 + CSS 呼吸（仅 opacity/transform）。
- 摸摸/戳仍有轻震和气泡。
- 麦克风联动只保留气泡/状态点，不阻塞录音。
- 静默降级，不向用户报错；本地记录一次 `pet_error`。

### 8.2 减少动效

- 系统 `prefers-reduced-motion: reduce` 或设置开启：
  - 去掉随机 idle、弹跳、爱心粒子、闪光；
  - 保留状态切换的即时表情（交叉淡入 120ms）；
  - 保留触摸/录音的按钮反馈；
  - 睡觉/醒来用静态姿势切换。

### 8.3 低电量/低内存

- 低电量：idle 间隔加倍，粒子关闭，保留触摸反馈。
- 低内存/后台被杀：恢复上次保存状态；不重复问候。
- 存储失败：本次会话继续，设置页提示“这次记不住”。

## 9. 无障碍

- 宠物舞台提供可读标签：“小跟班，正在陪伴”；状态变化用 `aria-live="polite"` 简短播报。
- 摸摸/戳一戳提供替代按钮（设置页或辅助功能层），不强制手势。
- 气泡文字对比 ≥4.5:1；不只用颜色表达心情。
- 计时/录音状态有文字，不只波形。
- 减少动效遵循系统设置；应用内可覆盖。
