# 情绪宠物 · 一页摘要

> 一只住在手机里的黏土小宠物：会想你、听你说话、等你回来。
> 本期定位：**纯陪伴**。不做任务看板，不做饥饿/签到/排行榜。

## 本期做什么

- 首次见面、命名、默认名。
- 桌面陪伴：呼吸、眨眼、张望、伸懒腰、夜间睡觉。
- 触摸互动：摸摸、戳一戳。
- 情绪与记忆：心情、精力、亲密度（隐藏）、离开后回来、跨重启保存。
- 双姿态：支架模式、手持模式；横屏自动支架、竖屏自动手持，设置可手动覆盖；传感器判定 P1。
- 麦克风联动：契约保留、本轮未实现（P1）。
- 设置：名字、震动、减少动效、姿态（docked/handheld）、屏幕常亮（默认开，最长 2 小时可调）、自动变暗（默认 5 分钟可调）、重置、关于/隐私；声音暂未接入。

## 不做什么

- 喂零食、小游戏、服装、社交、排行榜（P1/P2）。
- AI 工作状态映射（P2；本期不把宠物变成状态指示灯）。
- 桌面端宠物渲染。
- 单独竖屏布局；跨端响应式。

## 成功标准

- 7 日回访率 ≥ 40% `[假设]`；每次打开 ≥1 次有效互动 `[假设]`。
- 5 人试用中 ≥4 人用“治愈/可爱/想摸”描述 `[假设]`。
- 真机 60fps；触摸反馈 ≤100ms；气泡主动关闭率 <20%。
- 无通知、无红点、无惩罚型文案。

## 平台

- 手机端（Android 优先；不强制横竖屏），支架/手持两种姿态。
- 桌面端不渲染宠物；麦克风相关状态由桌面浮窗负责。

## 已定决策

- 纯陪伴优先，AI 状态映射后置（D20）。
- 柔软黏土/手绘矢量，Rive 状态机（D23）。
- 双姿态：支架 + 手持（D22；方向自动 + 手动覆盖，D35；不强制横竖屏，D33）。
- 存档：plugin-store + PetStorage adapter（D28）。
- 戳/摸规则与麦克风延后（D30/D31）；宠物为手机默认主界面（D32）。
- 不制造焦虑：无签到、无饥饿、无红点（[product/principles.md](../../product/principles.md)）。
