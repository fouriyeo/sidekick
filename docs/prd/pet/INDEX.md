# 情绪宠物 · 一页摘要

> 一只住在手机里的黏土小宠物：会想你、听你说话、等你回来。
> 本期定位：**纯陪伴**。不做任务看板，不做饥饿/签到/排行榜。

## 本期做什么

- 首次见面：宠物固定叫「小跟班」，主动打招呼；不提供命名/改名（2026-11-05 下线）。
- 桌面陪伴：呼吸、眨眼、张望、伸懒腰、夜间睡觉。
- 情绪与记忆：心情、精力、离开后回来、跨重启保存。
- 单竖屏布局（D62）：宠物居中略偏上，麦克风 56px 高宽胶囊；Android 锁竖屏，浏览器 dev 也按竖屏渲染。
- 麦克风联动：已下线（D77）；录音全程宠物不变，只保留录音时静音 AI 音效/触感的 `micListening` 门禁。
- 设置：震动、减少动效、屏幕常亮（默认开，最长 2 小时可调）、自动变暗（默认 5 分钟可调）、重置、关于/隐私；无名字入口；声音暂未接入。

## 不做什么

- 喂零食、小游戏、服装、社交、排行榜（P1/P2）。
- 触摸互动（点击/长按/抚摸宠物无任何反应，D69）；后续如需恢复另行评审。
- AI 工作状态映射（P2；本期不把宠物变成状态指示灯）。
- 桌面端宠物渲染。
- 横屏 / 平板 / 折叠屏专用布局；跨端响应式。

## 成功标准

- 7 日回访率 ≥ 40% `[假设]`。
- 5 人试用中 ≥4 人用“治愈/可爱/愿意放在桌边”描述 `[假设]`。
- 真机 60fps；按钮反馈 ≤100ms；气泡主动关闭率 <20%。
- 无通知、无红点、无惩罚型文案。

## 平台

- 手机端（Android 优先；只支持竖屏），单套竖屏舞台。
- 桌面端不渲染宠物；麦克风相关状态由桌面浮窗负责。

## 已定决策

- 纯陪伴优先，AI 状态映射后置（D20）。
- 宠物美术是 OpenPets schema 2 帧动画图集（WebP + poster，D57b）；不用 Rive / SVG 运行时。
- 单竖屏布局（D62）：只有一套竖屏壳，无方向检测与姿态切换。
- 存档：plugin-store + PetStorage adapter（D28）。
- 触摸互动已下线（D69，取代 D30）；麦克风联动已下线（D77）；首次命名/改名下线（2026-11-05）：固定显示「小跟班」，`onboarded` 只表示是否已见过面；宠物为手机默认主界面（D32）。
- 不制造焦虑：无签到、无饥饿、无红点（[product/principles.md](../../product/principles.md)）。
