# 情绪宠物 · 验收清单

> 只列可执行用例。产品规则见 [PRD.md](./PRD.md)，体验细节见 [SPEC.md](./SPEC.md)。
> 本轮范围：宠物 P0（单竖屏布局、plugin-store 存档、屏幕常亮）；触摸互动已下线（D69）、麦克风联动已下线（D77），只保留「无反应/无变化」回归；首次命名已下线（2026-11-05），只保留「无命名弹窗/旧 name 忽略」回归；done 循环与无声呐环为 D77 新增验收点。
> 设备基线：Realme RMX3370 / Android 13 / 竖屏；16:9 与 20:9 竖屏各跑一遍。

> 首次命名/改名已下线（2026-11-05）：宠物固定显示「小跟班」，不再收集/保存用户自定义名字；`onboarded` 只表示「是否已见过面」。

## 11. 执行说明

- 每条用例记录：设备、系统版本、屏幕比例、姿态、结果、截图/录屏。
- 性能用例用 Android Studio Profiler / Chrome Performance 记录帧率和长任务。
- 隐私用例用抓包工具确认无网络请求；检查应用私有目录无音频文件。
- P0 全过才可发版；本轮 P0 指宠物范围内用例（触摸互动仅保留 PET-AC-48 无反应回归；麦克风联动已下线（D77），只保留 PET-AC-51 回归；屏幕常亮已落地，按 P1 回归）；P1 失败需记录 issue 和影响范围。
- 发现规则冲突，先改 PRD/SPEC，再改实现；不要只改测试。
