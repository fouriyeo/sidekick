# 情绪宠物 · 验收清单

> 只列可执行用例。产品规则见 [PRD.md](./PRD.md)，体验细节见 [SPEC.md](./SPEC.md)。
> 本轮范围：宠物 P0（方向自动姿态 + 手动覆盖、plugin-store 存档、屏幕常亮）；无麦克风、声音，相关用例标 P1/未覆盖。
> 设备基线：Realme RMX3370 / Android 13 / 横屏；16:9 与 20:9 各跑一遍。

## 1. 首次与命名

| ID | 优先级 | 类型 | Given | When | Then |
| --- | --- | --- | --- | --- | --- |
| PET-AC-01 | P0 | 功能 | 无存档（首次安装）、未连接电脑 | 打开宠物页 | 宠物醒来并邀请命名；不请求任何权限 |
| PET-AC-02 | P0 | 功能 | 命名页 | 输入 1–8 字符并确认 | 名字立即生效；杀进程重启后仍保留 |
| PET-AC-03 | P0 | 功能 | 命名页 | 点“先这样叫我” | 使用默认名“小跟班”，进入 idle |
| PET-AC-04 | P1 | 边界 | 命名页 | 输入 9 个字符/换行/空格 | 截断或拒绝并提示；不崩溃 |
| PET-AC-05 | P1 | 异常 | 本地存储不可写 | 确认名字 | 本次会话使用默认名；提示“这次先不保存” |

## 9. 执行说明

- 每条用例记录：设备、系统版本、屏幕比例、姿态、结果、截图/录屏。
- 性能用例用 Android Studio Profiler / Chrome Performance 记录帧率和长任务。
- 隐私用例用抓包工具确认无网络请求；检查应用私有目录无音频文件。
- P0 全过才可发版；本轮 P0 指宠物范围内用例（麦克风/声音不计入；屏幕常亮已落地，按 P1 回归）；P1 失败需记录 issue 和影响范围。
- 发现规则冲突，先改 PRD/SPEC，再改实现；不要只改测试。
