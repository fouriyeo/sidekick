# Token 用量看板 · 体验规格

> 本文回答「页面长什么样、数字怎么格式化、空态/错态说什么」。产品规则见 [PRD.md](./PRD.md)；技术方案见 [engineering/token-usage-pricing.md](../../engineering/token-usage-pricing.md)。
> 视觉沿用 [tokens.css](../../../app/src/shared/styles/tokens.css) 的 hex 语义令牌；颜色只是第二线索，文字与数字始终在场。

## 1. 桌面布局（1180 / 960）

### 1.1 页面骨架

```text
┌────────────────┬──────────────────────────────────────────┐
│ 224 玻璃侧栏    │  sticky 玻璃工具栏（滚动后 17/600 紧凑标题） │
│ 概览            │  用量（34/600）        [区间分段] [刷新]     │
│ 内容            │                                            │
│ 用量 ◀          │  花费      Token      （2×2 汇总）          │
│ 设置            │  会话      缓存命中                        │
│                 │                                            │
│ ● 服务 47810    │  [客户端 | 会话 | 模型]（胶囊分段）          │
│ ● 手机 1 台     │  分组行：label · 副行        Token · 金额    │
│ ● AI 空闲       │  价格表                                    │
│                 │                                            │
│                 │  花费趋势（近 30 天 · 合计）                 │
│                 │  Token 构成（五桶行）                       │
└────────────────┴──────────────────────────────────────────┘
```

- 桌面壳是 Liquid Glass v2（D86）：**224 玻璃侧栏** + **sticky 玻璃工具栏**；工具栏未滚动透明、滚动 > 6px 变玻璃胶囊并淡入 17/600 紧凑标题，进页时大标题 34/600。
- 内容列最大宽 **730**、左右 **28** 居中、单列；不写 `lg` 两栏；960 窗宽不横向滚动。白卡 16 圆角、行 54、行标题 15，内容层不透明。
- 页头右侧只放区间分段与刷新；没有说明句、状态胶囊；价格表入口在分组列表卡尾，不新增导航项。
- 没有页脚；内容区独立滚动。
- 默认区间 = 近 7 天；切视图再回来保持本次会话的选择（不落盘）。

### 1.2 汇总（2×2）

| 汇总格 | 主数值 | 备注 |
| --- | --- | --- |
| 花费 | `¥29.84`；估算时标 `≈` | 成本来源 `unknown` 时显示「—」，不编造 0 |
| Token | 五桶和，紧凑格式（万/亿） | 不含 ASR |
| 会话 | 会话数 | 跨天同 id 只算 1 个 |
| 缓存命中 | `97.2%` | 分母 0 显示「—」 |

- 2×2 网格（`dsl-card`），标签 12、数值 30/600 + tabular；数字换区间时 400ms 补间（首帧直接显示终值，不数数）；不显示环比、不画缓存环。

### 1.3 花费趋势

- 「花费趋势」组：固定近 30 天（`days[].slice(-30)`），按天**花费**画柱（div/CSS）；只画账本真实存在的日期，不补零。
- 柱高按当天花费归一化到峰值；组标题右侧显示「合计 ¥x」；今日柱用 `--ios-blue`、其余 `--signal`、0 值用 hairline；柱阵 420ms / 20ms 错峰入场（只在日期窗口变化时重播，同区间刷新不重播），带 `aria-label` 文字摘要（合计 / 日均）。
- 只画极淡网格线，不画坐标轴、不加循环动画；无数据时不画空坐标轴。

### 1.4 缓存命中

- 只在 2×2 汇总里显示命中率；命中率 = 缓存读 ÷（输入 + 缓存读 + 缓存写），分母 0 显示「—」。不再单独做环形卡。

### 1.5 Token 构成

- 「Token 构成」组：五桶逐行（缓存读 / 输入 / 输出 / 缓存写 / 推理），为 0 的桶省略。
- 每行「桶名 + 右侧「Token · 占比」」；不画堆叠条和图例。

### 1.6 分组列表

- 三视角胶囊分段（玻璃轨道 + spring 滑块）：客户端 / 会话 / 模型；默认会话；切换只换行，不改变上方汇总。
- 行结构：label（+ 可选副行）→ 右侧「Token · 金额」；估算行金额带 `≈`；不显示状态点、占比条与小徽标。
- 客户端：只显示 DSH 真实数据；不显示「未接入」占位行。
- 会话：label 为标题或「会话 + 8 位短 id」；副行为「最近 MM-DD HH:mm · N 次调用」。
- 模型：label 为模型 id；副行为「接入方 · 缓存命中 x.x%」；金额按账本/估算，估算行带 `≈`。
- 「其他 N 个」行：label「其他 N 个会话/模型」，只显示 Token/金额，不可展开。
- 卡尾单一动作行：「价格表」/「价格表 · 待更新」，点击打开价格面板。
- 空组一行结论（如「这个区间没有数据」「模型分组已在电脑端关闭」）；分组切换立即生效，不做加载态。

### 1.7 模型价格面板（右侧 Sheet，460px）

| 区域 | 内容 |
| --- | --- |
| 标题 | 「模型价格」；说明「只拉取公开价格目录，不上传用量、模型名或任何本机数据。」 |
| 状态 | 来源（OpenRouter 公开目录 / 内置价格表 / 本地覆盖 / 多来源合并）、更新（刚刚更新 / N 分钟前 / N 小时前 / N 天前 / 从未更新）、模型数、汇率（1 USD = x.xxxx CNY）、自动刷新、手机模型分组 |
| stale | 超过 7 天：琥珀提示「价格表已超过 7 天未更新；估算可能偏离账单。」 |
| 上次失败 | `lastError` 一行「上次刷新失败：…」 |
| 刷新 | 「刷新价格」按钮；进行中「刷新中」+ 旋转图标并禁用；最短 60 秒，未到提示「刚刚刷新过，稍后再试。」 |
| 价格表 | 列：模型 / 接入方 / 输入 / 输出 / 缓存读 / 来源；¥/1M，<1 保留 3 位；无价时整表空态 |
| 开关 | 「自动刷新价格」（打开用量页时若超过 24 小时，后台刷新一次）、「在手机显示模型分组」（只同步模型 ID 与接入方，不含提示词/路径/用量原文） |
| 脚注 | 单价单位与来源说明；实际花费以 DSH 账本为准，估算仅作参考 |

## 2. 手机布局（390 / 360 / 320）

```text
┌ 状态条 44 ──────────────────────────────┐
│ ‹ 返回设置  用量                        │ ← 页头
│             DSH 本机账本 · 不上传        │
├──────────────────────────────────────────┤
│  [今天] [7 天] [30 天] [半年]            │ ← 分段 44
│  ┌ 近 7 天 · 总 TOKEN        7 天有数据 │
│  │ 1.23 亿                                │
│  │ 花费 ¥29.84 · 缓存 97.2% · 调用/会话  │ ← 汇总卡
│  ├ 近 14 天花费（柱阵 + 日均 + 起止日期）┤
│  ├ Token 构成（五桶 + 占比）─────────────┤
│  ├ 分组 [客户端|会话|模型] + 行 ────────┤
│  ├ 价格表  N 个模型有价 · 更新于 …      │
│  └ 隐私说明（不含提示词/路径/cwd）      │
└──────────────────────────────────────────┘
```

- 页头：返回「返回设置」+ 标题「用量」+ 副标题「DSH 本机账本 · 不上传」；标题 17/400。
- 分段：4 档等宽、min-height 44、圆角容器；选中 `bg-card` + 文字加深，不只用颜色。
- 汇总卡：大数 30px + 「{区间} · 总 TOKEN」+ 右侧「N 天有数据」；下方三指标 11px 标签 / 15px 数值：花费（估算带 `≈`）、缓存命中、调用 / 会话。
- 近 14 天花费：76px 柱阵（柱 `--signal/70`），头部「近 14 天花费」+「日均 ¥x」，底部起止日期。
- Token 构成：堆叠条 + 图例（缓存读/输入/输出/缓存写/推理，为 0 省略）。
- 分组：卡片头「分组」+ Tab；行 = label（14px）+ Token（13px）；第二行 sub + sharePct + 金额（估算带 `≈`）+ 占比条；空组「这个区间没有可展示的分组。」；客户端 Tab 提示「Claude Code / Codex 解析器在 P1」；模型关闭时提示「手机模型分组已在电脑端关闭。」。
- 价格表卡：`N 个模型有价 · 更新时间 · 成本来源` + 右侧「在电脑上刷新」；**不提供刷新**，模型分组关闭时显示「模型分组已在电脑端关闭」。
- 底部隐私说明：「只显示聚合数据：不包含提示词、文件路径、cwd 或工具参数。实际花费以 DSH 账单为准，缺价时按价格表估算并标 ≈。」
- 断连/无快照：等待卡「还没连上电脑」/「电脑还没回应」/「正在读账本…」+ 主按钮「去连接」或「重试」。
- 320 宽：无横向滚动；数字 tabular；模型行 sub 可换行，不截断关键金额。

## 3. 数值与文案

### 3.1 格式化（复用 `app/src/shared/lib/usage.ts`，不另写）

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| Token（卡片/分组） | 紧凑：≥1 亿 → `X.XX 亿`；≥1 万 → `X.X 万`；否则千分位 | `1.23 亿` / `384,120` |
| Token（完整） | 千分位完整数字 | `12,345,678` |
| 金额 | `¥` + 2 位小数；0 < 金额 < 0.01 → `<¥0.01`；估算前加 `≈` | `¥29.84` / `<¥0.01` |
| 不可用金额 | 「—」 | `—` |
| 单价 | ¥/1M；<1 保留 3 位，其余 2 位；无价「—」 | `¥0.006` / `¥2.50` |
| 百分比 | 1 位小数，null → 「—」 | `97.2%` |
| 日期 | `MM-DD`（看板内）；跨年补 `YYYY-MM-DD` | `11-06` |
| 时间 | `HH:mm`（24 小时制） | `09:20` |
| 更新时间 | 刚刚更新 / N 分钟前 / N 小时前 / N 天前 / 从未更新 | `3 小时前` |

### 3.2 文案表

> 下表是文案方向；V1 收口后界面以一行结论为主（不写解释性长句），逐字以当前实现为准。

| 场景 | 文案 |
| --- | --- |
| 账本缺失 | 「还没找到 DSH 账本。先把 DSH 打开一次；账本只在本机读取。」 |
| 账本格式异常 | 「账本格式暂时认不出来。DSH 正在写入时可能短暂读不到；稍后点重试。」 |
| 文件过大 | 「账本文件异常偏大。已超过 64MB 保护上限，看板停止读取。」 |
| 读取失败但有缓存 | 「展示上次成功读取的缓存。」 |
| 正在读取 | 「正在读取本机账本…」 |
| 区间无数据 | 「这个区间没有可展示的分组。」（分组）/ KPI 全 0 + 覆盖说明 |
| 部分缺价 | 「部分日期缺价，金额为已知部分。」 |
| 全部缺价 | 金额「—」+「没有可用价格」 |
| 价格过期 | 「价格表已超过 7 天未更新；估算可能偏离账单。」 |
| 刷新中 / 限频 | 「刷新中」/「刚刚刷新过，稍后再试。」 |
| 刷新失败 | 「上次刷新失败：网络不通 / 请求超时 / 目录格式变化。」 |
| 手机未连接 | 「还没连上电脑」「电脑还没回应」+ 重试 |
| 模型分组关闭 | 「手机模型分组已在电脑端关闭。」 |
| 手机超时 | 「电脑没有回应，点这里重试」 |
| 未接入客户端 | 「未接入」 |
| 其他行 | 「其他 N 个会话」/「其他 N 个模型」 |

禁止：错误码、堆栈、「暂无数据」（单独出现）、长时间「加载中」、编造 0 金额。

## 4. 视觉与状态

- 颜色/圆角/边框全部取语义令牌：桌面用 `.desktop-ios` 的语义类（白卡 `--card` + `--card-shadow`、hairline `--border`、强调 `--signal`）；估算/过期用 `--decide`；失败用 `--destructive`。深浅主题两套都必须成立。
- 字体：桌面用系统栈（`-apple-system`，不随包字体）；手机 `.mobile-clean` + 随包 MiSans Normal 400（D81），标题 17、卡片 16、正文 13、行高 1.45。
- 图表只用 div/CSS（花费柱阵）；不引图表库、不写 SVG 数据图、不用 `oklch` / `color-mix` / CSS `translate`。
- 状态：默认 / 加载中 / 刷新价格中 / 读取失败 / 空 / 断连；价格刷新不遮罩整页，只改按钮与面板内状态。
- `prefers-reduced-motion`：去掉入场与柱状增长动画，数字直接呈现。
- 无障碍：区间/分组用可聚焦按钮组；每张卡 `aria-label` 含数值；价格状态用 `aria-live="polite"`；图表提供文字摘要（「近 30 天共 N 天有数据，峰值 11-05」）。

## 5. 交接清单

- [ ] 桌面 4 项导航与 ⌘1–⌘4 生效，⌘3=用量；1180/960 单列、内容最大宽 720、无溢出。
- [ ] 四区间、2×2 汇总、分组列表、花费趋势、Token 构成、价格面板全部接真数据；无页脚 / 说明句 / 状态胶囊。
- [ ] `≈`、`—`、覆盖标注、缺价说明、读取缓存提示在真实/畸形账本下都出现正确。
- [ ] 手机设置入口、返回键、录音拦截、断连等待卡、模型开关关闭提示可演示。
- [ ] 深浅双主题 + 320 宽 + MiSans 字体走查通过。
- [ ] 无外部请求（除 OpenRouter 价格目录），无图表库、无 SVG 数据图。
