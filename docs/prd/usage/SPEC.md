# Token 用量看板 · 体验规格 v2

> v2（2026-11-06，D97 桌面 / D98 手机）重做两端页面：桌面宽幅「深潜仪表」、手机紧凑仪表。
> 取代 v1 的 2×2 汇总卡、固定近 30 天柱阵、桌面 730 单列、手机近 14 天柱阵与卡片堆。
> 数据口径、协议、隐私边界不变；产品规则见 [PRD.md](./PRD.md)，验收见 [ACCEPTANCE.md](./ACCEPTANCE.md)。

## 1. 桌面布局（1180 / 960）

### 1.1 页面骨架

```text
┌────────────────┬──────────────────────────────────────────────┐
│ 224 玻璃侧栏    │  用量（17/600 compact）  [今天 7天 30天 半年] ⟳ │
│ 概览            │  近 7 天花费                    10-31 – 11-06 │
│ 语音            │  ¥29.81  ↑12.3% 较上期   Token 4.81亿 会话 15 缓存 98.2% │
│ 内容            │  ─────────────────────────────────────────── │
│ 用量 ◀          │  每日花费                             日均 ¥4.26 │
│ 设置            │  [花费剖面：折线 + 面积 + y 轴 + 网格 + 今日点]     │
│                 │  ─────────────────────────────────────────── │
│ ● 服务 47810    │  Token 构成（光谱 + 5 行）   客户端 会话 模型  按花费 │
│ ● 手机 1 台     │  [五桶光谱]                  [账本行 + 占比条]      │
│ ● AI 空闲       │  [价格表 · 模型数 · 更新]    [其他会话]            │
└────────────────┴──────────────────────────────────────────────┘
```

- 用量页是桌面 **730 单列的明确例外**（D97）：`PageShell size="wide"` 最大宽 956，左右 28 后约 **900 内容**；`bottomGap="compact"` 底部 24；1180×760 首屏不裁切。
- 页头用 `PageHeader compact`：**不渲染 34/600 大标题**，sticky 工具栏 17/600 标题常显；右侧只放区间 tab 与刷新；保留 `sr-only h1`。
- 无白卡、无组标题、无页脚：区块用 hairline `--border` 分隔；内容区独立滚动。
- 960 窗宽：`max-width: 1079px` 断点下 hero 读数换行、下半区单列（账本在前、构成 + 价格在后），允许纵向滚动、不横向溢出。
- 默认区间 = 今天（D102）；同会话切走再回来保持选择（不落盘）。

### 1.2 花费 hero

| 元素 | 规格 |
| --- | --- |
| 标签 | 「今天 / 近 7 天 / 近 30 天 / 近半年」+「花费」；12 号次级灰 |
| 区间 | 右上 `MM-DD – MM-DD`（单日只写 `MM-DD`）；10.5 号等宽 |
| 花费 | 58/500 等宽，`¥` 22 号；估算/混合前缀 `≈`；`costSource=unknown` 显示「—」，不编造 0 |
| 环比 | 上期 > 0 且金额已知才显示：`↑/↓/→ + 1 位小数 + 较上期`；涨珊瑚 `--usage-up`、跌薄荷、持平灰；补间 400ms（首帧直接显示终值） |
| 读数 | 右侧三列：Token（紧凑格式）/ 会话 / 缓存命中（`—` 当 null）；标签 11.5、数值 23 等宽；列间 hairline |
| 缓存提示 | 账本读取失败但有缓存时一行「展示上次成功读取的缓存」 |

### 1.3 花费剖面

- 数据：协议 `days` 是「最近最多 180 个真实日期」，不是当前区间；两端用 `shared/lib/usage-chart.ts` 的 `daysForRange(days, range, generatedAt)` 按区间过滤后再画（今天 = 1 天 / 7 / 30 / 180），只画账本真实存在的日期，不补零。
- 面积 + 折线：SVG `viewBox 900×196`，左轴 40 / 顶 14 / 底 170；Catmull-Rom 平滑，面积渐变从 `--usage-c1` 26%（浅色 13%）到 0。
- 坐标轴：只画 y 轴（2 条网格 + 基线，取整刻度 `¥0 / ¥x / ¥y`），x 轴只标起止 + 中间 4 个日期；180 天线宽 1.35。
- 参考线：日均虚线；峰值标注金额（峰值是今天则跳过）。
- 今天：竖虚线 + 空心点 + 呼吸环（3.2s，reduced-motion 冻结）；最后一段用虚线，表示今天未过完。**最后一天不是今天**（旧快照）时不做「今天」标记。
- 单日：退化为「今天柱 + 昨日基准虚线 + `昨天 ¥x`」，不画折线。
- 悬停：十字线 + 点在点上 + 气泡（日期 / `¥x` / Token）；高点气泡自动翻到点下方；离开即消失。
- 动画：描线 `pathLength` 1.05s，面积淡入；切区间重播；reduced-motion 直接定格。
- 无障碍：`role="img"` + aria-label（区间/合计/日均/最高日期金额）+ `sr-only` 每日表（日期/花费/Token）。
- 缺价/全 0：不画空坐标轴，一行「这个区间还没有记账金额」。

### 1.4 缓存命中

- 只在 hero 读数里显示；命中率 = 缓存读 ÷（输入 + 缓存读 + 缓存写），分母 0 显示「—」；不做环形卡。

### 1.5 Token 构成

- 一条 10px 光谱（五桶连续占比，段间 1px 缝，圆角 5）+ 5 行图例。
- 每行「色块 7px / 桶名 / Token 紧凑值 / 占比 1 位小数」；为 0 的桶省略；合计由最大余数法保证 **100.0%**。
- 缓存读固定 `--usage-c1`（薄荷）；输入 c2、输出 c3、缓存写 c4、推理 c5；**不再用 `--chart-2` 蓝**。

### 1.6 分组账本

- 下划线 tab：客户端 / 会话 / 模型；默认模型（D102）；右侧「按花费」；切换只换行，不重新请求。
- 行：label（+ 后端 `sub`）→ 3px 占比条 → Token → 金额；估算金额带 `≈`。
- 排序：**返回的 Top 行内按金额降序**；`tag=other` 的「其他 N 个…」始终垫底并压暗；占比 = 行金额 ÷ 组内金额（组内全 0 退回 Token）。
- 后端按金额降序选取 Top 8（D102，同额再按 Token）；前端仍按金额排序兜底，不编造行、不拆「其他」。
- 客户端行不显示副行；会话副行「最近 MM-DD HH:mm · N 次调用」；模型副行「接入方 · 缓存命中 x.x%」。
- 会话标签：账本 `title` 优先；缺失时只读 DSH 会话缓存的 `record.rows.title.val` 回填（不读提示词/消息），仍无才「会话 + 8 位短 id」。
- 模型分组关闭：显示一行「模型分组已在电脑端关闭」；空组：「这个区间没有数据」。

### 1.7 模型价格面板（右侧 Sheet，460px，行为不变）

- 入口：左下「价格表 / 价格表 · 待更新」+ 右侧「N 个模型 · 更新时间」；点击打开 Sheet。
- 标题/来源/更新/模型数/汇率/自动刷新/手机模型分组/stale/上次失败/刷新限频/价格表/脚注均沿用 v1（见下方文案表）。
- 价格表行按模型分组数据展示；估算只用于缺价行并标 `≈`；实际花费以 DSH 账本为准。

- 页头沿用 `PageHeader`：返回宠物 + 「用量」+ 副行「DSH 本机账本 · 不上传」；不在正文重复隐私长句。
- **无白卡**：整页 `--background` 铺底，区块用 hairline 分隔，左右 16；价格行与隐私行直接落在页面上。
- 区间与分组都用**下划线 tab**（区间 44 高、分组 36 高 / 命中区 44），与桌面同源；不再用胶囊分段。
- 320 宽无横向滚动；三列读数可缩，金额/Token `tabular-nums`。

### 2.2 花费 hero

- 标签「近 7 天花费」+ 区间日期；花费 40–42/400 等宽，估算/混合 `≈`，未知「—」。
- 环比与桌面同规则（上期 ≤0 隐藏）；涨珊瑚、跌薄荷、持平灰。
- 三列读数 Token / 会话 / 缓存命中；标签 11、数值 15。

### 2.3 花费剖面（触摸）

- 高度 150；**无 y 轴**（省空间），峰标只在 ≤31 点时显示；顶部「日均」给绝对值；`days` 同样先按当前区间过滤（今天只画当天）。
- 今天：空心点 + 末段虚线 + 竖虚线 + 静态柔光 halo（移动端不做循环呼吸动画，D58/D89；桌面端保留呼吸环）；单日：柱 + 昨日基准线；最后一天不是今天时不做今日标记。
- 触摸：`touch-action: pan-y`；水平位移 >8px 才捕获指针；原地轻点也出气泡；取最近日期显示 HTML 气泡（日期 / ¥ / Token），松手 1.2s 收起；**不劫持纵向滚动**；拖动后吞掉 click。
- 动效：描线一次性；`prefers-reduced-motion` 定格；无循环动画。
- 无障碍：`role="img"` + aria-label + `sr-only` 每日列表。

### 2.4 Token 构成

- 光谱 8px + 5 行图例；缓存读薄荷 c1；百分比最大余数合计 100.0；0 值桶省略。

### 2.5 分组

- 下划线 tab：客户端 / 会话 / 模型；模型分组关闭时**隐藏模型 tab**并给一行结论。
- 行：标题 14 + 后端 `sub` 11；右侧 Token 13 / 金额 13；底部 3px 占比条；`other` 压暗。
- 行内按金额降序、「其他」垫底（后端 Top 8 也按金额选，D102）；不显示 share% 文本、不展开。
- 空组「这个区间没有可展示的分组。」；模型关闭「模型分组已在电脑端关闭。」。

### 2.6 价格行

- 只读：「价格表」+ 右侧「N 个模型 · 更新时间」；估算/缺价/模型关闭时换成对应一句（`按价格表估算 · …` / `没有可用价格` / `模型分组已在电脑端关闭`）。
- **手机不打开价格面板、不提供刷新**；刷新在电脑上完成。

### 2.7 状态

- 未连接：「还没连上电脑。」+「去连接」。
- 已连接但无快照/超时：「电脑还没回应。」+「重试」；等待：「正在读账本…」。
- 账本缺失：「还没找到 DSH 账本，先在电脑上打开 DSH。」+「重试」。
- 有旧快照但当前未连接：正文顶部一行「电脑未连接，显示最后一次快照。」。

## 3. 数值与文案

### 3.1 格式化（复用 `app/src/shared/lib/usage.ts`，不另写）

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| Token（卡片/分组） | 紧凑：≥1 亿 → `X.XX 亿`；≥1 万 → `X.X 万`；否则千分位 | `1.23 亿` / `384,120` |
| Token（完整） | 千分位完整数字 | `12,345,678` |
| 金额 | `¥` + 2 位小数；0 < 金额 < 0.01 → `<¥0.01`；估算前加 `≈` | `¥29.84` / `<¥0.01` |
| 不可用金额 | 「—」 | `—` |
| 单价 | ¥/1M；<1 保留 3 位，其余 2 位；无价「—」 | `¥0.006` / `¥2.50` |
| 百分比 | 1 位小数，null → 「—」 | `97.2%` |
| 日期 | `MM-DD`；单日只写一个 | `11-06` |
| 更新时间 | 刚刚 / N 分钟前 / N 小时前 / N 天前 / 从未更新；手机价格行补「更新」后缀 | `2 小时前` |

### 3.2 文案表（v2 实际用词）

| 场景 | 桌面 | 手机 |
| --- | --- | --- |
| 账本缺失 | 「还没找到 DSH 账本」+ 重试 | 「还没找到 DSH 账本，先在电脑上打开 DSH。」+ 重试 |
| 账本格式异常 | 「账本格式暂时认不出来」+ 重试 | — |
| 文件过大 | 「账本文件异常偏大」+ 重试 | — |
| 读取失败 | 「读取用量失败」+ 重试 | 「电脑还没回应。」+ 重试 |
| 正在读取 | 「正在读取本机账本…」 | 「正在读账本…」 |
| 有缓存 | 「展示上次成功读取的缓存」 | 「电脑未连接，显示最后一次快照。」 |
| 区间无金额 | 「这个区间还没有记账金额」 | 「缺价，画不出花费剖面。」/「这个区间还没有花费记录。」 |
| 分组为空 | 「这个区间没有数据」 | 「这个区间没有可展示的分组。」 |
| 模型分组关闭 | 「模型分组已在电脑端关闭」 | 「模型分组已在电脑端关闭。」 |
| 价格表 | 「价格表」/「价格表 · 待更新」 | 「价格表」+ 只读 meta |

禁止：错误码、堆栈、单独「暂无数据」、编造 0 金额、没有基数的环比、「加载中」长时间停留。

## 4. 视觉与状态

### 4.1 令牌与样式位置

- 桌面：`app/src/desktop/styles/usage.css`，`.dsl-usage` 作用域；浅/深 `--usage-c1..c5`、`--usage-up`、`--usage-grid`、`--usage-glow`、`--usage-mono`；画布 `.dsl-usage-canvas`；数字 `.dsl-num`（SF Mono → Menlo 回退 + tabular）。`ios.css` / `tokens.css` 不改色板。
- 手机：`app/src/mobile/styles/usage.css`，`.mobile-usage` 作用域；`--mu-c1..c5`、`--mu-up`、hairline、`.mu-num`；`clean.css` 不改（在途改动多，D98 用独立文件）。
- 两端共用 `app/src/shared/lib/usage-chart.ts` 的刻度/路径/日期/环比/百分比/排序；不复制数学。

### 4.2 图表

- 桌面 SVG 900×196（y 轴 + 网格 + 悬停 + 今日），手机 SVG 无 y 轴（触摸 + 气泡）；**允许 SVG 数据图**（D97/D98 取代 v1 的「div/CSS only」）。
- 不引图表库；渐变用 CSS 类给 `<stop>`（不要 `stop-color="var(--x)"` 这种 presentation attribute，Safari/WebKit 不解析）。
- 今天/单日/缺价规则见 §1.3 / §2.3；`previous<=0` 不画昨日基准。
- `prefers-reduced-motion`：描线/呼吸环/面积淡入全部退化；`prefers-reduced-transparency` 不影响用量页（内容层本就不透明）。

### 4.3 交互与无障碍

- 区间/分组是 `fieldset + button[aria-pressed]`，可键盘聚焦；桌面 hover 气泡 `pointer-events:none`，不挡操作。
- 图表 `role="img"` + 完整 aria-label + `sr-only` 每日表；装饰性光谱/占比条 `aria-hidden`。
- 手机触摸目标 ≥44（tab、返回、状态动作）；剖面拖动不抢纵向滚动。
- 手机竖屏单布局，不写 landscape 断点；WebView 103 红线：不用 `:has`、CSS `translate`/`scale` 属性、`oklch`、`color-mix`、`dvh`；用 `transform`、hex/rgba、100vh。

### 4.4 状态

- 默认 / 加载 / 刷新价格中 / 读取失败 / 空 / 断连 / 旧快照；价格刷新只改按钮与面板内状态，不遮罩整页。
- 桌面错误态一行结论 + 重试；手机错误态一句 + 动作；不画空态插画。
