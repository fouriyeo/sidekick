# PRD：Token 用量看板

**版本** v0.1 · **日期** 2026-11-06 · **状态** 草稿（待评审）
**平台** 桌面（主，可交互）+ 手机（只读）
**关联** [SPEC](./SPEC.md) · [ACCEPTANCE](./ACCEPTANCE.md) · [价格与工程方案](../../engineering/token-usage-pricing.md) · [DSH 联动](../hook/PRD.md)

## 0. 一页摘要

Sidekick 把本机 DSH 已经记账的 LLM Token 用量搬进应用内：桌面新增一级页「用量」（D104 后 5 项导航里的 ⌘3），手机在宠物页顶栏直接显示「今天」花费数字，点开全屏二级页（v17 / D93，设置页不再放入口）。用户能看到今天、近 7 天、近 30 天、近半年（180 天）的 Token 总消耗、人民币金额、缓存命中率、会话与三组明细（客户端 / 会话 / 模型），以及价格表来源与刷新状态。
> v2（2026-11-06，D97/D98）：两端重做为「深潜仪表 / 紧凑仪表」——桌面宽幅、花费当主角、花费剖面、Token 光谱、带占比条的账本；手机无卡片、花费 hero、可拖动剖面。取代 v1 的 2×2 卡片、固定 30 天柱阵与手机 14 天柱阵。
> v3（2026-11-07，D108）：菜单栏左键图标弹出 320×432 只读小看板（今天/7 天 + 7 天迷你柱 + 客户端/会话/模型 Top 3 分组 + 打开用量页），复用本页同一份账本数据；仍不做菜单栏常驻数字/图标徽标，也不做 always-on-top 悬浮窗。

- **P0**：只读本机 DSH cost-meter 账本；四区间花费 hero + 花费剖面 + 五桶构成；客户端 / 会话 / 模型分组（Top 8 + 其他）；价格来源与自动/手动刷新；估算费用标 `≈`；桌面/手机双端；菜单栏左键只读小看板（D108）；空态与降级；隐私白名单。
- **不做**：菜单栏常驻数字 / 状态徽标、预算与 5 小时额度、时段/星期/热力/半年回顾等洞察、Claude Code / Codex / Qoder 日志解析、ASR 费用合并、云同步、分享图、告警。
- **铁律**：只读、不写账本、不上传；外发字段只含聚合 Token / 金额 / 日期 / 会话标题（≤80 字符）/ 模型名与接入方（受 D83 开关控制）；**绝不外发提示词、回复、工具参数、文件路径、cwd**。

## 1. 背景与目标

### 1.1 背景

- DSH 的 cost-meter 已在本机 `<DSH_HOME>/storages/cost-meter/ledger.json` 按天记账，但用户只能在 DSH 里看，Sidekick 的手机侧完全看不到「AI 今天花了多少」。
- 桌面「语音 › 语音用量」已有百炼 ASR 用量统计，但那是语音转写账单，**不是 LLM Token**，不能混成一个「总花费」。
- 调研 tokei 后确认：用户要的是「应用内看板」，不是菜单栏状态数字；V1 以信息最全的「总览」结构落地，先验证有没有人看（[设计归档](../../design/token-dashboard-v1/README.md)）。
- 不做会怎样：用户继续在 DSH 与账单之间来回切；做了会怎样：打开 Sidekick 就能回答「今天/这个月花了多少、花在哪」。

### 1.2 用户与场景

| 用户角色 | 特征 | 核心诉求 | 使用场景 |
| --- | --- | --- | --- |
| 个人开发者 | 本机跑 DSH，订阅或按量计费 | 今天/这周花了多少、哪个会话最贵 | 收工前扫一眼；月底对账 |
| 成本敏感用户 | 担心 Token 花超 | 缓存命中率、模型构成、价格是否过期 | 调模型/调 prompt 前后对比 |
| 远程/手机用户 | 手机常在手边 | 不打开电脑也能看个大概 | 外出时查当天消耗 |

非目标：需要多设备汇总、团队账单、预算告警的用户（P1 及以后）；只关心菜单栏常驻数字/徽标的用户（P1；D108 已提供点击图标弹出的小看板，但不在菜单栏常显数字）。

### 1.3 目标与成功指标

| 目标 | 衡量指标 | 目标值 | 监测方式 |
| --- | --- | --- | --- |
| 数据可信 | 页面数字与账本公式直算一致率 | 100%（金额差 ≤1 微元） | U-01 对账脚本 |
| 不造假 | 无数据时显示空态、缺价时显示「—」的比例 | 100% | U-02 / U-06 |
| 打开即用 | 桌面打开用量页到首屏可见 p95 | ≤1s `[假设]` | 本地计时 |
| 手机可用 | 手机请求到渲染 p95（局域网） | ≤1.5s `[假设]` | 本地计时 |
| 不拖慢 | 冷读 / 大文件 / 预热耗时 | 见质量门 | U-12 |
| 隐私 | `usage` 消息越界字段数 | 0 | U-11 抓包检查 |

指标口径沿用 [product/metrics.md](../../product/metrics.md)。所有目标值先测基线再校准。

## 2. 需求概述

**一句话**：读本机 DSH 账本，用同一份数据回答「花了多少、花在哪、准不准」。

| 模块 | 包含 | 优先级 |
| --- | --- | --- |
| 入口与导航 | 桌面一级页「用量」（⌘3）；手机宠物页顶栏今日数字 → 二级页（D93） | P0 |
| 区间与汇总 | 今天 / 近 7 天 / 近 30 天 / 近半年；花费 hero（环比 + Token / 会话 / 缓存命中读数） | P0 |
| 趋势与构成 | 当前区间的花费剖面（折线 + 面积 + 今日/单日处理）；五桶构成与缓存命中 | P0 |
| 分组明细 | 客户端 / 会话 / 模型；Top 8 + 其他；行内按金额排序 + 占比条 | P0 |
| 价格 | 来源与优先级、自动/手动刷新、stale、`≈` 估算 | P0 |
| 双端 | 桌面页面 + 手机只读页 + `usage` 协议 | P0 |
| 降级 | 账本缺失/损坏、价格失败、未连接、旧版本 | P0 |
| 多客户端解析、预算、洞察 | 见范围外 | P1+ |

## 3. 功能规则

### 3.1 入口与导航（P0）

**功能描述**：用量是桌面一级视图；手机从宠物页顶栏的今日数字进入只读二级页。

**业务规则**

1. 桌面导航固定 6 项，顺序：概览 / 剪贴板 / 备忘录 / **用量** / 语音 / 设置；快捷键 ⌘1–⌘6 与顺序一一对应（备忘录 ⌘3、用量 ⌘4、语音 ⌘5、设置 ⌘6，D85 结构 + D104 + D123；D119 把第 2 项「内容」改名「剪贴板」，⌘2 不变）。
2. 桌面默认首页仍是概览；不记住上次视图，重启回概览。
3. 手机入口固定在宠物页顶栏右侧：显示「今天」花费（账本不可用/无快照时退回仪表盘图标），点开全屏二级页，页头返回宠物；设置页不再放「用量」入口（v17 / D93）。
4. 手机只有一个只读页面；不做编辑、导出、分享（P2）。
5. 新增页面不得破坏现有壳：桌面单列（1180/960 不溢出；除用量页 900 宽幅例外外，内容最大宽 730）；手机只支持竖屏。
6. 菜单栏入口（D108）：左键托盘图标弹出/收起只读小看板（大小约 320×432，贴图标下方）；面板只做「今天 / 7 天」，不加载桌面壳、不连手机；主窗口改走右键菜单「显示主窗口」或面板底部「打开用量页」；点其它 App / Esc 收起。

### 3.2 数据口径（P0）

**功能描述**：所有数字来自同一份本机账本，公式唯一、可对账。

**业务规则**

1. 唯一数据源：`<DSH_HOME>/storages/cost-meter/ledger.json`，只读。DSH_HOME 优先级 `SIDEKICK_DSH_HOME` > `DSH_HOME` > `~/.dsh`。
2. 区间固定 4 档：今天 / 近 7 天（含今天）/ 近 30 天（含今天）/ 近半年（180 天，含今天）。**不做本年度**。
3. 总 Token = `input + output + cacheRead + cacheWrite + reasoning` 五桶之和（与 DSH 记账一致）。
4. 缓存命中率 = `cacheRead ÷ (input + cacheRead + cacheWrite)`；分母为 0 时显示「—」，不显示 0%。
5. 金额单位人民币微元（1 元 = 1,000,000 微元）；`costCny` 字段存在时优先用账本值，缺失才按价格表估算并标 `≈`。
6. 成本来源四态：`ledger`（账本）/ `estimated`（全部估算）/ `mixed`（账本 + 估算）/ `unknown`（金额为 0 且无估算，含缺价；页面显示「缺价」或「—」）。
7. 缺价不估算：某个模型查不到价格时，该部分不计入金额，也不编造 0；页面提示「部分日期缺价，金额为已知部分」。
8. ASR（百炼语音）费用**不并入**本页，仍在「语音 › 语音用量」独立统计；两端不出现「总花费」合并数。
9. 日期按本机时区切天；「今天」= 本机当天日期。区间内「有数据天数」单独标注（`coverageDays`），缺数据的日期不补零画柱。
10. 账本只读：不写、不锁、不改 mtime；不因读取失败而创建或修复文件。账户余额、5 小时额度、预算不在本页读取。

### 3.3 桌面用量页（P0）

**功能描述**：一页回答「用了多少 / 花了多少 / 缓存有多省 / 花在哪」。

**业务规则**

1. 页面骨架（D97）：宽幅数据页（内容约 900，`PageShell size="wide"`），**不渲染 34/600 大标题**，工具栏 17/600 标题常显；右侧只放四档区间下划线 tab 与刷新；切换区间只刷新本页数据，不改导航；1180×760 首屏不裁切，960 可纵向滚动、不横向溢出。
2. 花费 hero：花费 58/500 等宽为主角（估算 `≈`、未知「—」），环比（上期 >0 才显示）+ 区间日期；右侧 Token / 会话 / 缓存命中三列读数；不再有 2×2 汇总卡。
3. 花费剖面：使用**当前区间** `days`（今天/7/30/180），折线 + 面积 + y 轴取整刻度 + 日均虚线 + 峰值标注；仅最后一天是今天时出现竖虚线/呼吸点/末段虚线；单日退化为「今天柱 + 昨日基准」；悬停十字线 + 气泡；`role="img"` + `sr-only` 每日表；缺价/全 0 不画空轴。
4. Token 构成：10px 光谱 + 5 行图例（缓存读/输入/输出/缓存写/推理，为 0 省略）；缓存读固定薄荷 c1，不再用 chart-2 蓝；百分比最大余数合计 100.0。
5. 分组账本：下划线 tab 客户端 / 会话 / 模型；行 = label + 后端副行 + 3px 占比条 + Token + 金额；**返回的 Top 行内按金额降序**、其他垫底，右侧标「按花费」；空组一行结论。
6. 价格行贴左下：`价格表 / 价格表 · 待更新` + `N 个模型 · 更新时间`，点击打开右侧 Sheet「模型价格」；面板规则与刷新策略不变（见 3.6）。
7. 空态与错态：一行结论 + 一个动作（重试），不显示假 0；读取失败但有缓存时显示缓存并注明「展示上次成功读取的缓存」；账本缺失/损坏/过大只显示一句结论。
8. 桌面页没有页脚、说明句、状态胶囊与 mono 大写装饰；用量页是宽幅数据页例外，但内容层仍不叠玻璃。

### 3.4 分组规则（P0）

**业务规则**

1. **客户端**：本期只接入 DSH，显示真实数据（100% 占比）；未接入的客户端不显示占位行，也不带任何数字（V1 收口去掉「未接入」占位）。
2. **会话**：账本 `days[].sessions[]` 按 `id` 跨天合并；标题优先用账本 `title`（单行 ≤80 字符）；账本无标题时只读 DSH 会话缓存 `storages/session_projcache/sessions/<id>.json` 的 `record.rows.title.val` 回填（只读标题、不读提示词/消息）；仍无才显示「会话 + 短 id」，不猜内容。
3. **模型**：来自 `days[].byProviderModel` 的 `provider: model` 键，按**金额降序**（同额再按 Token）；每行显示模型 id、接入方（provider 中文名）、缓存命中率、当前价格来源（override / DeepSeek 官方 / 远程目录 / seed / 无价）。
4. 每组最多 8 行明细 + 1 行「其他 N 个」汇总；「其他」行的 Token/金额/调用数为其余行之和，会话组另计剩余会话数。
5. 分组金额以账本/估算聚合为准；页面不重新定价账本已有金额。
6. 分组行**排行**：后端按**金额降序**选取 Top 8（D102，同额再按 Token），前端仍按金额排序兜底（「其他」始终垫底），并标「按花费」；占比条 = 行金额 ÷ 组内金额（组内全 0 退回 Token）。
7. 手机端模型分组受 D83 开关控制：开（默认）显示模型 tab；关则不下发模型名（`groups.models` 为空 + `modelsHidden=true`），手机隐藏模型 tab。`status.sessionList` 仍不含模型名（D78 不变）。

### 3.5 手机用量页（P0）

**功能描述**：手机只读，干净版页面，一眼看到区间花费、构成与去向。

**业务规则**

1. 页面结构（D98）：页头（返回宠物 + 「用量」+ 副行「DSH 本机账本 · 不上传」）→ 四档区间下划线 tab → 花费 hero（花费 40–42 等宽 + 环比 + Token/会话/缓存三读数）→ 花费剖面（当前区间、150 高、可拖动读数）→ Token 光谱 + 5 行图例 → 分组下划线 tab + 账本行（行底 3px 占比条）→ 只读价格行 → 隐私一行；**无白卡**，hairline 分区。
2. 手机发 `usage.request{range}`，电脑回 `usage{data:…}`；进入页面、切换区间、连接恢复时请求；不轮询。8 秒无响应显示「电脑还没回应。」+「重试」；未连接显示「还没连上电脑。」+「去连接」。
3. 断连时保留最后快照（仅当前区间）并在正文顶部标注「电脑未连接，显示最后一次快照。」；没有快照显示等待/去连接。
4. `ledger.available=false` 时显示「还没找到 DSH 账本，先在电脑上打开 DSH。」+ 重试；不显示假数字。
5. 文字规格按 D91：HarmonyOS Sans SC Regular 400、页面标题 17、正文 13；颜色用 hex 令牌（WebView 103 不支持 oklch / color-mix / CSS translate/scale 属性）。
6. 录音中不允许切换到用量页（`ui-store.setView` 拦截）；从用量页返回宠物，返回键行为与其它二级页一致。
7. 手机不提供「刷新价格」按钮，也不写价格缓存文件；`groups.modelsHidden=true` 时模型 tab 不出现（当前在模型 tab 时自动切会话），并给一行「模型分组已在电脑端关闭。」。
8. 两端都显示环比（`previous` 随快照下发；上期 ≤0 或金额未知时隐藏）。

### 3.6 价格规则（P0）

**功能描述**：账本已有金额时不重复计算；缺金额时用可追溯的价格表估算，并让用户看见来源与新鲜度。

**业务规则**

1. 价格来源优先级：**用户覆盖 override > DeepSeek 官方 CNY（峰谷表）> OpenRouter 远程目录（USD/1M 换算 CNY）> 内置 seed 快照**。
2. DeepSeek 官方价按北京时间峰谷：工作日 09:00–12:00、14:00–18:00 为峰时，其余为谷时；周六日按谷时（V1 不处理法定调休）。
3. 汇率 FX 优先级：overrides 的 `fxCnyPerUsd` > 环境变量 `SIDEKICK_FX_CNY_PER_USD` > 账本 `config.exchangeRate` > 7.0。
4. 缓存文件 `~/.sidekick/token_pricing.json`（0600）；用户覆盖 `~/.sidekick/token_pricing_overrides.json`；seed 随安装包内置，首启/离线可用。
5. 打开用量页且价格缓存超过 24 小时 → 后台自动刷新一次（每会话最多一次）；手动刷新最短间隔 60 秒；失败保留上次成功数据，1 小时内不自动重试；超过 7 天未成功视为 stale，页面明示「价格表已过期，金额为估算」。
6. 远程刷新只 `GET` OpenRouter 公开模型目录，不携带任何用量、模型名、标识或本机数据；失败不降级为编造价格。
7. 覆盖文件由用户/高级用户手动维护；页面只读展示，不提供在线编辑。

### 3.7 隐私与安全（P0）

**业务规则**

1. `usage` 消息为 `{type:"usage",v:1,ts,data:{…}}`；`data` 字段白名单：`range`、`generatedAt`、`summary`、`previous`、`days[]`、`groups{clients,sessions,models,modelsHidden?}`、`pricing`、`coverageDays`、`ledger{available,reason}`；**不含**提示词、回复、工具参数、文件路径、cwd、会话正文。
2. 会话标题是账本已有字段（单行 ≤80 字符）；模型名与接入方在手机端是新增外发字段，受 D83 开关控制，默认开、可关。
3. `status.sessionList` 仍不包含模型名（D78 不变）；本功能不得改动 `sessionList` 的字段与语义。
4. `usage` 与 `status` 一样由桌面广播给所有已连接客户端（均为用户本机设备），不包含越界字段。
5. 账本只读；`token_pricing.json` / 覆盖文件 0600；日志不记录会话标题与提示词等内容。
6. 不新增遥测、不上传统计、不做多设备同步。

### 3.8 空态与降级（P0）

| 场景 | 页面表现 | 下一步 |
| --- | --- | --- |
| DSH 未安装 / 无账本 | 桌面「还没找到 DSH 账本」+ 重试；手机「还没找到 DSH 账本，先在电脑上打开 DSH。」+ 重试 | 不造假、不显示 0 |
| 账本损坏 / 读不到 | 桌面「读取用量失败」/「账本格式暂时认不出来」+ 重试 | 说明只读、不会改动文件 |
| 账本正在被替换 | 显示上次成功缓存 + 「展示上次成功读取的缓存」 | 稍后自动恢复；不打断浏览 |
| 区间内 0 天有数据 | 花费「—」或 0 + 剖面一行「这个区间还没有记账金额」 | 切更短/更长区间；仍可用 |
| 价格首次刷新失败 | 用 seed/缓存照常出数 | 显示旧时间与失败原因；可再试 |
| 价格 stale >7 天 | 金额前标 `≈`；价格行「价格表 · 待更新」 | 立即刷新 |
| 部分模型缺价 | 金额为已知部分 + `≈`；手机价格行「按价格表估算」 | 提供覆盖文件路径提示（桌面） |
| 手机未连接 | 最后快照 + 「电脑未连接，显示最后一次快照。」 | 去连接页；无快照显示「还没连上电脑。」 |
| 旧电脑端无 usage | 「电脑端需要更新」 | 升级电脑端 |
| 录音中尝试进入 | 拦截，不切页 | 松手后再进 |

## 5. 非功能与质量门

- **性能**：当前 6–7 天账本冷读 <300ms；30MB 账本 <2s；预热（缓存命中）<50ms；账本读取不阻塞 UI 线程。
- **兼容**：桌面 1180×760 / 960×640；手机 390×844、360×800、320 宽不横向滚动；深浅双主题；WebView 103 限制（无 oklch/color-mix/CSS translate）。
- **可访问性**：区间切换可用键盘；图表有文字替代与 `aria-label`；状态变化 `aria-live`；`prefers-reduced-motion` 下不播放入场动画。
- **质量门**：`cargo fmt --check`、`cargo test`、`pnpm typecheck/lint/test/build`、`node scripts/check-docs.mjs`、`node scripts/check-boundaries.mjs` 全绿；新增 Rust 测试不联网。
- **文档**：本目录 + 工程方案；`protocol/README.md` 同步 `usage.request` / `usage`；`decisions.md` 含 D83/D97/D98；`docs/engineering/desktop-ios-ui.md` v3；`docs/design/usage-dashboard-v2/`；`docs/prd/INDEX.md`、`docs/engineering/INDEX.md`、`docs/design/INDEX.md`、`docs/INDEX.md` 补入口。

## 6. 依赖、排期与风险

**依赖**

- DSH cost-meter 账本（本机文件，schema 无契约、可能变化）→ Rust 侧容错；见工程方案 §3。
- 账本 `sessions[].title`（可选）与会话 id；无标题时用短 id。
- tokei `pricing.json` / OpenRouter 目录作为 seed 与远程价格来源。
- 桌面 5 入口壳与快捷键（D85 结构 + D104）、手机 D80/D81 壳。

**排期（建议）**

| 阶段 | 内容 | 出口 |
| --- | --- | --- |
| 1 | Rust 解析 + 聚合 + 价格表 + 单测 | 账本对账通过 |
| 2 | 桌面用量页 + 价格面板 + 空态/降级 | 1180/960 双主题走查 |
| 3 | `usage` 协议 + 手机页 | 真机四区间/断连/返回 |
| 4 | 验收 U-01–U-15 + 文档同步 | 质量门全绿 |

**风险**

- 账本 schema 变化：只依赖白名单字段，缺失/非法按 0 容错，异常给空态不崩溃。
- 模型名无法匹配价格：按「缺价不估算」处理，不猜。
- 峰谷/节假日：V1 只按工作日峰谷估算，法定调休日可能偏差，页面标 `≈`。
- 0 元账单（免费模型）可能被判定为「缺价」；属已知口径限制，P1 修。
- 手机模型名外发是新隐私面：默认开但可一键关闭（D83），并在文档与设置处说明。
