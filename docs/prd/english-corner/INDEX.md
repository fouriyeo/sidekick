# 英语角（生词本）· 一页摘要

> 实现状态（2026-11-09）：Rust 核心（词库/AI 解释/造句/用量）、桌面一级页、手机全屏页、局域网双向同步已完成；真机与 QA 待补。技术细节见 [engineering/english-corner.md](../../engineering/english-corner.md)。

> 把「读英文时遇到的生词」随手存进 Sidekick，AI 给出中文解释，再用**你自己的词库**造句；桌面和手机都能记、都能看，同一局域网自动同步。
> 本期定位：**桌面主写 + 手机可写可读**。不做口语陪练、不做 OCR/划词、不做 SRS 提醒。

## 本期做什么

- 桌面新增第 7 个一级页「英语角 ⌘7」：输入/粘贴单词 → 百炼 `qwen3.8-flash` 解释（释义/词性/音标/例句/搭配/常见错误/词根）→ 存本机词库。
- 手机新增全屏页「英语角」（顶栏入口）：查看/搜索/新增/解释/删除/造句/用量；未配对时仍可看本地词库。
- 词库：归一化去重、状态（待解释/已解释/失败）、备注、语境句、来源、删除墓碑。
- 造句：选 5–10 个已解释的词 → 3–5 句英文 + 中文翻译 + 逐词标注。
- 用量：页内显示今日/近 30 天调用次数与估算花费（标注「估算」）。
- 同步：同一局域网、配对后双向合并；离线可存，联网补推。
- 隐私：首次使用显式同意；只发单词原文与可选语境句；结果只存本机。

## 不做什么

- AI 口语陪练/实时语音对话（与「英语角」字面预期不同，独立评估）。
- 拍照 OCR、划词取词、语音拼读、全局快捷键。
- SRS 排程、每日推送、打卡、排行榜（与零焦虑原则冲突）。
- 导出、标签体系、云同步/账号、多设备、iOS。
- 宠物页显示词汇量（宠物不做效率看板）。

## 关联

- 与「语音」的关系：共用同一套百炼 Key（桌面 `asr.json`、手机备忘录配对下发），不新增第三套凭据。
- 与「备忘录」的关系：备忘录是时间线 + AI 归类，词条是原子实体（去重、复用、造句），不复用页面与数据模型。
- 与「剪贴板」的关系：剪贴板只作桌面取词来源（显式点击、只读候选），词库不写进剪贴板历史（D119 单一职责）。
- 决策依据：[D128](../../decisions.md)（定义与双端）、[D129](../../decisions.md)（同步与模型/Key 复用）。
