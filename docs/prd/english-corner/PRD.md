# PRD：英语角（生词本）

版本 1.0 / 2026-11-09 / 生效 / 桌面 + 手机 / 关联：[INDEX](./INDEX.md) · [SPEC](./SPEC.md) · [ACCEPTANCE](./ACCEPTANCE.md) · [engineering](../../engineering/english-corner.md)

## 0. 一页摘要

读英文文档/报错时遇到的生词，随手存进 Sidekick；AI 给出中文解释，并能用**用户自己的词库**造句。桌面（阅读现场）与手机（碎片时间）都能记、都能看，同一局域网配对后双向同步。不做的：口语陪练、OCR/划词、SRS 提醒。

## 1. 背景与目标

### 1.1 背景

- 现有能力（语音、备忘录、剪贴板、用量）已经跑通「AI + 本地库 + 局域网同步」三件基础设施；英语角只复用，不新造。
- 单纯的「查词」被 macOS 自带 Look Up 一个动作覆盖；Sidekick 的差异点只能是**个人词库持续长大 + 用我的词生成我能读的例句**。
- 不做：生词看完即忘，没有「自己的词」这条资产；做了但做全（口语陪练/OCR/SRS）会与零焦虑原则和本期范围冲突。

### 1.2 目标用户

- 主要：现有画像 A（25–40 岁，macOS 上用 AI 结对开发/读英文文档与报错的研究者与开发者），作者本人是典型用户。
- 次要：画像 B（内容创作者，读英文资料）可顺带使用。
- 非目标：备考背单词人群、口语陪练需求者、儿童。

### 1.3 目标与成功指标（[假设]，待试用校准）

| 指标 | 目标 |
| --- | --- |
| 自然阅读中每周新增词条 | ≥10 条/周 |
| 解释可用率（未编辑未删除） | ≥80% |
| 词库复用率（被造句过 / 总词条，30 天） | ≥40% |
| 桌面「读到词 → 看到解释」中位耗时 | ≤10s |
| 解释延迟 p95（关闭思考模式） | ≤5s |
| 重复词重复 AI 调用 | 0 次 |
| 单日 AI 花费 | <¥0.05 |

## 2. 需求概述

记录英文生词 → AI 解释 → 本机词库 → 用词库造句 → 双端同步。

## 3. 功能详细设计

### 3.1 词条与词库（P0）

- 描述：一个词条 = 归一化词形（去首尾、连续空白折叠、小写）+ 原样单词 + 状态 + 解释 + 备注 + 语境 + 来源 + 时间。
- 用户故事：作为读者，我粘贴一个生词，希望 3 秒内看到中文释义和两个例句。
- 规则：
  - 输入只接受拉丁字母、空格、连字符、撇号、点；长度 1–64 字符；否则 `invalid_word`。
  - 同一归一化词形只保留一条（重复添加刷新时间与语境，不重复计费；已有解释不丢）。
  - 状态：`pending` 待解释 / `ready` 已解释 / `failed` 失败（可重试）。
  - 删除是墓碑（`deletedAt`），同步到另一端；90 天后清理。
  - 列表按 `updatedAt` 倒序，最多 2000 条；搜索匹配词形与释义。
- 交互：输入框 + 可选语境句（≤200 字符）→ 查词；列表行显示状态点、首条释义、相对时间。
- 异常：空/非英文/超长 → 内联提示；重复词 → 直接打开已有详情。

### 3.2 AI 解释（P0）

- 描述：调用百炼 `qwen3.8-flash` 兼容模式，严格 JSON 输出：释义（1–3 条）、词性、音标（不确定留空）、例句（2 条）、搭配（≤3）、常见错误、词根。
- 规则：
  - 首次使用必须显式同意（`wordConsent`）；未同意返回 `need_consent`，不发请求。
  - 无 Key → `no_key`，引导去「语音」页配置（手机：先配对）。
  - 已有解释且模型/提示词版本一致 → 直接命中缓存，0 网络调用。
  - 失败码：`timeout` / `rate_limited` / `model_error` / `bad_json`；失败保留词条为 `failed`，输入不清空。
  - 音标/词源标「AI 生成」，不确定不编造。
- 异常：JSON 非法 → 自动补括号后重试 1 次；仍失败 → `bad_json`。

### 3.3 造句（P0）

- 描述：选 5–10 个已解释的词 → 生成 3–5 句英文 + 中文翻译 + 逐词标注。
- 规则：只允许已解释的词；少于 1 个有效词 → `invalid_word`；难度 B1–B2；结果可重新生成（重新生成覆盖展示，不写词库）。
- 异常：模型输出为空/结构非法 → `bad_json`；失败保留已选词。

### 3.4 用量与花费（P0）

- 描述：页内显示今日/近 30 天调用次数、输入/输出 token、估算人民币。
- 规则：每次成功解释/造句记一次；失败不计费；金额为估算并明确标注；不并入 DSH 账本看板（口径不同）。

### 3.5 双端同步（P0）

- 描述：桌面与手机各自本地 SQLite，同一局域网、配对后双向合并。
- 规则：
  - 鉴权复用备忘录配对令牌；未配对只读本地，不发送。
  - 合并字段级：解释取「ready 且 explainedAt 较新」；备注/语境后写胜；较新墓碑删除；`createdAt` 取早；桌面为时间权威。
  - 手机本地未推送的改动保留 dirty，下一轮补推。
  - 断网/未连接是常态，不弹错、不阻塞本地使用。
- 异常：对端发来非法词条 → 跳过该条，不落库。

### 3.6 隐私（P0）

- 首次使用一屏说明：发送什么（单词原文 + 可选语境句）、发给谁（阿里云百炼）、存哪（本机）、不发送什么（整个词库、剪贴板历史、设备信息）。
- 日志与事件不含词条正文；Key 只在 Rust 侧读取，不进 WebView。

### 3.7 取词入口（P1，已实现）

- 桌面：添加卡「从剪贴板取词」→ 从剪贴板历史提取英文候选词（只读、最多 20 个，界面展示前 8 个），点候选只填入输入框、不自动查词。
- 手机：系统长按粘贴到输入框（不加插件）。

### 3.8 导出（P1，已实现）

- 两端：导出全部词条为 Markdown（单词、音标、词性、释义、例句、备注），在弹层/全屏页展示，复制走系统剪贴板；不写文件、不联网；空词库禁用。

### 3.9 复习（P1，已实现）

- 两端：列表上方「今天复习」卡，从已解释词随机抽 5 个（不足取全部）；「看释义」按需加载首条释义 + 第一条例句；「下一个」推进；看完「复习完成 / 再来一组」。
- 不做：SRS 排程、每日推送、签到、掌握度评分。

### 3.10 语音朗读（P0，已实现）

- 模型：`qwen-audio-3.1-tts-plus`（百炼，按字符计费 1.4 元/万字符）；默认音色 `longanhuan_v3.1`。
- 入口：单词详情页单词、每条例句、造句结果每一句，各一个喇叭按钮；同一条再点即停。
- 单词用 0.85 语速 +「只读单词」指令；句子用自然语速 +「注意连读语调」指令。
- **本地缓存**：合成结果按内容哈希存 `word_audio/<hash>.mp3`；同文本+音色+语速只合成一次，重复播放不等待、不花钱。
- 兜底：桌面云端失败回退 macOS `say`（离线）；手机失败给可重试提示。
- 用量：合成次数/字符/估算费用记入英语角用量，缓存命中不计费。
- 隐私：只发送要朗读的那段文本（单词或句子），不发词库全量。

## 4. 非功能需求

- 性能：列表 2000 条内滚动流畅；解释 p95 ≤5s；同步单批 ≤100 条。
- 兼容：桌面 macOS（1180/960 两档、深浅主题）；手机竖屏 300×800 起，无横向滚动。
- 无障碍：点击目标 ≥44×44；文字对比 ≥4.5:1；键盘可达（桌面）。
- 隐私：见 3.6；数据只存本机与局域网。

## 5. 数据需求

- 本机 SQLite `words.db`（词条，不含剪贴板原文）。
- `word_usage.json`（日汇总：次数/token/估算费用）。
- `word.json`（同意标记、可选模型覆盖）。
- `word_sync.json`（手机同步游标）。
- 不采集 PII；不埋点上报。

## 6. 验收标准（摘要，详细见 ACCEPTANCE）

- 首次使用未同意时点查词 → 出现隐私说明，不发起网络请求。
- 已同意 + 有 Key：粘贴 `resilient` → 5 秒内出现释义/词性/例句。
- 重复粘贴同一词 → 不重复调用（第二次无网络请求）。
- 选 3 个已解释词造句 → 返回 3–5 句且每句含至少 1 个所选词。
- 手机配对后：桌面新增的词 2 秒内出现在手机；手机新增的词 30 秒内出现在桌面。
- 删除后两端都不再显示，重启不复活。

## 7. 排期建议（[估算]，不承诺）

阶段：Rust 核心 → 桌面页 → 同步 → 手机页 → 文档与验收。桌面与手机 UI 可并行，同步在核心之后。

## 8. 风险与依赖

| 风险 | 应对 |
| --- | --- |
| 模型 id/地域不可用 | 已用真实 AK 探测通过（`qwen3.8-flash`）；模型可配置覆盖 |
| 音标/词根幻觉 | 标「AI 生成」，不确定留空；评测不达标就下线该字段 |
| 双向同步冲突 | 字段级合并 + 墓碑 + 桌面时间权威；规则写进 engineering |
| 取词摩擦导致不用 | 桌面主入口 + 手机入口；P1 再做剪贴板候选 |
| 与 P0 收口抢资源 | 列 Phase 2；先完成现有待验收项 |

## 9. 开放问题

- 手机端是否需要「今天复习 N 个」（当前只有手动浏览）。
- 是否引入权威词典源来保证音标正确（需新依赖/许可）。
- 「英语角」命名是否改为「词汇」（当前按用户原话保留）。
