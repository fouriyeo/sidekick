# 英语角（生词本）SPEC

> 这篇回答：英语角在桌面与手机上的布局、状态机、文案与交互细节。
> 产品规则见 [PRD](./PRD.md)，技术实现见 [engineering](../../engineering/english-corner.md)。

## 1. 入口与承载

| 平台 | 入口 | 承载 |
| --- | --- | --- |
| 桌面 | 侧栏「英语角 ⌘7」（设置仍 ⌘6，固定在底部） | 一级页，730 单列，页内 push 详情 |
| 手机 | 宠物页顶栏「英语角」图标（原「消息」位置） | 全屏页，页内 push 详情；消息入口保留在「设置 › 消息通道」 |

- 桌面快捷键按 `item.shortcut` 反查，不再依赖数组下标；输入框/下拉/contentEditable 内不劫持。
- 手机返回键必须接入 `pushBackHandler`：详情 → 列表 → 宠物页。

## 2. 桌面布局

自上而下：

1. **页头**：34/600 大标题「英语角」，滚动后 17/600 紧凑标题。
2. **添加卡**：单词输入框 + 可选语境句 +「查词」按钮；空/超长/非英文内联提示。
3. **词库列表**：搜索框；行 = 状态点 + 单词 + 音标 + 首条释义 + 相对时间；点击 push 详情。
4. **造句卡**：多选已解释词（5–10）→「生成例句」→ 结果卡（英文 + 中文 + 用到的词胶囊）+「重新生成」。
5. **AI 用量**：今日 / 近 30 天：次数 + 估算 ¥；标注「估算」。

详情（页内 push，页头「‹ 词库」）：

- 单词 + 音标 + 词性；释义列表；例句（英/中）；搭配；常见错误；词根；组标题标「AI 生成」。
- 备注（可编辑）、语境句、来源与时间、模型。
- 操作：删除（二次确认）、失败/待解释时「重试」。

## 3. 手机布局

- 页头 44：「‹ 返回」+ 标题「英语角」+ 右侧「＋」新增。
- 列表：搜索框、状态点、首条释义、相对时间；点击进详情。
- 新增页：单词输入 + 可选语境句 +「保存并解释」；失败留在详情可重试。
- 详情页：同桌面字段；备注、删除（二次确认）、重试。
- 造句：多选已解释词 → 生成 → 结果卡。
- 用量：今日 / 近 30 天次数与估算 ¥。
- 约束：300×800 起无横向滚动；点击目标 ≥44；不使用弹窗堆叠。

## 4. 状态机

### 4.1 页面级

```text
加载中 → (未同意) 同意引导 → (无 Key) 配置引导 → (空词库) 空态 → 就绪
就绪 ⇄ 失败（可重试）
```

- 未同意：显示隐私说明 +「同意并开始使用」；本机已有词条仍可看，添加/造句隐藏。
- 无 Key：桌面提示去「语音」页并给跳转；手机提示「先在电脑上配对手机」。
- 未连接/未配对（手机）：本地词库可用；顶部一行「连上电脑后自动同步」，不弹错。

### 4.2 词条级

| 状态 | 列表表现 | 详情表现 |
| --- | --- | --- |
| pending | 灰色状态点 | 「解释中…」或「等待解释」+ 重试 |
| ready | 绿色状态点 | 完整解释 |
| failed | 红色状态点 | 错误原因 + 重试 |

## 5. 文案

| 错误码 | 桌面 | 手机 |
| --- | --- | --- |
| `need_consent` | 先同意隐私说明再查词 | 同左 |
| `no_key` | 去「语音」页配置百炼 Key | 先在电脑上配对手机 |
| `not_paired` | — | 连上电脑并配对后才能同步 |
| `invalid_word` | 请输入英文单词或短语（≤64 字符） | 同左 |
| `timeout` | 模型超时，稍后重试 | 同左 |
| `rate_limited` | 调用太频繁，稍后重试 | 同左 |
| `model_error` | AI 服务异常，稍后重试 | 同左 |
| `bad_json` | AI 返回格式异常，重试一次 | 同左 |
| `sync_failed` | — | 同步失败，稍后自动重试 |

- 隐私说明一句：单词原文与可选语境句会发送到阿里云百炼；解释只存本机；不发送整个词库或剪贴板历史。
- 用量标注：「估算」；价格说明由 Rust 下发。

## 6. 交互细节

- 搜索：输入即筛（本地，无网络），清空恢复全量。
- 从剪贴板取词：桌面添加卡底部次级按钮；候选以 chips 展示（最多 8 个），点 chip 只填入输入框；空候选提示「剪贴板里没有英文单词」。
- 导出：桌面页头「导出」/ 手机列表底部「导出 Markdown」→ 只读 Markdown 弹层（桌面 Dialog / 手机全屏页）+「复制」；复制失败提示「长按选择复制」；空词库禁用。
- 复习：「今天复习」卡在列表上方；ready 词为 0 时隐藏；显示「n / m」进度与「看释义 / 下一个」；看完显示「复习完成」「再来一组」。
- 发音：桌面详情页 44px 按钮（系统 `say`）；手机详情页 44dp 按钮（`speechSynthesis`，不可用时不渲染）。
- 造句选择：只列 `ready` 词；**5–10 个**才能生成（两端一致），选满 10 个后其余禁用，未满 5 个时按钮显示「再选 N 个」。
- 删除：二次确认；删除后列表立即移除（墓碑）。
- 事件：`word-changed` 触发列表与用量刷新；详情打开时刷新当前词条。
- 加载态：首帧 ≤100ms 显示骨架/占位，不出现空白页。
- 主题：深浅两套；不使用纯色硬编码，走现有令牌。

## 7. 无障碍

- 桌面：Tab 顺序与视觉一致；按钮有可读名称；⌘7 与侧栏可发现。
- 手机：热区 ≥44×44；TalkBack 读「英语角，N 个词条」；状态点不能是唯一提示（配文字）。
- 对比度：正文 ≥4.5:1，大文本 ≥3:1。
