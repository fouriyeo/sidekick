# AI 联动 · 体验规格

> 本文回答「桌面页长什么样、四态怎么动、声音怎么响、谁优先」。产品规则见 [PRD.md](./PRD.md)；宠物原有状态机见 [pet/SPEC.md](../pet/SPEC.md)。

## 1. 桌面「AI 联动」页

### 1.1 布局

```text
┌ 桌面右侧 ──────────────────────────────────────────┐
│ 聊天 | 剪贴板 | AI 联动                             │
│                                                    │
│ AI 联动                                             │
│ 把 AI 的工作状态同步给手机宠物                       │
│                                                    │
│ ┌ DeepSeek Harness ────────────────────────────┐   │
│ │ ● 已连接 · desktop        [开关]             │   │
│ │ 当前：工作中   1 个会话   最近心跳 2 秒前     │   │
│ │ 地址 http://127.0.0.1:47815/hook/dsh          │   │
│ └───────────────────────────────────────────────┘   │
│                                                    │
│ 首次开启步骤 / 等待重启提示 / 错误与修复             │
│                                                    │
│ 事件映射表                                          │
│ [工作中] [等你决定] [完成] [静态]  ← 本机模拟       │
│                                                    │
│ 最近事件                                            │
│ 22:31:05 工作中 · 1 个会话 · dsh                    │
│ 22:31:18 完成 · 1 个会话 · dsh                      │
│                                                    │
│ 隐私说明 / 配置路径 / 修复 / 移除                    │
└────────────────────────────────────────────────────┘
```

- 页面占右侧整列，内部滚动；左侧连接面板保持不变。
- 状态点：连接绿、等待黄、异常红、关闭灰。
- 开关是整页主操作；首次点击先弹确认 Dialog。
- 模拟按钮只用于验收，明确写「会真的推送到手机」。

### 1.2 首次/异常状态

| 状态 | 主文案 | 下一步 |
| --- | --- | --- |
| 未检测到 DSH | 没有找到 DSH profile | 检查 `~/.dsh/profiles`；不自动创建 |
| 未安装 | 开启后把状态同步给手机 | 点开关 → 确认 → 写入 |
| 已写入、未连接 | 已写入，重启 DSH 后生效 | 退出并重新打开 DSH；页面自动检测 |
| 已连接 | 已连接 · `<profile>` | 可模拟/关闭 |
| 心跳中断 | DSH 可能已退出，宠物已回静态 | 检查 DSH；恢复后自动连接 |
| 配置异常 | 无法写入 `<path>` | 显示路径、错误；修复/移除 |
| 已关闭 | 联动已关闭 | 再开即可，无需重启 |

### 1.3 文本

- 标题：AI 联动
- 说明：把 AI 的工作状态同步给手机宠物。
- 开关：DSH 状态同步
- 隐私：只同步状态、会话标题、当前工具类别、数量和事件时间；工具类别只取固定枚举，不含工具名原文、提示词、回复、工具参数或文件路径。桌面端只监听本机回环地址。桌面页不展示会话列表（列表只在手机宠物页）。
- 首次确认：会写入 3 个文件；不安装 npm 包；需要重启 DSH 一次。
- 移除确认：会删除 Sidekick 写入的脚本和配置；DSH 下次启动不再加载。

## 2. 手机会话列表（竖屏）

### 2.1 布局

```text
┌ 安全区 ──────────────────────────────────┐
│ [设置]                        [聊天] [●] │
│ ┌ 会话 ────────────────────────────────┐ │
│ │ ● 修复登录 bug   正在运行命令 · 2 分钟前  ✕ │ │  ← 收起：1 行 + 展开箭头
│ └──────────────────────────────────────┘ │
│              （宠物下移 32/56px）          │
│                  宠物舞台                 │
│      [  🎙 按住说话  ]  ← 56px 高胶囊     │
└──────────────────────────────────────────┘
```

- 面板宽 `min(92vw,520px)`，置顶居中，位于设置/聊天按钮下方；展开头部约 32px，行高约 46px，5 行后内部滚动。
- 宠物整栏下移：收起 32px、展开 56px；展开时隐藏气泡/文案，收起恢复。
- 麦克风按钮改为 56px 高、`min(86vw,360px)` 宽的胶囊；录音/处理状态在胶囊内，不再出现独立录音卡片。
- 单套竖屏值，不写横屏断点；手机系统锁定竖屏。

### 2.2 状态与排序

| 行状态 | 点色 | 文案 | 行行为 |
| --- | --- | --- | --- |
| 等你决定 | 珊瑚 | `等你决定 · 刚刚`（审批显示「等你审批」） | 点击唤起电脑；清除需二次确认 |
| 工作中 | 信号色（薄荷） | `正在<工具动作> · 2 分钟前`（无工具为「正在思考 · 2 分钟前」） | 行首小圆环 spinner 转动；点击无操作；清除可用 |
| 已完成 | 薄荷 | `已完成 · 22:31` | 点击无操作；清除可用 |
| 空闲 | 灰 | `空闲 · 昨天` | 点击无操作；清除可用 |

- 排序：asking → working → 有 completedAt → idle；同状态按 `lastEventAt` 倒序。
- 标题缺失显示「新会话 + id 后 4 位」。
- 完成态一直保留到手动清除或下一轮开始。
- 工作中行的「工具动作」只来自协议白名单 `tool`，映射固定：`bash` 运行命令 / `read` 阅读文件 / `edit` 修改文件 / `search` 搜索代码 / `web` 查资料 / `agent` 处理子任务 / `plan` 整理计划 / `tool` 使用工具；`tool` 为空（旧插件/还没开始调工具）显示「正在思考」。未知值不渲染，按「正在思考」处理。

### 2.3 交互

1. 收起条显示优先级最高的一条；点击非 asking 行或箭头展开，展开后点箭头收起。
2. 新出现 asking 会话自动展开一次；用户收起后只有新的 asking 会话才再次自动展开。
3. 点 asking 行发 `focus.request`；等待时行内显示 spinner；成功提示「已在电脑上打开 DeepSeek Harness」，失败按错误码提示。
4. 清除：普通行一次点击清除；asking 行第一次点击变为「再点一次」，3 秒内再点才清除。清除后提示「已清除；这个会话有新动静会再出现」。
5. 返回键：展开时先收起，收起时不拦截。
6. 断连立即清空列表；重连后由桌面快照恢复；会话全部清除或 DSH 退出时面板隐藏。

### 2.4 文案

| 场景 | 文案 |
| --- | --- |
| 标题 | 会话 |
| 汇总 | `N 个` / `N 个 · M 个等你决定` |
| 状态 | 等你决定 / 等你审批 / 已完成 / 空闲 |
| 工作行动作 | 正在运行命令 / 正在阅读文件 / 正在修改文件 / 正在搜索代码 / 正在查资料 / 正在处理子任务 / 正在整理计划 / 正在使用工具；无工具为「正在思考」 |
| 清除提示 | 已清除；这个会话有新动静会再出现。 |
| asking 清除确认 | 这个会话正在等你决定，再点一次清除。 |
| 唤起成功 | 已在电脑上打开 DeepSeek Harness。 |
| 未连接 | 先连上电脑，再打开会话。 |
| 电脑无响应 | 电脑没有响应，稍后再试。 |
| 未安装 DSH | 电脑上没有找到 DeepSeek Harness。 |
| 限频 | 刚打开过，稍等一下再试。 |

### 2.5 无障碍

- 面板 `role="region"` / `aria-label="AI 会话列表"`；行、清除、展开都有明确 `aria-label`。
- 提示用 `role="status"` + `aria-live="polite"`；不只用颜色区分状态（同时有文案）。
- 触控目标 ≥44px；清除 icon 与行主区域分开，避免误触。

## 3. 手机四态

### 2.1 状态总表

| 状态 | 轮廓/姿态 | 道具/符号 | 动作 | 主色 | 文案 | 声音 | 时长 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 静态 | 坐姿、放松、头正 | 无 | 4s 呼吸；6s 眨眼；8–12s 耳朵/尾巴；30–45s 伸懒腰 | 暖白 | 无 | 无 | 持续 |
| 工作中 | 前倾、低头、双爪敲键盘 | 键盘、飞纸、汗滴、速度线 | 180ms 交替敲击；0.35s 点头；0.25s 微振；5–7s 抛纸 | 琥珀 + 珊瑚汗滴 | 陪你工作中 | 开工音 | 持续 |
| 等你决定 | 站高、前倾、单爪高举 | 珊瑚感叹号、急促线、问号 | 1.6s 看左→看右→锁定你→挥爪；6s 后降为 4s 循环 | 珊瑚 | 等你决定 | 提问音 + 1 次提醒 | 持续 |
| 完成 | 双臂上举、跳起、笑眼 | 彩纸 6–8、对勾、爱心 ≤3 | 0.5s 跳 + 0.4s 压扁；1.4s 二次小跳；1.2s 闪光 | 薄荷绿 + 琥珀/珊瑚 | 搞定啦 | 完成音 | 3s |

### 2.2 四态动效细节

**静态（悠闲但活着）**

- 呼吸 `scale(1 → 1.015)` 4s；眨眼 6s；耳朵/尾巴 8–12s；伸懒腰/打哈欠 30–45s。
- 夜间更慢；不能完全静止。

**工作中（手忙脚乱，非常繁忙）**

- 身体前倾 8–10°，头低向键盘，双爪伸出；眉毛下压、眼睛聚焦、嘴角用力。
- 键盘/桌面从下方淡入；纸片每 5–7s 飞起；汗滴每 3s；速度线 3 条。
- 节奏：左/右爪 180ms 交替；头 0.35s 点头；身体 0.25s 微振；尾巴快摆。
- 忙但不痛苦；减少动效保留前倾+键盘+速度线+汗滴的静态轮廓。

**等你决定（着急、左右找人）**

- 站起、前倾、单爪高举、耳朵全竖、眼睛睁大、嘴微张。
- 珊瑚感叹号 + 2–3 条急促线 + 小问号。
- 前 6 秒：看左 0.25s → 看右 0.25s → 锁定你 0.3s → 挥爪 0.5s；身体小跳 2–3px；循环 1.6s。
- 6 秒后：4s 循环，保持举爪+感叹号+看向你，不再连续跳。
- 夜间全亮；唯一完全唤醒睡眠的状态。
- 减少动效：静态「举爪+感叹号+大眼」，保留珊瑚色。

**完成（爆发庆祝，3 秒）**

- 双臂上举、笑眼、跳起约 10px；拉长再压扁；1.4s 二次小跳。
- 6–8 片彩纸/闪光、对勾气泡、爱心 ≤3；3s 结束。
- 夜间降低亮度但保留跳跃/彩纸；减少动效改为静态双臂上举+彩纸。

### 2.3 切换

- 切换 120ms 淡入 + 1.03 倍弹一下；道具 160ms 淡入/淡出；不跳位。
- 工作 ↔ 等你决定：键盘淡出、爪子抬起；轮廓由「向下」变「向上」。
- 完成 → 稳定态：200ms 收彩纸，不残留。
- 只动 `transform` / `opacity`，不动宽高/filter/阴影。

### 2.4 优先级

从高到低：

1. App 后台 / away：不渲染、不播报、不播声音。
2. 命名庆祝（celebrating，1.5 秒）：AI 状态让位；结束后恢复 AI。
3. 等你决定。
4. 完成（3s）。
5. 工作中。
6. 静态/睡眠。

回前台/重连只恢复稳定态；完成态不补播。录音不再改变宠物姿态/气泡/触感（宠物与麦克风已解耦，D77）；录音时只静音 AI 音效与触感（`micListening` 门禁），麦克风 UI 自身的 arming/listening/processing 等状态保留。

### 2.5 声效

| 事件 | 声音 | 时长 | 规则 |
| --- | --- | --- | --- |
| 开工 | 柔和木琴/小铃铛「叮」，E5+B5 | ~220ms | 只在静态/睡眠 → 工作中；完成/提问回工作不响 |
| 提问 | 两下上扬「叮叮」，E5→A5 | ~350ms | 进入 asking；12s 未解决再响一次，最多 2 次 |
| 完成 | 三音上行 C5–E5–G5 | ~420ms | 每次完成脉冲一次；不连播 |
| 静态 | 无 | — | — |

- 只在 `sound=true`、App 前台、宠物页可见、麦克风未录音时响。
- 回前台仍在 asking：补一次提问音；完成态不补播。
- `AudioContext` 挂起时首次用户手势/试听解锁；未解锁静默跳过。
- 设置页：声音开关（默认关）+ 开工/提问/完成三个试听 + 说明「只在宠物页前台播放；录音时不响；系统静音/勿扰可能无法完全遵守」。

### 2.6 文案

| Copy ID | 文案 |
| --- | --- |
| `ai_working` | 陪你工作中 |
| `ai_asking` | 等你决定 |
| `ai_completed` | 搞定啦 |

- 状态文案占气泡位，AI 状态优先于宠物闲聊气泡。
- 文案是辅助；动作、道具、颜色和声音共同表达。
- 禁止制造愧疚/指责；不写「你怎么还不来」。

### 2.7 无障碍

- `aria-live="polite"` 播报「小跟班，正在陪你工作 / 等你决定 / 完成了一件事」。
- 状态文案 `aria-hidden`，避免重复播报。
- 不只靠颜色；减少动效下四态仍有不同轮廓/道具/主色。
- 轻震可关；声音可关；两者不替代视觉。

## 4. 与宠物原有状态的关系

- AI 四态是「叠加在宠物舞台上的展示状态」，不替代原有睡眠/问候。
- 原有 `PetPhase`（idle/celebrating/sleeping/away）与存档不变；AI 状态不落盘，重启后等桌面快照。
- 命名庆祝/休息优先；结束后恢复 AI 状态。
- 夜间 AI 状态唤醒宠物；空闲后恢复睡眠判定。
- 完成态 3 秒后回到稳定态；完成态不补播。
- 宠物不再响应麦克风（D77）：录音全程姿态/气泡/触感不变，只静音 AI 音效/触感。

## 5. 验收视觉/声音看点

- 四态并排截图：远看轮廓/道具/主色不同。
- 5 人、3 米、不看文案、每态 1 秒，识别 ≥ 80%。
- 工作 vs 等你决定：前者前倾+键盘+速度线，后者站高+举爪+感叹号。
- 完成必须有向上跳/双臂上举/彩纸。
- 减少动效、夜间仍可区分。
- 盲听三个音效，5 人至少 4 人对应到「开工/提问/完成」。
- Realme 真机 60fps，不跳位。
