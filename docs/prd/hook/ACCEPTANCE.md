# AI 联动 · 验收用例

> 覆盖安装、状态、四态动作、声音、恢复、隐私与回归。完整实现见 [engineering/dsh-hook.md](../../engineering/dsh-hook.md)。

## 1. 桌面安装与开关

| ID | Given | When | Then |
| --- | --- | --- | --- |
| HOOK-AC-01 | 桌面 App 正常启动 | 打开 系统 › 联动 | 显示「联动」段；消息 / 剪贴板页仍可用（D79） |
| HOOK-AC-02 | 未安装 DSH 联动 | 点开关 | 弹确认框，说明写 3 个文件、不装 npm 包、需重启 DSH |
| HOOK-AC-03 | 确认首次安装 | 确认 | 写入插件/配置/patch；原 patch 有备份；页面显示等待重启；不出现半成品文件 |
| HOOK-AC-04 | 已写入 | 重启 DSH | 10 秒内显示「已连接 · desktop」「插件 v3」；当前状态静态 |
| HOOK-AC-05 | 已连接 | 关闭开关 | 1–2 秒内手机回静态；页面显示已关闭；再开无需重启 |
| HOOK-AC-06 | 已安装 | 点移除并确认 | patch 标记/脚本/配置被移除；DSH 下次正常启动；页面回未安装 |
| HOOK-AC-07 | patch 含用户已有配置 | 安装/移除 | 用户原有配置保留；标记块外内容不被改写 |
| HOOK-AC-08 | patch 是 `[]`/空/非序列 | 安装 | `[]`/空可安全写入；非序列报错且不写；有明确路径/错误 |
| HOOK-AC-09 | 端口 47815 被占 | 启动 Sidekick | 自动顺延 47816–47819；配置 endpoint 写实际端口 |
| HOOK-AC-10 | DSH 未运行 | 打开页面 | 显示未连接/等待；不谎报已连接；不自动创建 profile |

## 2. DSH 状态映射

| ID | Given | When | Then |
| --- | --- | --- | --- |
| HOOK-AC-11 | DSH 已连接 | 发起一个普通 turn | 1 秒内手机进入「工作中」；会话行显示 spinner + 「正在…」动作（尚未调工具时为「正在思考」） |
| HOOK-AC-12 | turn 进行中 | 触发权限审批/ask_user_question/计划确认 | 手机进入「等你决定」；动作着急找人；不误报 |
| HOOK-AC-13 | 等用户决定 | 用户处理/审批完成 | 回「工作中」；不残留 asking |
| HOOK-AC-14 | 普通工具调用 10 次 | 不触发显式提问 | 0 次 asking 误报（code_review/permission_scan 不算） |
| HOOK-AC-15 | turn 以 completed 结束 | 观察手机 | 「完成」3s ±0.3s；然后回工作/等待/静态 |
| HOOK-AC-16 | turn 以 error/aborted 结束 | 观察 | P0 回静态；不显示完成庆祝 |
| HOOK-AC-17 | 多顶层会话 | 一个工作、一个等待 | 等你决定优先；会话数正确 |
| HOOK-AC-18 | 子代理运行 | 观察状态/计数 | 不单独计数、不驱动 asking/completed；已知父 turn 可能提前完成（P1） |
| HOOK-AC-19 | 完成脉冲 5 秒内再次完成 | 观察 | 只显示一次完成脉冲，不连续闪 |
| HOOK-AC-20 | DSH 退出/崩溃 | 等待 | 15 秒内心跳超时，手机回静态 |
| HOOK-AC-21 | DSH 恢复 | 重新启动 | 10 秒内恢复当前状态；手机可拿快照 |
| HOOK-AC-22 | 手机重连 | 桌面在 working/asking | 连接后立即显示当前稳定态；过期 completed 不补播 |
| HOOK-AC-23 | 手机从后台回前台 | asking 仍有效 | 补一次提问音（声音开）；状态正确 |
| HOOK-AC-24 | 定时提问未回答 | 观察 | 保持 asking；回答/turn 结束清除 |

## 3. 手机四态与声音

| ID | Given | When | Then |
| --- | --- | --- | --- |
| HOOK-AC-25 | 手机宠物页 | 收到四态 | 四态动作明显不同；远看轮廓/道具/主色可区分 |
| HOOK-AC-26 | 工作中 | 观察 | 前倾、双爪敲键盘、汗滴/速度线/飞纸；不是坐着微动 |
| HOOK-AC-27 | 等你决定 | 观察 | 站高、举爪、感叹号、左右找人；6 秒后降速但不消失 |
| HOOK-AC-28 | 完成 | 观察 | 双臂上举/跳起/彩纸；3 秒后收干净 |
| HOOK-AC-29 | 减少动效 | 切换四态 | 仍有四套不同静态轮廓/道具/主色；不快速循环/跳跃 |
| HOOK-AC-30 | 夜间 | 切换四态 | 静态困、工作暗、等待全亮、完成低亮但仍庆祝 |
| HOOK-AC-31 | 声音默认关 | 收到四态 | 不出声 |
| HOOK-AC-32 | 声音开 | 进入工作中 | 开工音一次；从完成/提问回工作不响 |
| HOOK-AC-33 | 声音开 | 进入等你决定 | 提问音；12s 未解决再响一次；最多 2 次 |
| HOOK-AC-34 | 声音开 | 完成 | 完成音一次；不连播；录音中则麦克风释放 3 秒后补一次 |
| HOOK-AC-35 | 录音中 | 收到任何状态 | 静音；不形成回声；期间收到 completed 时，麦克风释放 3 秒后补一声（只补一次） |
| HOOK-AC-36 | App 后台 | 收到任何状态 | 静音；回前台不补播 completed（录音补音也只在宠物页前台发生） |
| HOOK-AC-37 | 声音设置页 | 点开工/提问/完成试听 | 分别播放正确音效；开关持久化 |
| HOOK-AC-38 | 录音中 | 收到 asking/working | 宠物姿态/气泡/触感不因录音改变（D77）；AI 音效/触感在录音期间静音；麦克风 UI 自身状态正常 |

## 4. 隐私与回归

| ID | Given | When | Then |
| --- | --- | --- | --- |

| HOOK-AC-42 | 现有功能 | 跑回归 | 宠物/麦克风/聊天/剪贴板测试全绿；旧手机忽略 status 不崩 |

## 4.1 会话列表与唤起

| ID | Given | When | Then |
| --- | --- | --- | --- |
| HOOK-AC-43 | 2 个顶层会话（一个工作中、一个等决定） | 打开宠物页 | 会话卡折叠显示 1 行（asking 优先）；header 计数 2；状态图标/文案/时间正确；不自动展开 |
| HOOK-AC-44 | 有 >5 个会话 | 展开会话卡 | 只渲染前 5 行、不出现滚动容器；header 计数为总数；footer 显示「收起」；**无自动展开** |
| HOOK-AC-45 | 宠物页会话卡 | 点 asking 行 / 点其他行 | asking → 等你决定页，主按钮「在电脑上继续」发 `focus.request`；其他行无操作；不存在自动展开 |
| HOOK-AC-46 | 会话完成 | 观察 | 显示「已完成」并保留；该会话开始新一轮后变「工作中」；其它会话不受影响 |
| HOOK-AC-47 | 已完成会话 | 左滑露出「清除」并点按钮 | 行消失；提示「已清除…」；该会话产生新事件后重新出现 |
| HOOK-AC-48 | asking 会话 | 左滑露出「清除」并点按钮 | 一次点击即清除（无「再点」）；之后有新事件重新出现 |
| HOOK-AC-49 | 清除标记写入 | 杀 App 重启 | 已清除会话仍隐藏；新事件后重新出现 |
| HOOK-AC-58 | 已完成会话 `completedAt` 超过 2 小时 | 观察手机会话卡 | 自动隐藏；不写本地清除标记、不弹提示；有新事件重新出现；未超过 2 小时仍显示 |
| HOOK-AC-50 | 手机已连接、DSH 在后台 | 点 asking 会话 | 电脑 DSH ≤2s 切到前台；手机提示「已在电脑上打开」；不发送任何内容 |
| HOOK-AC-51 | DSH 未启动/未安装/限频 | 点 asking 会话 | 分别启动 DSH / 提示未找到 / 提示稍后再试；失败不谎报成功 |
| HOOK-AC-52 | 杀 DSH / 手机断线 | 观察 | 15s 内会话卡消失、宠物回静态；断连时保留最后快照并标可能过期；重连/重启 DSH 后从快照恢复 |

## 4.2 会话行工具动作（hook v3）

| ID | Given | When | Then |
| --- | --- | --- | --- |
| HOOK-AC-53 | 会话工作中 | 依次执行命令/读文件/改文件/搜索/联网/子任务/计划类工具 | 工作行 1 秒内显示 spinner + 「正在运行命令 / 正在阅读文件 / 正在修改文件 / 正在搜索代码 / 正在查资料 / 正在处理子任务 / 正在整理计划」，行尾保留「 · 相对时间」 |
| HOOK-AC-54 | 会话工作中但尚未调工具，或旧插件不发送 `tool` | 观察工作行 | 显示 spinner + 「正在思考」；不报错、不丢会话 |
| HOOK-AC-55 | 执行白名单外的自定义工具（名称/参数含敏感串） | 观察工作行与抓包 | 行内只显示「正在使用工具」；抓包/日志无工具名原文、参数、路径、模型名 |
| HOOK-AC-56 | 会话进入等你决定/完成/空闲 | 观察工作行 | 不再显示工具动作；回到对应状态文案；工具动作不残留 |
| HOOK-AC-57 | 工作行正在跑工具 A，又并行启动工具 B | 观察 | 显示最近启动的 B；B 结束后回退到仍在跑的 A；都结束后回「正在思考」 |
