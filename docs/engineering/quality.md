# 测试与发布质量

> 目标：宠物和麦克风的 P0 能在真机上稳定工作；隐私与安全边界不被“优化”掉。
> 用例细节见 [pet ACCEPTANCE](../prd/pet/ACCEPTANCE.md) 与 [mic ACCEPTANCE](../prd/mic/ACCEPTANCE.md)。

## 1. 测试金字塔

```text
        ┌──────────────┐
        │ 真机端到端    │  少量、每次发版必跑
        ├──────────────┤
        │ 集成测试      │  WS 音频流、文本输入、权限
        ├──────────────┤
        │ 组件测试      │  麦克风按钮、宠物降级、错误态
        ├──────────────┤
        │ 单元测试      │  状态机、协议、时间、持久化
        └──────────────┘
```

- 单元测试最多、最快；真机测试最少但不可省。
- 不为 UI 细节写脆弱快照；测状态和可访问性。
- 外部依赖（Tauri、ASR、辅助功能、图集解码）用 adapter/mock 隔离。

## 2. 单元测试

| 模块 | 用例 |
| --- | --- |
| 宠物状态机 | 每个转移；覆盖层/后台；负面状态 3 秒恢复；点击宠物不产生事件 |
| 精力 | 边界 0/100；睡眠恢复；时间回拨 |
| 问候/时段 | 6h/3d 阈值；夜间睡眠；睡眠优先；时区变化 |
| 持久化 | plugin-store 保存/读取；版本迁移；损坏回退；`onboarded` 与重置；旧存档 `name` 字段忽略 |
| 协议 | 消息解析；未知类型；重复 start；未知 session；大帧 |
| 音频缓冲 | 100ms 分片拼接；丢帧；取消清空；60 秒上限 |
| 文案 | 无禁用词；气泡频率；错误文案有下一步 |

## 3. 组件测试

- 麦克风按钮：idle/arming/listening/processing/delivered/error 六态。
- 取消区：上滑进入/滑回退出/松手取消。
- 宠物：静态降级、减少动效、气泡 2 行、设置保存。
- 桌面浮窗：不抢焦点逻辑（mock）、状态切换、自动收起。
- 权限引导：拒绝后不重复弹系统弹窗。
- 可访问性：标签、`aria-live`、对比度 token。

## 4. 集成测试

| 链路 | 方式 | 期望 |
| --- | --- | --- |
| WS 音频 | Rust mock 服务 + 手机 mock 采集 | start/ready/chunks/stop/result 全通 |
| 取消 | start/chunk/cancel | 不转写、缓冲清空 |
| 断线 | 录音中关闭 WS | 停止、丢弃、无后台重试 |
| 转写 | mock ASR 成功/空/超时 | 输入/提示/失败三态 |
| 文本输入 | mock 辅助功能 | 自动/复制/目标变化/密码框 |
| 宠物联动 | mock 麦克风状态 | 倾听/成功/取消/失败动作 |

## 5. 真机矩阵

| 设备 | 系统 | 场景 |
| --- | --- | --- |
| Realme RMX3370 | Android 13 | 16:9/20:9、支架/手持、录音、后台、来电、断网 |
| macOS 开发机 | 13.3+ | 转写、自动粘贴、复制、密码框、窗口切换、手动回车/清空 |
| 第二台安卓（可选） | Android 12+ | 低端性能、权限差异 |
| iOS（P2） | — | 暂不测 |

每次发版至少跑：

- 宠物：首启见面、idle、点击/长按/抚摸无反应、姿态切换、重启恢复、减少动效、60fps。
- 麦克风：按住/取消/60 秒/后台/断网/权限拒绝/自动粘贴/密码框/目标切换/结果卡片回车与清空。
- 桌面：浮窗不抢焦点、⌘Z 撤销、剪贴板降级。

## 6. 测试数据

- 30 句转写集：
  - 中文日常 15 句；
  - 代码术语 10 句（函数名、变量名、终端命令）；
  - 中英混说 5 句；
  - 安静/风扇噪声各一遍。
- 5 秒、10 秒、30 秒语音各 20 次延迟样本。
- 错误样本：空白、超短、超长、多人说话、背景音乐。
- 测试集入库（文本），音频样本不入库；记录采集条件。

## 7. 指标测量

| 指标 | 方法 |
| --- | --- |
| 端到端延迟 | 手机日志时间戳 + 桌面输入完成时间；至少 20 次 |
| 倾听反馈 | 屏幕录制逐帧/Performance 面板 |
| 帧率 | Android GPU 渲染 / Chrome Performance |
| 准确率 | 测试集人工比对；记录错误类型 |
| 掉电/发热 | 30 分钟混合使用，记录电量与温度 |
| 内存 | Android Profiler；宠物页/录音峰值 |
| 隐私 | 应用目录检查 + 抓包 + 日志抽查 |

## 8. 回归清单（每次提交/发版）

- [ ] `pnpm typecheck && pnpm lint && pnpm test && pnpm build` 全绿。
- [ ] `node scripts/check-docs.mjs` 通过。
- [ ] 平台边界检查：`node scripts/check-boundaries.mjs` 通过（迁移后自动生效）。
- [ ] 宠物 P0 AC 通过。
- [ ] 麦克风 P0 AC 通过。
- [ ] 无音频文件、无全文日志、无云端上传。
- [ ] 不自动回车/发送；密码框/窗口切换只复制。
- [ ] 真机 60fps；p95 延迟达标。
- [ ] 减少动效、权限拒绝、断网三条降级可演示。
- [ ] 协议/架构/索引文档同步。

## 9. 完成定义（DoD）

一个功能只有同时满足以下条件才算完成：

1. PRD/SPEC/ACCEPTANCE 已评审；P0 用例通过。
2. 代码通过 lint/typecheck/test/build；无新增 `any` 跨边界。
3. 真机走通正常/异常/权限三类路径。
4. 性能/电量在预算内；超预算有记录和缓解。
5. 隐私/安全边界有测试或人工检查证据。
6. 文档同步；索引链接有效。
7. 没有“先上线再补”的 P0 缺口。

## 10. 发布门

**Phase 1 发布前必须**

- [ ] 两份 PRD 的 P0 AC 全过。
- [ ] 麦克风 p95 ≤3s、成功率 ≥80%（试用基线）。
- [ ] 宠物 60fps、触摸 ≤100ms。
- [ ] 0 音频落盘、0 自动发送、0 错误目标应用。
- [ ] 权限拒绝/断网/后台/来电四条异常路径可演示。
- [ ] 文档树检查通过；协议提案与实际实现一致。
- [ ] 正式 release 签名与公证（对外分发前）；当前 `release/` 为本地密钥签名的 release 包（D63）。

## 11. 隐私与安全审计

- 检查应用私有目录：无 `.wav/.pcm/.opus` 等音频文件。
- 抓包：无云端 ASR/上报；局域网流量符合预期。
- 日志：搜索转写文本、剪贴板、目标应用名，应为 0。
- 权限：只申请 `RECORD_AUDIO` / 语音识别 / 辅助功能；无后台服务/定位/通知。
- 目标应用：密码框、窗口切换、无输入框三种场景实测。
- 依赖：`pnpm audit --prod`、许可证白名单。

## 12. CI 与命令

```bash
cd app
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm audit --prod
node ../scripts/check-docs.mjs
```

- CI 至少跑 typecheck/lint/test/build/docs。
- Rust：`cargo fmt --check`、`cargo clippy`、`cargo test`、`cargo audit`（引入后）。
- 真机测试无法完全 CI 化；发版前人工跑清单并记录。

## 13. 麦克风 / 剪贴板专项

- 麦克风协议：`cargo test --lib`（`mic_protocol` 帧往返/非法帧/session）；前端 `audio-frame.test.ts`、`messages.test.ts`。
- 录音 UI：真机长按、上滑取消、50/60 秒、后台、断连、权限说明、结果卡片；WebView 103 的 `ScriptProcessor` 必须 2 的幂。
- 自动粘贴：授权前后各跑一次；目标窗口切换、密码框/安全输入只复制；确认**不自动**发送 Return。
- 手动按键：`cargo test --lib desktop_keys key_`（按键计划/安全闸门/30 秒 TTL/一次性/限频）；真机点「回车」发送一次、点两次「清空」清空输入框；说话后切窗口/密码框/关辅助功能时只提示不按键；确认日志无文本与应用名。
- 语音页：百炼配置可保存/测试（完整 URL，无业务空间 ID）；开页不读 Keychain；未配置时手机明确报错；用量今天/7/30/365 区间切换（今天无明细、1 年按月）；清空统计只重置本地文件；`models/` 旧目录不参与运行。
- 剪贴板：复制/搜索/回填/置顶/删除/清空/暂停；Concealed 类型不记录；`clipboard.json` 权限 `600`；日志无正文。

## 14. 缺陷分级

| 级别 | 定义 | 处理 |
| --- | --- | --- |
| S0 | 隐私泄露/自动发送/数据损坏 | 立即停止发版，修复后全量回归 |
| S1 | 核心功能不可用（录不了/输不对） | 发版阻塞 |
| S2 | 明显体验问题（延迟高/掉帧/文案错误） | 本期修复或记录豁免 |
| S3 | 小瑕疵（间距/低频边界） | 可下期 |

S0/S1 不允许“已知问题”发版；S2 豁免需在 `status.md` 记录。
