# 桌面剪贴板管理

> 经用户确认的桌面 **P1 辅助能力**，与麦克风/宠物 P0 并行交付；不改变“本期两个主功能”的定位。
> 产品范围见 [scope.md](../product/scope.md)；隐私原则见 [principles.md](../product/principles.md)。

## 1. 范围

**做（P1）**

- 监听 macOS 剪贴板文本变化，保存最近 N 条（默认 100，可配 10–200，D121）；
- 语音转写成功后以 `kind = "voice"` 记入历史，和普通文本一样可搜索、复制回填、置顶；
- 搜索、复制回填、置顶、删除、清空、暂停记录；
- 本地 JSON 持久化，文件权限 `0600`；
- 过滤密码管理器标记为隐藏的内容；Sidekick 自身写入用一次性 `skip_next` 防重复入库。

**不做**

- 图片、文件、富文本；
- 全局快捷键、菜单栏入口、自动粘贴历史项；
- 手机/云端同步、来源应用识别、剪贴板历史搜索服务。

## 2. 监听与过滤

- 桌面后台线程每 500ms 读 `NSPasteboard.general.changeCount()`；变化后才读取内容。
- 先读 `types()`；出现以下任一类型直接跳过，不读取正文：
  - `org.nspasteboard.ConcealedType`
  - `org.nspasteboard.TransientType`
  - `org.nspasteboard.AutoGeneratedType`
  - 密码管理器前缀：1Password / Bitwarden / LastPass / AgileBits。
- 只读 `public.utf8-plain-text`；没有纯文本内容（例如纯图片/文件）则不记录。
- 空文本、超过 50,000 字符的文本跳过。
- 自身写入统一先设置一次性 `skip_next`，watcher 看到同一文本时跳过，避免把同一条再记一遍：
  - 语音转写：`WriteTextAndRecord` 先写系统剪贴板（用于自动粘贴/降级复制），再显式以 `kind = "voice"` 入库一次；
  - 剪贴板回填（`clipboard_copy`）：只刷新 `lastUsedAt`，不新增记录。
- 暂停记录（`enabled = false`）时语音转写仍会写系统剪贴板，但不进入历史。

## 3. 数据与保留

```json
{
  "version": 1,
  "enabled": true,
  "items": [
    {
      "id": "1793461057331-0",
      "text": "复制的文字",
      "kind": "text",
      "createdAt": 1793461057331,
      "lastUsedAt": 1793461057331,
      "pinned": false
    }
  ]
}
```

- 路径：`~/.sidekick/clipboard.json`（旧版在 `~/Library/Application Support/Sidekick/`，首次启动自动复制一次）。
- 写入：`.tmp` + rename 原子替换；Unix 权限 `0600`。
- 最多保留 N 条（默认 **100**，范围 **10–200**，用户可在剪贴板页「设置」组里改，D121）；新内容淘汰最旧的未置顶项；全部置顶时淘汰最旧置顶项；改小时**立即**按同样规则裁剪现有历史。
- 剪贴板页页头显示 `N / M 条`（`formatClipboardCount`，M 取自快照的 `maxItems`），让「只保留多少条」可见；新壳没有页脚，不再有淘汰规则的说明句。
- 相同文本去重：保留置顶状态，刷新时间并移到最新。
- 暂停记录期间仍推进 `changeCount`，不补录暂停期间的复制。
- `kind`：`http(s)://` / `mailto:` 为 `url`，语音转写为 `voice`，其余为 `text`。

## 4. 命令与 UI

| 命令 | 用途 |
| --- | --- |
| `clipboard_list` / `clipboard_status` | 返回完整快照（enabled、items、path、maxItems） |
| `clipboard_copy(id)` | 写回系统剪贴板并刷新 `lastUsedAt` |
| `clipboard_toggle_pin(id)` | 置顶/取消置顶 |
| `clipboard_delete(id)` | 删除单条 |
| `clipboard_clear()` | 清空全部（UI 二次确认） |
| `clipboard_set_enabled(enabled)` | 暂停/继续记录 |
| `clipboard_set_max_items(maxItems)` | 改「最多保留」，夹到 10–200 后立即裁剪、落盘并广播（D121） |

- 每次变更广播 `clipboard-changed` 快照；桌面 UI 订阅后刷新。
- 桌面「剪贴板」页（一级页 ⌘2；D79 起就是剪贴板唯一归属，D119 从「内容」改名）：页头 `N / M 条` + 清空（二次确认），正文是搜索、组标题「设置」下的记录开关、最多保留（20 / 50 / 100 / 200 分段）与「密码框与隐藏内容 不记录」、以及记录列表。
- 列表每行两行文字（摘要 + 来源类型 · 最近使用时间），超出截断；整行点按复制回填并 toast「已复制到剪贴板」；置顶标记常显，置顶 / 删除只在 hover 或键盘聚焦时出现。旧版「查看详情（眼睛）」弹层已删除，完整文本用行的 `title` 悬停查看，或直接点按复制。
- 设置里没有剪贴板入口与二级页（D119）：记录开关、保留条数与清空都只在剪贴板页；隐私说明在「设置 › 关于本机 › 隐私说明」。

## 5. 隐私与安全

- 只在本机；不联网、不上传、不写转写全文日志。
- 日志只记录保存失败等错误，不记录剪贴板内容。
- 密码管理器以外的敏感文本无法完全识别；提供一键清空与暂停。
- 不读取剪贴板历史应用的数据；只读系统当前剪贴板。
- 不做来源应用识别，避免额外读取窗口/焦点信息。

## 6. 验收

- 在 TextEdit 复制文本 → 1 秒内出现在列表；
- 搜索命中/不命中正确；点击条目复制回填，粘贴内容一致；
- 长文本行内截断，悬停 `title` 可看到完整文本；点按复制、置顶、删除即时生效；
- 置顶项保持顶部；删除/清空即时生效；重启应用历史恢复；
- 暂停后复制不进入列表，继续后只记录新内容；
- 把「最多保留」从 100 改成 20：列表立刻只留最新 20 条（置顶的优先保留），页头变成 `N / 20 条`，重启后仍是 20；
- 模拟 `org.nspasteboard.ConcealedType` 的密码内容不出现；
- `clipboard.json` 权限 `600`，日志无正文；
- `pnpm typecheck/lint/test/build` 与 `cargo test --lib` 通过。

## 7. 已知限制

- 仅在桌面应用运行时监听；应用退出期间不记录。
- 没有全局快捷键，需要打开 Sidekick 窗口切到「剪贴板」页。
- 不保存图片/文件；终端里的多行文本会按原样保存。
