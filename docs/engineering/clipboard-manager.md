# 桌面剪贴板管理

> 经用户确认的桌面 **P1 辅助能力**，与麦克风/宠物 P0 并行交付；不改变“本期两个主功能”的定位。
> 产品范围见 [scope.md](../product/scope.md)；隐私原则见 [principles.md](../product/principles.md)。

## 1. 范围

**做（P1）**

- 监听 macOS 剪贴板文本变化，保存最近 100 条；
- 搜索、复制回填、置顶、删除、清空、暂停记录；
- 本地 JSON 持久化，文件权限 `0600`；
- 过滤密码管理器标记为隐藏的内容与 Sidekick 自身写入。

**不做**

- 图片、文件、富文本；
- 全局快捷键、菜单栏入口、自动粘贴历史项；
- 手机/云端同步、来源应用识别、剪贴板历史搜索服务。

## 2. 监听与过滤

- 桌面后台线程每 500ms 读 `NSPasteboard.general.changeCount()`；变化后才读取内容。
- 先读 `types()`；出现以下任一类型直接跳过，不读取正文：
  - `org.nspasteboard.ConcealedType`
  - `org.nspasteboard.TransientType`
  - `org.nspasteboard.AutoGeneratedType`
  - 密码管理器前缀：1Password / Bitwarden / LastPass / AgileBits。
- 只读 `public.utf8-plain-text`；没有纯文本内容（例如纯图片/文件）则不记录。
- 空文本、超过 50,000 字符的文本跳过。
- 自身写入（语音转写、剪贴板回填）由 `ClipboardWriter` 设置一次性 `skip_next`，watcher 看到同一文本时跳过，避免把转写再次入库。

## 3. 数据与保留

```json
{
  "version": 1,
  "enabled": true,
  "items": [
    {
      "id": "1793461057331-0",
      "text": "复制的文字",
      "kind": "text",
      "createdAt": 1793461057331,
      "lastUsedAt": 1793461057331,
      "pinned": false
    }
  ]
}
```

- 路径：`~/Library/Application Support/Sidekick/clipboard.json`。
- 写入：`.tmp` + rename 原子替换；Unix 权限 `0600`。
- 最大 100 条；新内容淘汰最旧的未置顶项；全部置顶时淘汰最旧置顶项。
- 相同文本去重：保留置顶状态，刷新时间并移到最新。
- 暂停记录期间仍推进 `changeCount`，不补录暂停期间的复制。
- `kind`：`http(s)://` / `mailto:` 为 `url`，其余为 `text`。

## 4. 命令与 UI

| 命令 | 用途 |
| --- | --- |
| `clipboard_list` / `clipboard_status` | 返回完整快照（enabled、items、path、maxItems） |
| `clipboard_copy(id)` | 写回系统剪贴板并刷新 `lastUsedAt` |
| `clipboard_toggle_pin(id)` | 置顶/取消置顶 |
| `clipboard_delete(id)` | 删除单条 |
| `clipboard_clear()` | 清空全部（UI 二次确认） |
| `clipboard_set_enabled(enabled)` | 暂停/继续记录 |

- 每次变更广播 `clipboard-changed` 快照；桌面 UI 订阅后刷新。
- 桌面右侧「聊天 / 剪贴板」切换；剪贴板页含搜索、暂停、清空、条目预览与操作。
- 设置页显示记录开关、条数、清空入口和隐私说明。

## 5. 隐私与安全

- 只在本机；不联网、不上传、不写转写全文日志。
- 日志只记录保存失败等错误，不记录剪贴板内容。
- 密码管理器以外的敏感文本无法完全识别；提供一键清空与暂停。
- 不读取剪贴板历史应用的数据；只读系统当前剪贴板。
- 不做来源应用识别，避免额外读取窗口/焦点信息。

## 6. 验收

- 在 TextEdit 复制文本 → 1 秒内出现在列表；
- 搜索命中/不命中正确；点击条目复制回填，粘贴内容一致；
- 置顶项保持顶部；删除/清空即时生效；重启应用历史恢复；
- 暂停后复制不进入列表，继续后只记录新内容；
- 模拟 `org.nspasteboard.ConcealedType` 的密码内容不出现；
- `clipboard.json` 权限 `600`，日志无正文；
- `pnpm typecheck/lint/test/build` 与 `cargo test --lib` 通过。

## 7. 已知限制

- 仅在桌面应用运行时监听；应用退出期间不记录。
- 没有全局快捷键，需要打开 Sidekick 窗口切到剪贴板页。
- 不保存图片/文件；终端里的多行文本会按原样保存。
