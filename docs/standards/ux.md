# 交互与两端壳规范

> 范围：桌面端「Liquid Glass · iOS 26」壳（5 入口 + 224 玻璃侧栏 + sticky 玻璃工具栏 + 分组列表）与手机端两页壳的交互规则（导航、状态摘要、页头、滚动、空态、返回、触控），以及宠物 / 麦克风 / AI 联动的交互底线。
> 原则：一个动作可达、状态始终可见、不惩罚、不打扰。
> 页面归属与逐字状态词见 [prd/shell](../prd/shell/INDEX.md)；视觉令牌见 [visual.md](./visual.md)；本文只写「怎么交互」。
> 决策：D85（桌面结构：4 入口 / 设置 push / 删旧壳；D94 把语音提升为第 2 个一级页，变 5 入口 + 关键词）、D86（桌面质感：Liquid Glass，取代 D85 的视觉与布局数值）、D80（手机两页壳）、D81（手机字体）；D69/D77/D78 继续有效。

## 1. 平台与布局总则

- 桌面与手机是**两套固定壳**，不做跨端响应式断点；共享组件不承担跨平台布局。
- 桌面设计基准 1180×760，最小 960×640；单列固定布局（224 玻璃侧栏 + 内容最大宽 730 居中），窗口可缩放但不改变信息架构（侧栏不折叠成抽屉）。
- 手机**只做竖屏**：Android Activity 锁定 `portrait`，浏览器 dev 也不做横屏布局；旋转不改变界面。
- 所有全屏容器用 `100dvh` / `min-h-dvh`，并处理 `env(safe-area-inset-*)`；关键控件不放在刘海、挖孔、手势条、圆角裁切区域内。
- 手机竖屏最小可用 300×800，不出现横向滚动；20:9 与 16:9 都能放下。
- 删除 docked/handheld 双姿态、方向自动切换、宠物页会话浮层、设置 Sheet；只有一套竖屏壳与一套桌面壳。

## 2. 桌面壳规则

```text
┌────────────────┬──────────────────────────────────────────────┐
│ 38 交通灯区     │  sticky 玻璃工具栏（滚动后 17/600 紧凑标题）   │
│ logo 小跟班     │  概览（34/600）                      [动作组] │
│ ▸ 概览          │  组标题 13/400                                │
│   内容          │  ┌ 白卡 16 圆角（不透明） ──────────────────┐  │
│   用量          │  │ 行 54 / 图标块 30 / hairline 内缩 16     │  │
│ ──────────      │  └─────────────────────────────────────────┘  │
│ ▸ 设置          │                                               │
│ ● 服务 47810    │                                               │
│ ● 手机 1 台     │                                               │
│ ● AI 空闲       │                                               │
└────────────────┴──────────────────────────────────────────────┘
```

| 区域 | 规则 |
| --- | --- |
| 侧栏 224 | Liquid Glass 导航层（blur 30 / saturate 180 + 顶部受光）：38 交通灯区；logo 22 + 「小跟班」15/600；3 个一级入口（高 34、14/500、圆角 9，选中白色滑块 spring morph）；底部「设置」；分隔线 + 三行状态摘要（行 26、12 号、色点 7px）。 |
| 状态摘要 | 三行 = 服务（真实端口 / 未启动）、手机（N 台 / 未连接）、AI（空闲 / 工作中 / 等你决定 / 完成 / 未联动）；色点 + 文字，文字始终在场。服务与手机 → 设置 › 手机连接；AI → 设置 › AI 联动。 |
| 一级导航 | 只有 4 个：概览 ⌘1 / 内容 ⌘2 / 用量 ⌘3 / 设置 ⌘4；默认概览；任意页 ⌘1 回概览兜底。 |
| 页头 / 滚动 | **sticky 玻璃工具栏**：未滚动透明、只显示右侧动作组（二级页另有左侧「‹ 设置」返回）；滚动 > 6px 变玻璃胶囊（高 48 / 圆角 18）并淡入 17/600 紧凑标题；大标题 34/600 随后滚走；不写副题。 |
| 内容区 | 分组灰底（画布带极淡环境光）；左右 28 + 最大宽 730 居中；页内滚动、`overscroll-contain`；组间距 24；一级页 fade 320ms、二级页 push 340ms。 |
| 分组列表 | 组标题 13/400 次级灰在卡外；不透明白卡 16 圆角 + 双层阴影 + 顶部高光；行最小 54、15/400、hairline 0.5px 内缩 16（带图标块 60）；整行可点，右侧只有一值或一控件；卡尾动作用文字。 |
| 图标块 | 30×30 / 圆角 10 / 白字 / 7 个 iOS system color；不给 tone 时用薄荷线性图标（22 盒）。 |
| 语音 | 一级页（⌘2）：根页只有摘要（百炼状态 / 关键词计数 / 今天与近 7 天用量）；配置、关键词、用量用二级页 push；未配置时一张玻璃提示卡 + 「去配置」。 |
| 设置 | iOS push：首页一张分组列表（外观 / 自动输入 / 手机连接 / AI 联动 / 剪贴板 / 关于本机 / 消息通道），点进二级页；从任何页 ≤2 次点击可达（侧栏 / ⌘5）。 |
| 空态 / 错态 | 空态一行结论或一个动作（不画插画、不写「暂无数据」）；错态 = 原因 + 下一步 + 主按钮（重试 / 去开启 / 去配置）；不弹 modal、不显示堆栈。 |
| 辅助功能提示 | 只在概览页内容顶部出现一行玻璃提示（`role="status"`，未授权时才有，可关闭，带「去开启」）；不再浮在左下角，也不占其它页布局；授权后回窗口自动消失。 |
| 麦克风浮层 | 全局层：任意页右上角，宽 ≤320，不抢焦点、不挡输入；规则见 §11。 |
| 玻璃纪律 | 玻璃只给控件层（侧栏 / 工具栏 / 动作组 / 分段轨道 / 辅助功能提示 / 弹层遮罩）；内容卡、列表行、图表永远不透明；不在滚动内容上叠 `backdrop-filter`。 |
| 拖动区 | 侧栏顶部 38 与 sticky 工具栏（含二级页返回行）是拖动区；交互元素不做唯一拖动目标。 |
| 页脚 | 桌面新壳没有页脚。 |

- 焦点：内描边柔光 3.5px `--focus-ring`（不用外描边，避免列表抖动）；图标按钮必须有 `aria-label`。
- 键盘：⌘1–⌘5 切一级视图（概览 / 语音 / 内容 / 用量 / 设置）；焦点在输入框 / 下拉 / contentEditable 内时不拦截；Tab 顺序与视觉顺序一致。
- 动效：页面 fade / 二级页 push、侧栏与分段滑块 spring、按压缩放、弹层入场；只动 `transform` / `opacity` / 颜色，不做循环装饰。`prefers-reduced-motion` 关入场与缩放；`prefers-reduced-transparency` 玻璃退为 `--card` 实底。
- 桌面不渲染宠物；不做聊天为主的首页；聊天（消息）只在「设置 › 消息通道」。

## 3. 手机壳规则

```text
┌ 44 顶部条：[gear] [信号塔]        ¥0.42 [chat] ┐
│ 会话卡（置顶：折叠 1 行 / 展开最多 5 行）        │
│ 鲸鱼舞台（无底色，230 / 展开 220）              │
│ 56 薄荷圆麦克风（居中，距底 56）                │
└────────────────────────────────────────────────┘
```

| 区域 | 规则 |
| --- | --- |
| 顶部条 | 净高 44；左设置 44 热区 + 连接状态信号塔图标（连上只显示图标，不写「已连接 · 局域网」；没连上才补最短状态词，`aria-label` 保留完整连接文案与 detail）；右侧今日用量数字（「今天」花费，无快照退回仪表盘图标，点按进用量页）+ 消息 44 热区。四个热区都 ≥44。 |
| 二级页 | asking / chat / offline / scan 全屏；页头 44（返回 44 + 居中标题 + 右侧最多一个状态 / 动作）。 |
| 设置页 | 整页设置（非 sheet、非弹层），6 组顺序固定：连接 / 外观 / 反馈 / 显示 / 数据与关于（含重置宠物）/ 消息通道。 |
| 麦克风 | 空闲是 56 薄荷圆钮、居中、距底 56；录音时展开为 `min(90vw, 420px)` 胶囊，收尾时收回圆钮、只转 spinner 不写字；状态与覆盖层在按钮上方独立定位，不推动按钮。 |
| 录音中 | 所有换页入口禁用（由 `ui-store.setView` 拦截）；不切页、不弹气泡、不切换主题。 |
| 首用清单 | 设置页顶部 banner：有未完成步骤时 `首用清单 · 还差 N 步`，全部完成显示 `首用清单 · 已完成`；点开展开 4 步；①② 手机本地判定，③④ 吃桌面 `desktop.status` 真实状态，未知时「在电脑上完成」，不伪造。 |
| 宠物页 | 顶部条 → 会话卡 → 鲸鱼 → 圆麦克风；会话卡折叠 1 行 / 展开最多 5 行；没有「现在」行、气泡与首用清单。 |
| 会话卡 | AI 会话唯一入口：折叠 1 行 / 展开最多 5 行；点 asking 行进「等你决定」页；不显示剪贴板内容与 AI 提问正文。 |
| 连接页 | 连接排障唯一主入口：扫码为主按钮、手动地址同屏可展开、自动发现结果、重连行、局域网权限提示。 |
| 消息页 | 通道调试页；连接排障不在本页展开，只保留断连折叠块 + 文字入口。 |
| 空态 / 错态 | 与桌面同结构（结论 + 下一步 + 主 / 次按钮）；手机按钮高 48。 |

- 手机设置从 sheet 改为「设置」整页后，不再有盖住宠物页的设置弹层；打开设置页时按 §7 规则处理屏幕常亮。
- 手机端不渲染剪贴板历史、不做正式聊天列表、不提供批准 / 拒绝 AI 提问。

## 4. 触控与手势

- 点击目标 ≥ 44×44；麦克风胶囊高 56；桌面列表行最小 52；间距 ≥8。
- 只用三种手势：**点按、按住、上滑**。不引入双击 / 三击 / 画圈等隐藏手势做关键操作。
- 误触保护：
  - 麦克风按下 <300ms 释放：不发送，提示「按住说话」。
  - 上滑 ≥80dp（约 1.4cm）进入取消区；滑回 <32dp 退出；取消区要有明显视觉反馈。48dp 在真机上手指轻动就会误触。
- 手势不能和系统手势冲突：底部边缘 24dp 内不放主操作。
- 录音中不响应宠物触摸；换页入口禁用。
- 所有仅图标按钮必须有 `aria-label` / 可读文本。
- 不依赖 CSS `translate` 属性（WebView 103 不支持）；居中用 `inset-x-0` + flex 或 `left-0 right-0 mx-auto`。

### 4.1 系统返回键（Android）

返回键按「一次退一层」处理，和页内返回按钮、Esc（dev）走同一个处理函数：

| 当前界面 | 返回键行为 |
| --- | --- |
| 等你决定页 | 回宠物页 |
| 消息页 | 回宠物页 |
| 连接页 | 回上一页（宠物 / 消息 / 设置） |
| 扫码页 | 回连接页 |
| 更多（设置）页 | 回宠物页 |
| 宠物页（根页） | 第一次按：提示「再按一次退出」；2 秒内再按：退出 App |
| 录音中 | 先结束录音（同上滑取消），不切页 |

- 整个 App 只在启动时注册一次 `subscribeBackButton`（`shared/lib/tauri.ts`）；二级页把处理函数压入 `mobile/system-back.ts` 的返回栈，栈顶优先消费这次返回。
- 根页面不拦系统默认退出，而是走「再按一次」确认（第一次提示、2 秒内第二次调 `exitApp()`；需要 `core:app:allow-exit`，已在 `capabilities/default.json`）。
- **新增全屏页必须接入返回处理**（压栈，或在根页状态里显式优先处理），否则按返回会被根页面当成退出确认（D74 踩过）。
- Tauri 注册后不再自动退出/回退，行为完全由 JS 决定；退订后恢复系统默认。桌面端与 iOS（暂未支持）不注册；浏览器 `?role=mobile` 用 **Esc** 模拟返回键。

## 5. 按住说话标准

```text
按下 → 100ms 内进入「正在听」 → 说话 → 松手
  ├─ 在取消区松手 → 取消，丢弃音频
  ├─ 时长 <300ms → 视为误触，不发送
  ├─ 50s → 轻震 + 倒计时提示
  └─ 60s → 自动停止并转写
```

- 按下即反馈：按钮收缩、波形出现、计时开始（宠物不再响应录音，D77）。
- 倾听中始终显示：**录音指示 + 计时 + 上滑取消提示**。
- 松手后进入「转写中」，禁止再次录音，直到完成 / 失败 / 超时。
- 失败不自动重录；给「再说一次」按钮。
- App 进入后台、来电、失去麦克风焦点：立即停止并丢弃，不允许后台录音。
- 录音中不切页、不弹气泡、tab 禁用；胶囊保持不变宽不变位。
- 状态词两端同词（见 §6.3）；禁止「云端收尾」「准备中」。

## 6. 宠物状态与 AI 联动标准

宠物不提供触摸互动（D69）：点击、长按、来回抚摸都没有任何反馈，也不写存档；不要为宠物舞台添加 pointer 手势、爱心、亲密度或「摸摸/戳」入口。手机宠物舞台没有背景声呐环（D77）。

规则：

- 没有负面反应与惩罚；不跨会话记仇。录音不改变宠物姿态 / 气泡 / 触感（D77）。
- 气泡最多 1 条/30 秒，自动消失 4 秒；AI 状态文案占气泡位，优先于宠物闲聊。
- 文案不写：「你怎么才回来」「你不理我」「我饿了快喂我」。
- AI 联动展示优先级：away > asking > completed > working > sleeping/idle；completed 不跨后台 / 重连补播；asking 会唤醒睡眠。录音时只静音 AI 音效 / 触感（`micListening` 门禁）。
- AI 状态文案：工作中 5 秒淡出、等你决定持续、完成 3 秒。
- 会话行展示（D78）：工作中行 = spinner +「正在<动作>」（8 类白名单：运行命令 / 阅读文件 / 修改文件 / 搜索代码 / 查资料 / 处理子任务 / 整理计划 / 使用工具）；无 `tool` 或未知值显示「正在思考」；行尾保留相对时间。完成态行用「已完成」，保留到清除或下一轮。
- 点 asking 会话唤起电脑 DSH（`focus.request`）；手机不批准 / 拒绝。

### 6.1 状态语言规则

- 每个状态 = **文字 + 颜色点**；颜色只是第二线索，色弱也能读。3 格信号只在手机消息页的连接强度处保留。禁止只有颜色、没有文字。
- 琥珀 `--decide` 只给 AI「等你决定」；连接中 / 重连中 / 未连接 / 会话完成一律不用琥珀。
- **对象 vs 聚合**：「已完成」用于会话对象（概览当前会话行、手机会话卡行）；「完成」用于 AI 聚合态（侧栏 AI 行、概览 AI 行）。
- 两端同词：连接 7 态（服务在跑 / 服务异常 / 已连接 / 正在连接 / 正在重连 / 还没连上电脑 / 连接失败）、AI 4 态（空闲 / 工作中 / 等你决定 / 完成）、麦克风 9 态（按住说话 / 先连接电脑 / 倾听中 / 转写中 / 已输入 / 已复制到电脑 / 失败 / 已取消 / 未配置 P1）逐字见 [prd/shell/SPEC.md](../prd/shell/SPEC.md#7-状态语言逐字表)；改动必须两端同时改。
- 实时数字（倒计时、第 N 次、`N / 100 条`）必须用真实值；不造延迟 / 心跳 / 设备名。

### 6.2 空态与错态

- 空态 = 一句结论 + 一句下一步 + 主 / 次按钮；不写「暂无数据 / 可下拉刷新」。
- 错态 = 发生了什么 + 下一步 + 主按钮（重试 / 去开启 / 去配置）+ 次按钮（查看详情）；不弹 modal、不显示堆栈。
- 断连态不用琥珀；已缓存的只读内容可显示并标「可能过期」，不假装实时。

### 6.3 首次使用

- 顺序：连接（手机）→ 麦克风权限（手机）→ 百炼 Key（桌面）→ 桌面辅助功能。
- 手机首用清单的 ①② 本地验证；③④ 由桌面 `desktop.status` 上报真实状态，只有明确 true 才显示完成态；未知时写「在电脑上完成」，不伪造。
- 每步都写「为什么需要 + 跳过会怎样」；同一时刻只强调当前该做的一步。

## 7. 反馈、震动与声音

**反馈层级**：视觉 > 震动 > 声音。任何关键状态不能只靠声音。

| 事件 | 视觉 | 震动 | 声音 |
| --- | --- | --- | --- |
| 开始录音 | 波形 + 计时 + 指示 | 中 | 默认关 |
| 取消录音 | 取消区高亮 + 「已取消」 | 轻 | 默认关 |
| 转写成功 | 对勾 + 最近一次卡片 | 无（宠物不再反应，D77） | 默认关 |
| AI 开工 | 前倾敲键盘 / 速度线 | 无 | 开工音，默认关 |
| AI 提问 | 举爪 / 感叹号 / 找人 | 两下轻 | 提问音，默认关，最多 2 次 |
| AI 完成 | 跳起 / 彩纸，3 秒 | 成功震 | 完成音，默认关 |
| 失败 | 错误文案 + 重试 | 无（宠物不再反应，D77） | 默认关 |
| 连接断开 | 顶部条变灰 + 胶囊禁用 + 说明 | 无 | 无 |

- AI 联动声音只在宠物页前台、麦克风未录音时播放；录音 / 后台静音；不作为唯一提示。
- 震动默认开，可在手机「更多 → 反馈」关闭（桌面不做音效 / 触感设置）；触感由 App 原生层统一触发（`performHapticFeedback`，不申请 VIBRATE 权限，跟随系统「触摸振动」开关）；WebView 自带长按震动在启动时关闭。
- 宠物页禁用长按选中 / 复制（保持纯净）；聊天文本与输入框保留系统选择能力。
- 宠物页无操作默认 5 分钟自动暗到 70%（可调 1/2/5/10/15/30 分钟），触摸恢复；屏幕常亮默认最长 2 小时（可调，0 = 不限），只在宠物页前台生效。
- 尊重系统静音 / 勿扰；不绕过系统音量。
- 动画尊重 `prefers-reduced-motion`：减少位移 / 弹跳，保留即时状态变化。

### 7.1 外观（双主题）

设置入口：桌面「设置 › 外观」（设置首页第一组），手机「更多 → 外观」（共用 `shared/ui/theme-options.tsx`）。

| 选项 | 行为 |
| --- | --- |
| 跟随系统 | 跟随系统浅色 / 深色，系统切换即时跟随，无需重开 App；**默认值** |
| 浅色 | 强制「海面雾光 + 海玻璃」 |
| 深色 | 强制「深海自发光」 |

- **即时生效**：点选后立刻换主题，不确认、不重启、不重置设置 / 存档。
- **只存本机**：偏好只写 `localStorage`（key `sidekick:theme`），不上传、不参与同步；localStorage 不可用（隐私模式等）时静默回退深色。
- **宠物舞台随主题**：深色深海自发光，浅色海玻璃舞台（`--pet-bg #dcebe7`）；鲸鱼资产不重绘，浅底对比度偏低是已知代价（见 [visual](./visual.md) §8）。
- **始终深色的表面**用 `.deep-sea-scope` 钉住深色 pet 令牌与壳层信号色：桌面麦克风浮层、手机扫码取景，不随页面主题漂白。
- 三个选项是分段按钮（`aria-pressed`），键盘 / 辅助功能可访问；当前选中项有明确视觉态，不能只靠颜色。

## 8. 错误文案

格式：**发生了什么 + 下一步**；不指责、不卖萌、不甩代码。

| 场景 | 文案 |
| --- | --- |
| 没连接电脑 | 「还没连上电脑。先连接，再按住说话。」 |
| 麦克风权限被拒 | 「需要麦克风权限才能说话。去系统设置打开后回来。」 |
| 桌面辅助功能未开 | 「已复制到电脑剪贴板。要自动输入，请在电脑上允许 Sidekick 的辅助功能。」 |
| 转写为空 | 「没听清。靠近一点，再说一次。」 |
| 网络断开 | 「连接断了，这段没有发送。检查 Wi-Fi 后再试。」 |
| 目标窗口变化 | 「你切到了别的窗口，文字已复制，避免输错地方。」 |
| 密码框 | 「当前是密码输入框，已复制，未自动输入。」 |
| 电脑端版本旧 | 「电脑端需要更新才能接收语音。」 |
| 连接页 0 台 | 「没找到电脑。确认同一 Wi-Fi、电脑端开着、防火墙允许 Sidekick 接入。」 |
| 扫码没识别到 | 「没识别到。对准电脑上的二维码再试，或返回手动输入地址。」 |
| DSH 唤起失败 | 「没打开，电脑上 DeepSeek Harness 在运行吗？」 |

禁止：`Error 500`、`操作失败`、`请重试`（没有下一步）、`你怎么...`。

## 9. 隐私提示

- 录音时始终有可见指示（脉冲点 + 「正在听」+ 计时），不能只靠麦克风按钮变色。
- 首次录音前解释：只在按住时录、松手即停、不保存音频。
- App 进入后台立即停止；回来时明确告知「已取消」。
- 手机不显示剪贴板内容与 AI 提问正文。
- 桌面手机台数是近似值（`clients - 1`，含网页预览），文案用「N 台设备」，不显示设备名。
- 任何上传 / 云转写必须单独开关 + 明确告知，不能默认开启。

## 10. 无障碍

- 文本对比 ≥ 4.5:1；大文本 ≥ 3:1；不以颜色作为唯一状态提示。深色 / 浅色两套主题都要满足，不能只测一套。
- 所有交互可键盘 / 辅助功能访问；图标按钮有标签；焦点可见。
- 侧栏三行状态摘要都是按钮并带 `aria-label`；色点 `aria-hidden`、文字始终在场；当前导航项 `aria-current="page"`；辅助功能提示 `role="status"`；会话卡折叠按钮用 `aria-expanded`；页头标题是页面 h1。
- 宠物状态变化用文字 / 气泡补充，不只靠表情。
- 减少动效时保留：状态切换、按钮反馈；去掉：随机 idle、弹跳、粒子。
- 录音 / 转写状态用 `aria-live="polite"` 播报，避免频繁打断。
- 触控目标、间距、安全区按本文件执行；不做「像素级精准点击」。

## 11. 桌面端麦克风浮窗（不属于移动布局）

- 不抢焦点、不挡当前输入；默认右上角，避开菜单栏与 Dock；宽 ≤320。
- 状态：倾听中 / 转写中 / 已输入 / 已复制 / 失败；完成后 2 秒收起，失败保留 5 秒。
- 只显示状态、计时、简短结果；详细内容在手机端。
- 不自动按回车、不自动发送；只输入文本。
- 目标窗口变化 / 密码框时只复制，并明确提示。
- **倾听中右侧常显「取消录音」**：点击立即丢弃当前会话，不转写、不插入；转写中 / 已输入 / 失败不显示。电脑端必须有一个人工中断入口，不能只能等手机超时。
- 取消后浮层显示「已取消」1.8 秒；服务端看门狗取消显示「录音超时，已自动停止。」。
- 浮层用 `.deep-sea-scope` 恒定深海，不随页面主题漂白。
