# 交互与竖屏规范

> 范围：手机竖屏的宠物、会话列表与麦克风；桌面端只做麦克风状态浮窗，不套用本文件的移动布局。
> 原则：一个动作可达、状态始终可见、不惩罚、不打扰。

## 1. 平台与布局总则

- 手机端**只做竖屏**：Android Activity 锁定 `portrait`，浏览器 dev 也不做横屏布局；旋转不改变界面。
- 桌面和手机是两套固定壳，**不做跨端响应式断点**；共享组件不负责跨端布局。
- 删除 docked/handheld 双姿态与方向自动切换；只有一套竖屏舞台。
- 所有全屏容器用 `100dvh` / `min-h-dvh`，并处理 `env(safe-area-inset-*)`。
- 关键控件不放在刘海、挖孔、手势条、圆角裁切区域内。
- 竖屏最小可用高度按 640dp 设计；20:9 与 16:9 竖屏都要能放下，不出现横向滚动。

## 2. 竖屏分区

```text
┌──────────────────────┐
│ 安全区（顶部）         │
│ [设置]        [聊天 ●]│
│ ┌ 会话（可选）──────┐ │
│ │ 收起 1 条 / 展开 5 条│ │
│ └───────────────────┘ │
│     心情气泡（≤2 行）   │
│       宠物舞台          │
│        （视觉中心）      │
│  [ 🎙 按住说话 ]        │
│ 安全区（底部手势条）     │
└──────────────────────┘
```

| 区域 | 占比 | 规则 |
| --- | --- | --- |
| 顶部信息区 | 10–20% | 设置/聊天、会话列表、气泡；会话列表展开时隐藏气泡 |
| 宠物舞台 | 45–55% | 视觉中心；点击/抚摸热区比视觉大 24dp；有会话列表时整体下移 |
| 底部控制区 | 10–15% | 56px 高宽胶囊，水平居中；覆盖层在胶囊上方独立定位 |
| 安全边距 | 24dp | 刘海、圆角、手势条额外避让 |

## 3. 会话列表与麦克风胶囊

| 项 | 规则 |
| --- | --- |
| 会话列表入口 | 宠物上方；默认收起只显示优先级最高的一条；点收起条/箭头展开 |
| 展开高度 | 头部约 32px + 最多 5 行（行高约 46px），超出内部滚动 |
| 宠物位移 | 收起下移 32px、展开下移 56px；展开时隐藏气泡 |
| 自动展开 | 新出现「等你决定」的会话自动展开一次；手动收起后仅新的 asking 才再展开 |
| 麦克风按钮 | 56px 高、`min(86vw,360px)` 宽胶囊；录音/处理状态在胶囊内，不再出现独立录音卡片 |
| 覆盖层 | 实时文本/结果卡片在胶囊上方独立定位，出现/消失不推动按钮 |
| 取消 | 只保留上滑手势（≥48dp 进入、<24dp 退出）；不设左下取消按钮 |

**布局规则**

1. 录音过程中冻结布局，按钮固定在底部，不因录音条/结果卡片/提示变化而位移。
2. 覆盖层使用独立绝对定位层，不参与按钮容器宽度计算。
3. 不写 `landscape:` / orientation 断点；不依赖 CSS `translate` 属性（WebView 103 不支持）。
4. 展开/收起、宠物下移尊重减少动效；减少动效时立即完成。

## 4. 触控与手势

- 点击目标 ≥ 44dp；麦克风胶囊高 56px；间距 ≥ 8dp。
- 只用三种手势：**点按、按住、上滑**。不引入双击/三击/画圈等隐藏手势做关键操作。
- 误触保护：
  - 麦克风按下 <300ms 释放：不发送，提示“按住说话”。
  - 上滑 ≥48dp 进入取消区；取消区要有明显视觉反馈。
- 手势不能和系统手势冲突：底部边缘 24dp 内不放主操作。
- 录音中禁止宠物触摸抢事件；麦克风按钮优先。
- 所有仅图标按钮必须有 `aria-label` / 可读文本。

### 4.1 系统返回键（Android）

返回键按“一次退一层”处理，和页内返回按钮、Esc 走同一个处理函数：

| 当前界面 | 返回键行为 |
| --- | --- |
| 设置页 | 关闭设置，回到宠物舞台 |
| 会话列表展开 | 先收起列表；再按回到宠物舞台的退出逻辑 |
| 设置页 · 重置确认展开 | 先收起确认，再按才关闭设置 |
| 聊天页 | 回到宠物舞台 |
| 宠物主界面 | 第一次按：提示「再按一次退出」；2 秒内再按：退出 App |

- 整个 App 只在启动时注册一次 `subscribeBackButton`（`shared/lib/tauri.ts`）；设置页、聊天页把处理函数压入 `mobile/system-back.ts` 的返回栈，栈顶优先消费这次返回。
- 根页面不拦系统默认退出，而是走「再按一次」确认：第一次按出提示（2 秒窗口），第二次才调用 `exitApp()` 退出（Android 需要 `core:app:allow-exit` 权限，已加在 `capabilities/default.json`）。
- 注册后 Tauri 不再自动退出/回退，行为完全由 JS 决定；退订后恢复系统默认。
- 桌面端与 iOS（暂未支持）不注册，调用无效；浏览器 `?role=mobile` 环境用 **Esc** 模拟返回键。

## 5. 按住说话标准

```text
按下 → 100ms 内进入“正在听” → 说话 → 松手
  ├─ 在取消区松手 → 取消，丢弃音频
  ├─ 时长 <300ms → 视为误触，不发送
  ├─ 50s → 轻震 + 倒计时提示
  └─ 60s → 自动停止并转写
```

- 按下即反馈：按钮收缩、波形出现、计时开始、宠物竖耳。
- 倾听中始终显示：**录音指示 + 计时 + 上滑取消提示**。
- 松手后进入“转写中”，禁止再次录音，直到完成/失败/超时。
- 失败不自动重录；给“再说一次”按钮。
- App 进入后台、来电、失去麦克风焦点：立即停止并丢弃，不允许后台录音。

## 6. 宠物交互标准

| 动作 | 手势 | 反馈 | 限制 |
| --- | --- | --- | --- |
| 摸摸 | 在宠物区域来回滑动，1.5 秒内至少 2 次方向变化，持续 3 秒 | 靠近、闭眼、轻震；开心 + 爱心 ≤6 | 冷却 2 秒（手势结束起算） |
| 戳一戳 | 点按 <250ms | 看向手指、好奇 | 冷却 2 秒；冷却期点击丢弃、不计数、不排队 |
| 快速连戳（P1） | 2 秒内 3 次点按 | 扭头 3 秒，之后恢复 | 冷却 5 秒；本轮不实现 |
| 喂零食（P1） | 拖星星到宠物 | 开心进食 | 不做库存/饥饿惩罚 |

规则：

- 热区比宠物视觉大 24dp；点不到不是用户的问题；滑动 slop 8px 起步，真机校准。
- 指针抬起后 2 秒无新触摸回 idle；负面反应最多持续 3 秒，不跨会话记仇。
- 多指触摸只认第一根手指；录音中禁用宠物互动。
- 气泡最多 1 条/30 秒，自动消失 4 秒；录音中不出气泡。
- 文案不写：“你怎么才回来”“你不理我”“我饿了快喂我”。
- AI 联动状态优先级：away > listening > interacting > celebrating/concerned > asking > completed > working > sleeping/idle；倾听/摸摸结束后恢复 AI；completed 不跨后台/重连补播；asking 会唤醒睡眠。
- AI 状态文案占气泡位，优先于宠物闲聊；工作 5 秒淡出、等你决定持续、完成 3 秒。
- 会话列表展示 asking/working/已完成/空闲；完成态保留到清除或下一轮；点 asking 会话唤起电脑 DSH。

## 7. 反馈、震动与声音

**反馈层级**：视觉 > 震动 > 声音。任何关键状态不能只靠声音。

| 事件 | 视觉 | 震动 | 声音 |
| --- | --- | --- | --- |
| 摸到宠物 | 闭眼/靠近 | 轻 | 默认关 |
| 开始录音 | 波形 + 计时 + 指示 | 中 | 默认关 |
| 取消录音 | 取消区高亮 + “已取消” | 轻 | 默认关 |
| 转写成功 | 对勾 + 最近一次卡片 | 两下轻 | 默认关 |
| AI 开工 | 前倾敲键盘/速度线 | 无 | 开工音，默认关 |
| AI 提问 | 举爪/感叹号/找人 | 两下轻 | 提问音，默认关，最多 2 次 |
| AI 完成 | 跳起/彩纸，3 秒 | 成功震 | 完成音，默认关 |
| 失败 | 错误文案 + 重试 | 一下重 | 默认关 |
| 连接断开 | 麦克风按钮禁用 + 说明 | 无 | 无 |

- AI 联动声音只在宠物页前台、麦克风未录音时播放；录音/后台静音；不作为唯一提示。
- 震动默认开，可在设置关闭；触感由 App 原生层统一触发（`performHapticFeedback`，不申请 VIBRATE 权限，跟随系统「触摸振动」开关）；WebView 自带的长按震动在启动时关闭，长按不再由系统代发。
- 宠物页禁用长按选中/复制（保持纯净）；聊天文本与输入框保留系统选择能力。
- 宠物页无操作默认 5 分钟自动暗到 70%（可调 1/2/5/10/15/30 分钟），触摸恢复；屏幕常亮默认最长 2 小时（可调，0 = 不限）。
- 尊重系统静音/勿扰；不绕过系统音量。
- 动画尊重 `prefers-reduced-motion`：减少位移/弹跳，保留即时状态变化。

## 8. 错误文案

格式：**发生了什么 + 下一步**；不指责、不卖萌、不甩代码。

| 场景 | 文案 |
| --- | --- |
| 没连接电脑 | “还没连上电脑。先连接，再按住说话。” |
| 麦克风权限被拒 | “需要麦克风权限才能说话。去系统设置打开后回来。” |
| 桌面辅助功能未开 | “已复制到电脑剪贴板。要自动输入，请在电脑上允许 Sidekick 的辅助功能。” |
| 转写为空 | “没听清。靠近一点，再说一次。” |
| 网络断开 | “连接断了，这段没有发送。检查 Wi-Fi 后再试。” |
| 目标窗口变化 | “你切到了别的窗口，文字已复制，避免输错地方。” |
| 密码框 | “当前是密码输入框，已复制，未自动输入。” |
| 电脑端版本旧 | “电脑端需要更新才能接收语音。” |

禁止：`Error 500`、`操作失败`、`请重试`（没有下一步）、`你怎么...`。

## 9. 隐私提示

- 录音时始终有可见指示（脉冲点 + “正在听” + 计时），不能只靠麦克风按钮变色。
- 首次录音前解释：只在按住时录、松手即停、不保存音频。
- App 进入后台立即停止；回来时明确告知“已取消”。
- 桌面上传/云转写如果未来引入，必须单独开关 + 明确告知，不能默认开启。

## 10. 无障碍

- 文本对比 ≥ 4.5:1；大文本 ≥ 3:1；不以颜色作为唯一状态提示。
- 所有交互可键盘/辅助功能访问；图标按钮有标签；焦点可见。
- 宠物状态变化用文字/气泡补充，不只靠表情。
- 减少动效时保留：状态切换、按钮反馈；去掉：随机 idle、弹跳、粒子。
- 录音/转写状态用 `aria-live="polite"` 播报，避免频繁打断。
- 触控目标、间距、安全区按本文件执行；不做“像素级精准点击”。

## 11. 桌面端麦克风浮窗（不属于移动布局）

- 不抢焦点、不挡当前输入；默认右上角，避开菜单栏与 Dock。
- 状态：倾听中 / 转写中 / 已输入 / 失败；完成后 2 秒收起，失败保留 5 秒。
- 宽度 ≤ 320dp；只显示状态、计时、简短结果；详细内容在手机端。
- 不自动按回车、不自动发送；只输入文本。
- 目标窗口变化/密码框时只复制，并明确提示。

## 12. 交互验收清单

- [ ] 竖屏 16:9、20:9 都不遮挡、不横向/纵向滚动；旋转不重排。
- [ ] 会话列表展开/收起、宠物下移不遮挡宠物与麦克风；录音时按钮不跳位。
- [ ] 按住说话：按下 100ms 内有反馈；上滑取消有明确反馈。
- [ ] 录音中始终有可见指示；后台立即停止。
- [ ] 所有主操作 ≥44dp，麦克风胶囊高 56px。
- [ ] 错误文案都有“下一步”。
- [ ] 减少动效下无强制动画。
- [ ] 宠物不遮挡麦克风、波形、计时、取消区。
- [ ] 任何操作都不自动发送/回车。
