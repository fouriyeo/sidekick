# 交互与横屏规范

> 范围：手机横屏的宠物与麦克风；桌面端只做麦克风状态浮窗，不套用本文件的移动布局。
> 原则：一个动作可达、状态始终可见、不惩罚、不打扰。

## 1. 平台与布局总则

- 手机只做**横屏**；竖屏只显示“请横屏使用”的提示，不提供完整布局。
- 桌面和手机是两套固定壳，**不做跨端响应式断点**；共享组件不负责跨端布局。
- 手机端支持两种姿态：**支架模式（docked）**、**手持模式（handheld）**；这是状态切换，不是媒体查询。
- 所有全屏容器用 `100dvh` / `min-h-dvh`，并处理 `env(safe-area-inset-*)`。
- 关键控件不放在刘海、挖孔、手势条、圆角裁切区域内。
- 横屏最小可用高度按 360dp 设计；20:9 与 16:9 都要能放下，不出现横向滚动。

## 2. 横屏分区

```text
┌──────────────────────────────────────────────────┐
│ 安全区（顶部）                                     │
│  ┌──────────────┐          ┌──────────────────┐  │
│  │ 心情气泡      │          │                  │  │
│  │ 最多 2 行     │          │   宠物舞台        │  │
│  └──────────────┘          │   （视觉中心）     │  │
│                            │                  │  │
│  [设置]        [摸摸提示]   └──────────────────┘  │
│                    [ 按住说话 ] / [🎤]            │
│ 安全区（底部手势条）                               │
└──────────────────────────────────────────────────┘
```

| 区域 | 占比 | 规则 |
| --- | --- | --- |
| 顶部信息区 | 10–15% | 气泡/状态；不可放关键按钮；最多 2 行 |
| 宠物舞台 | 50–65% | 视觉中心；点击/抚摸热区比视觉大 24dp |
| 底部控制区 | 25–35% | 主操作在右手拇指弧内；左手区放取消/次要操作 |
| 安全边距 | 24dp | 刘海、圆角、手势条额外避让 |

## 3. 支架模式 vs 手持模式

| 项 | 支架模式（docked） | 手持模式（handheld） |
| --- | --- | --- |
| 距离 | 40–70cm | 20–30cm |
| 宠物 | 更大，居中偏右 | 上 2/3，给底部控制让位 |
| 麦克风入口 | 底部居中胶囊，高 72dp | 右下圆形按钮，直径 96dp |
| 取消区 | 胶囊上滑取消 | 左下角“取消”按钮 + 上滑取消 |
| 界面元素 | 5 秒无操作自动隐藏 | 常显 |
| 屏幕常亮 | 充电时默认开启（可关） | 仅录音时保持 |
| 触控目标 | ≥ 56dp | ≥ 64dp |

**切换规则**

1. 默认自动：充电中 + 静止 10 秒 → 支架；检测到拿起/移动 → 手持。
2. 自动判断不确定时保持上一次模式，不来回跳。
3. 设置里始终可以手动锁定模式；手动选择优先于自动。
4. 录音过程中不切换布局；等录音结束再切换。
5. 切换动画 320ms spring；宠物和按钮不重叠、不跳位。

## 4. 触控与手势

- 点击目标 ≥ 48dp；主麦克风按钮 ≥ 72dp；间距 ≥ 8dp。
- 只用三种手势：**点按、按住、上滑**。不引入双击/三击/画圈等隐藏手势做关键操作。
- 误触保护：
  - 麦克风按下 <300ms 释放：不发送，提示“按住说话”。
  - 上滑 ≥48dp 进入取消区；取消区要有明显视觉反馈。
- 手势不能和系统手势冲突：底部边缘 24dp 内不放主操作。
- 录音中禁止宠物触摸抢事件；麦克风按钮优先。
- 所有仅图标按钮必须有 `aria-label` / 可读文本。

## 5. 按住说话标准

```text
按下 → 100ms 内进入“正在听” → 说话 → 松手
  ├─ 在取消区松手 → 取消，丢弃音频
  ├─ 时长 <300ms → 视为误触，不发送
  ├─ 50s → 轻震 + 倒计时提示
  └─ 60s → 自动停止并转写
```

- 按下即反馈：按钮收缩、波形出现、计时开始、宠物竖耳。
- 倾听中始终显示：**录音指示 + 计时 + 上滑取消提示**。
- 松手后进入“转写中”，禁止再次录音，直到完成/失败/超时。
- 失败不自动重录；给“再说一次”按钮。
- App 进入后台、来电、失去麦克风焦点：立即停止并丢弃，不允许后台录音。

## 6. 宠物交互标准

| 动作 | 手势 | 反馈 | 限制 |
| --- | --- | --- | --- |
| 摸摸 | 在宠物区域来回滑动，1.5 秒内至少 2 次方向变化 | 靠近、闭眼、轻震；3 秒后开心 + 爱心 | 冷却 2 秒；不要求精确路径 |
| 戳一戳 | 点按 <250ms | 看向手指、好奇 | 2 秒内 3 次 → 扭头 3 秒，之后恢复 |
| 喂零食（P1） | 拖星星到宠物 | 开心进食 | 不做库存/饥饿惩罚 |

规则：

- 热区比宠物视觉大 24dp；点不到不是用户的问题。
- 负面反应最多持续 3 秒，不跨会话记仇。
- 多指触摸只认第一根手指；录音中禁用宠物互动。
- 气泡最多 1 条/30 秒，自动消失 4 秒；录音中不出气泡。
- 文案不写：“你怎么才回来”“你不理我”“我饿了快喂我”。

## 7. 反馈、震动与声音

**反馈层级**：视觉 > 震动 > 声音。任何关键状态不能只靠声音。

| 事件 | 视觉 | 震动 | 声音 |
| --- | --- | --- | --- |
| 摸到宠物 | 闭眼/靠近 | 轻 | 默认关 |
| 开始录音 | 波形 + 计时 + 指示 | 中 | 默认关 |
| 取消录音 | 取消区高亮 + “已取消” | 轻 | 默认关 |
| 转写成功 | 对勾 + 最近一次卡片 | 两下轻 | 默认关 |
| 失败 | 错误文案 + 重试 | 一下重 | 默认关 |
| 连接断开 | 麦克风按钮禁用 + 说明 | 无 | 无 |

- 震动默认开，可在设置关闭；声音默认关，避免办公室打扰。
- 尊重系统静音/勿扰；不绕过系统音量。
- 动画尊重 `prefers-reduced-motion`：减少位移/弹跳，保留即时状态变化。

## 8. 错误文案

格式：**发生了什么 + 下一步**；不指责、不卖萌、不甩代码。

| 场景 | 文案 |
| --- | --- |
| 没连接电脑 | “还没连上电脑。先连接，再按住说话。” |
| 麦克风权限被拒 | “需要麦克风权限才能说话。去系统设置打开后回来。” |
| 桌面辅助功能未开 | “已复制到电脑剪贴板。要自动输入，请在电脑上允许 Sidekick 的辅助功能。” |
| 转写为空 | “没听清。靠近一点，再说一次。” |
| 网络断开 | “连接断了，这段没有发送。检查 Wi-Fi 后再试。” |
| 目标窗口变化 | “你切到了别的窗口，文字已复制，避免输错地方。” |
| 密码框 | “当前是密码输入框，已复制，未自动输入。” |
| 电脑端版本旧 | “电脑端需要更新才能接收语音。” |

禁止：`Error 500`、`操作失败`、`请重试`（没有下一步）、`你怎么...`。

## 9. 隐私提示

- 录音时始终有可见指示（脉冲点 + “正在听” + 计时），不能只靠麦克风按钮变色。
- 首次录音前解释：只在按住时录、松手即停、不保存音频。
- App 进入后台立即停止；回来时明确告知“已取消”。
- 桌面上传/云转写如果未来引入，必须单独开关 + 明确告知，不能默认开启。

## 10. 无障碍

- 文本对比 ≥ 4.5:1；大文本 ≥ 3:1；不以颜色作为唯一状态提示。
- 所有交互可键盘/辅助功能访问；图标按钮有标签；焦点可见。
- 宠物状态变化用文字/气泡补充，不只靠表情。
- 减少动效时保留：状态切换、按钮反馈；去掉：随机 idle、弹跳、粒子。
- 录音/转写状态用 `aria-live="polite"` 播报，避免频繁打断。
- 触控目标、间距、安全区按本文件执行；不做“像素级精准点击”。

## 11. 桌面端麦克风浮窗（不属于移动布局）

- 不抢焦点、不挡当前输入；默认右上角，避开菜单栏与 Dock。
- 状态：倾听中 / 转写中 / 已输入 / 失败；完成后 2 秒收起，失败保留 5 秒。
- 宽度 ≤ 320dp；只显示状态、计时、简短结果；详细内容在手机端。
- 不自动按回车、不自动发送；只输入文本。
- 目标窗口变化/密码框时只复制，并明确提示。

## 12. 交互验收清单

- [ ] 横屏 16:9、20:9 都不遮挡、不横向滚动。
- [ ] 支架/手持切换不打断录音，按钮不跳位。
- [ ] 按住说话：按下 100ms 内有反馈；上滑取消有明确反馈。
- [ ] 录音中始终有可见指示；后台立即停止。
- [ ] 所有主操作 ≥48dp，麦克风 ≥72dp。
- [ ] 错误文案都有“下一步”。
- [ ] 减少动效下无强制动画。
- [ ] 宠物不遮挡麦克风、波形、计时、取消区。
- [ ] 任何操作都不自动发送/回车。
