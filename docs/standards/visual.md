# 视觉与动效规范

> 概念：**夜灯桌宠**。深色房间里的一盏暖灯，灯下有一只柔软、手绘感的小家伙。
> 宠物是视觉中心；UI 退后，不抢戏。暗色优先，本期不做浅色主题。

## 1. 视觉原则

1. **一个暖焦点**：画面只允许宠物和麦克风状态使用高饱和暖色；其它区域保持低对比。
2. **柔软有触感**：圆角、软阴影、黏土质感；不用硬边框、玻璃拟态、霓虹发光。
3. **手绘不完美**：轮廓允许轻微不对称；避免工业级完美几何。
4. **克制的动**：呼吸、眨眼、尾巴；不做持续粒子、全屏漂浮。
5. **可读性优先**：情绪表达不能牺牲文字对比和按钮识别。
6. **性能即风格**：安卓上避免大面积 blur/filter；用 transform/opacity 做动画。

## 2. 色彩

基础层沿用现有 shadcn 暗色令牌（[tokens.css](../../app/src/shared/styles/tokens.css)）；宠物舞台暖色作用域令牌已于 2026-10-31 写入 `tokens.css`，组件只引用语义令牌。

| 令牌（已落地） | 值 | 用途 |
| --- | --- | --- |
| `--pet-bg` | `oklch(0.17 0.02 260)` | 宠物舞台背景，比全局背景略深 |
| `--pet-glow` | `oklch(0.82 0.12 75 / 0.32)` | 宠物背后的暖光晕 |
| `--pet-primary` | `oklch(0.78 0.13 70)` | 麦克风主按钮、关键状态 |
| `--pet-primary-foreground` | `oklch(0.2 0.03 60)` | 暖色上的文字 |
| `--pet-coral` | `oklch(0.72 0.14 30)` | 录音/取消/爱心点缀 |
| `--pet-success` | `oklch(0.78 0.1 160)` | 完成 |
| `--pet-danger` | `oklch(0.66 0.18 25)` | 失败，仅小面积 |
| `--pet-text` | `oklch(0.94 0.015 80)` | 舞台主文字，暖白 |
| `--pet-muted` | `oklch(0.72 0.02 80)` | 次要文字 |
| `--pet-border` | `oklch(0.32 0.02 260)` | 分隔线/卡片边 |

规则：

- 暖色只用于“宠物/麦克风状态”；导航、设置、系统提示继续用现有 `primary`（靛蓝）。
- 不用纯黑 `#000` 和纯白 `#fff`；暗色背景保留一点蓝紫，和暖光形成对比。
- 录音状态用暖珊瑚 + 脉冲点，不用刺眼大红；失败才用 danger 小面积。
- 所有文字对比用工具验证 ≥4.5:1；颜色不是唯一状态提示。
- 宠物本体颜色不超过 4 个主色 + 2 个点缀；避免彩虹渐变。

## 3. 字体

- 系统栈：`-apple-system, "PingFang SC", "Noto Sans CJK SC", sans-serif`。
- 不打包第三方中文字体；不引 CDN 字体。
- 标题 600–700 字重；正文 400–500；计时/数字用 tabular numbers。
- 字号：舞台标题 20–24；气泡 15–17；按钮 16–18；辅助文字 ≥12，正文 ≥14。
- 行高：正文 1.5；气泡 1.4；按钮单行。
- 不使用全大写英文做装饰；不滥用字间距。

## 4. 形状与层次

- 圆角：宠物卡片/气泡 20–28；按钮 16–20；胶囊 999；麦克风主按钮圆形。
- 阴影：柔和、低对比；黏土感用内阴影 + 外阴影，但只在桌面端或静态卡片使用；安卓动画元素避免阴影动画。
- 边框：1px 低对比描边即可；不用 3–4px 粗边框（Neubrutalism 不适合本产品）。
- 层次：背景 → 光晕 → 宠物 → 气泡 → 控制区；z-index 固定层级，不临时加 9999。
- 不用玻璃拟态、大面积 `backdrop-filter`、渐变光斑堆叠。

## 5. 图标

- 统一 lucide-react，线宽 2，圆角端点；尺寸 20/24/28。
- 麦克风、取消、设置、重试必须有文字或 `aria-label`，不只靠图标。
- 不使用 emoji 当图标；宠物表情由 Rive 资产表达，不用 emoji 拼贴。
- 图标颜色跟随文字层级，不单独用彩色图标制造噪音。

## 6. 宠物美术方向

**风格**：柔软黏土 / 手绘矢量（2.5D 感），圆润、微胖、短肢、大头，表情靠眼睛、眉毛、耳朵、尾巴。

**比例与识别**

- 头部占身体 45–55%；轮廓在 240px 宽时仍可识别。
- 剪影优先：去掉颜色也能认出是同一只宠物。
- 眼睛是情绪主载体；嘴部简化；不做拟真毛发。
- 默认姿态：坐姿，尾巴可见，耳朵有轻微不对称。
- 不穿复杂服装；配饰是 P1，且不影响剪影。

**颜色**

- 本体：暖米/奶油/浅陶土；阴影用低饱和紫灰，不用纯黑。
- 点缀：珊瑚、琥珀、薄荷（三选二）；与舞台暖光协调。
- 禁止：荧光色、彩虹渐变、金属质感、写实眼球高光。

**Rive 资产要求**

- 分层：身体、头、耳朵、眼睛、眉毛、嘴、尾巴、光晕分开；便于状态机组合。
- 网格/骨骼数量控制在中端安卓可 60fps 的范围内；避免大面积网格变形。
- 状态机输入命名稳定：`mood`、`energy`、`trigger_pet`、`trigger_poke`、`trigger_listen`、`trigger_success`、`trigger_cancel`、`trigger_error`、`trigger_wake`、`is_night`。
- 单个 `.riv` ≤2MB；纹理图集 ≤2048；不把音频塞进 `.riv`。
- 提供静态 SVG/PNG/WebP 降级图；Rive 加载失败时使用（当前实现为内联 SVG + CSS 呼吸）。
- 动画命名和状态映射写入 [engineering/pet-runtime.md](../engineering/pet-runtime.md)。

## 7. 动效

| 层 | 引擎 | 用途 | 约束 |
| --- | --- | --- | --- |
| 微动效 | CSS transition | 按钮按下、颜色、透明度、呼吸灯 | 120–180ms；只动 transform/opacity |
| 界面 | Motion | 姿态切换、气泡、卡片进出 | 240–320ms；spring 或统一 easing |
| 角色 | Rive | 宠物 idle、互动、倾听、庆祝、困倦 | 状态机驱动；懒加载；后台暂停 |

- 时长令牌：120 / 180 / 240 / 320ms；缓动统一 `--ease-out-soft` 或 Motion spring。
- 宠物 idle：呼吸 3–5 秒循环；眨眼 2–6 秒随机；张望/伸懒腰 4–12 秒随机。
- 触摸反馈 ≤100ms；开心/庆祝 ≤2 秒；失败关心 ≤1.5 秒。
- 不做持续全屏粒子；爱心粒子最多 6 个，1 秒内消失。
- `prefers-reduced-motion: reduce`：去掉随机 idle、弹跳、爱心粒子、闪光；保留状态切换的即时表情（交叉淡入 120ms）与按钮反馈；睡觉/醒来越过动画，直接用静态姿势。
- 后台/息屏暂停 Rive；回前台恢复并先眨眼一次，避免“突然复活”。

## 8. 声音

- 默认关闭；设置里可开（本轮未接入，设置项 disabled；P1 接入）。
- 声音只做点缀：轻“咪”、呼噜、完成提示；不循环、不尖锐。
- 不绕过系统静音；不在录音时播放声音，避免回声。
- 所有声音信息必须有视觉替代。

## 9. 资源与性能

- 图片 WebP/AVIF；图标 SVG；`.riv` 懒加载，不进首屏。
- 不打包中文字体；如需品牌字体，必须子集化并走依赖审批。
- 宠物舞台 `devicePixelRatio` 上限 2；安卓避免大面积 blur/shadow 动画。
- 真机 60fps 是硬指标；掉帧就减粒子/网格，不降整体帧率目标。
- 暗色 OLED 防烧屏：屏幕常亮已落地（默认开，宠物页前台生效），支架模式 2 分钟无操作自动暗到 70%，触摸恢复；宠物仍有轻微呼吸，不长期静止。

## 10. 交接

- 设计令牌落地到 `app/src/shared/styles/tokens.css`；组件只引用语义令牌。
- Rive 输入/状态映射写入 `engineering/pet-runtime.md`；不在 UI 组件里硬编码节点名。
- 新视觉资产登记来源、许可证、体积到 [dependency-policy.md](../dependency-policy.md) 的资源规则。
- 任何视觉方案变更影响 PRD/SPEC 时，同步更新文档，不只在设计稿里改。

## 11. Do / Don't

| Do | Don't |
| --- | --- |
| 深色底 + 一处暖光 | 满屏渐变、霓虹、玻璃卡片 |
| 圆润黏土、手绘小瑕疵 | 锐利几何、写实 3D、金属高光 |
| 宠物是主角，UI 退后 | 按钮比宠物更抢眼 |
| 只动 transform/opacity | 动画 width/height/filter |
| 情绪用眼睛/耳朵/尾巴 | 用 emoji 或文字标签代替表情 |
| 60fps 优先 | 为炫技加粒子/模糊 |
